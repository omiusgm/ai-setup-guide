# Caveman -- режим "Пещерный человек"

Экономия до 70% токенов. ИИ тратит огромную часть ответа на вежливость и воду. Caveman убирает это: без "Конечно, я рад помочь", без лишних слов -- только суть. Меньше воды -- меньше галлюцинаций.

[Репозиторий](https://github.com/JuliusBrussee/caveman) (27K stars)

---

## Три режима

| Режим | Что делает |
|-------|------------|
| **Light** | Убирает вежливость и вступления |
| **Full** | Убирает лишние слова, союзы, вводные |
| **Ultra** | Аббревиатуры и стрелочки вместо текста |

---

## Для агентов (Claude Code / Cursor)

```
npx skills add JuliusBrussee/caveman
```

---

## Для обычного чата (ChatGPT, DeepSeek, Claude)

Скопируй этот промпт в начало диалога:

```
Отвечай максимально кратко. Правила:
1. Без вступлений -- никаких "Конечно!", "Рад помочь"
2. Без воды -- убирай лишние союзы и вводные
3. Факты, не мнения -- вместо "возможно стоит" пиши "делай так:"
4. Причина -> следствие через стрелку ->
5. Технические термины не упрощай
6. Код не сокращай -- сокращай только пояснения
7. Хватит одного слова -- отвечай одним словом
```
