    Инструкция для чатботов¶

    Ты чатбот (ChatGPT, DeepSeek, Gemini, Claude Chat, Perplexity). Ты НЕ можешь трогать файлы, ставить программы, выполнять команды терминала.

    Что ты МОЖЕШЬ: объяснять, советовать, составлять планы, писать промпты, генерить тексты, помогать выбрать инструмент.

    Чего НЕ делай: - Не выдумывай папки, MCP-серверы и команды терминала — пользователь сидит в браузере - Не спрашивай "чем помочь?" — предлагай конкретное - Не выдумывай того чего нет в гайде - Если не знаешь ответа — так и скажи, не галлюцинируй

    Если пользователю нужно что-то, что требует агента (файлы, автоматизация, код) — честно скажи: "Для этого нужен агент (Claude Desktop/Code, Cursor, Codex). Я могу составить план, а выполнить — он." Разница объяснена ниже в секции "Уровни ИИ".

    Отвечай на языке пользователя. Прежде чем писать кастомное решение — предлагай собрать из готовых API и сервисов как конструктор.

    ЗОЛОТЫЕ ПРАВИЛА ВАЙБКОДИНГА — ДЛЯ КОЖАНОГО¶

    Эта секция — для человека. Если ты чатбот и тебя об этом спросили — объясни на пальцах, с примерами из жизни пользователя.

    Правило 1: Новый чат — это не потеря. Это перезагрузка¶

    У ИИ есть лимит памяти (контекстное окно). Чем дольше диалог — тем хуже ИИ помнит начало. Через 50-100 сообщений он начинает тупить.

    Закончил задачу — начни новый чат. Если проект правильно настроен, ИИ подхватит контекст за секунды.

    Аналогия: это как смены на работе. Новый сотрудник читает журнал смены и продолжает.

    Правило 2: Проект живёт в файлах, не в чате¶

    Чат закончится и исчезнет. Всё важное должно быть в файлах проекта: - CLAUDE.md — конституция проекта. ИИ читает его при каждом запуске - docs/roadmap.md — куда идём, что в планах - docs/decisions.md — почему приняли решение X - CHANGELOG.md — что изменилось и когда

    Аналогия: представь что ты нанимаешь фрилансера на день. Ты дашь ему документацию, а не будешь рассказывать весь проект голосом. CLAUDE.md — это и есть документация для ИИ-фрилансера.

    Правило 3: Git — это твои сейвы. Без них ты голый¶

    Git — система версий. Как "сохраниться" в игре перед боссом. Если ИИ сломает проект — откатишься к рабочей версии за секунду.

    • Перед большими изменениями: "сделай коммит перед тем как менять"
    • Сломалось всё: "откати к последнему рабочему коммиту"

    Правило 4: Сначала план, потом код¶

    Главная ошибка: "напиши мне приложение". ИИ радостно напишет — криво, сложно, не то.

    Сначала попроси план. Обсуди. Поправь. И только потом — "делай".

    • Неправильно: "Сделай мне CRM-систему"
    • Правильно: "Составь план: что нужно для простой CRM. Какие страницы, база, функции. Покажи план — я скажу что убрать и добавить"

    Правило 5: Маленькие шаги, частые проверки¶

    Не пытайся сделать всё за один запрос. ИИ теряет фокус на больших задачах. Разбивай на шаги: сделал шаг — проверил — следующий.

    Правило 6: Говори "максимально просто"¶

    ИИ обожает усложнять. Напишет "энтерпрайз-архитектуру" для TODO-списка. Добавляй: "делай максимально просто", "без лишнего".

    Правило 7: Ошибки — это нормально. Не лезь чинить руками¶

    ИИ сломал что-то? Скопируй ошибку, отдай ИИ: "ты накосячил, исправь". В 90% случаев разберётся. В 10% — начни новый чат и объясни проблему с чистого листа.

    Правило 8: Не доверяй — проверяй¶

    ИИ скажет "всё готово, работает идеально" с уверенностью, которой не стоит верить. Протестируй сам. ИИ не умеет объективно проверять свою работу — это как спрашивать повара "вкусно ли он готовит".

    Правило 9: Скиллы и MCP — не сразу¶

    Не бросайся ставить 20 скиллов. Начни с базы: промпты → Git и CLAUDE.md → первый проект → и только потом расширяй.

    Правило 10: Ты — дирижёр, не скрипач¶

    Вайбкодинг — это не "ИИ всё сделает за меня". Ты решаешь ЧТО строить, ЗАЧЕМ и КУДА. ИИ — исполнитель. Чем лучше ты объясняешь "что" и "зачем" — тем лучше результат.

    ЕЖЛИКБЕЗ: УРОВНИ ИИ — КАКОЙ ЗАПУСКАТЬ¶

    Не "от плохого к хорошему", а как транспорт: самокат не хуже машины — он для другого.

    Найди себя за 3 вопроса¶

    1. Тебе нужно поговорить или сделать? - Поговорить (спросить, найти инфо, написать текст) → Чатбот - Сделать (создать файлы, автоматизировать) → читай дальше

    2. Ты готов ставить программу на комп? - Нет, только браузер → Чатбот (и это нормально, 80% задач решаются тут) - Да → Агент на ПК

    3. Тебе нужно писать код? - Нет, я не кодер → Агент на ПК (Claude Desktop, Codex) — он сам разберётся - Да → Редактор кода (Cursor, VS Code + расширения)

    Уровень 1: Чатбот (браузер)¶

    Умный собеседник в кафе — обсуждает, советует, но за тебя ничего не делает

    Примеры: ChatGPT, DeepSeek, Claude.ai, Gemini, Perplexity

    Лучшие сценарии: написать/отредактировать текст, ресёрч, объяснить тему, перевести, составить план

    Чего НЕ может: не трогает файлы, не помнит между сессиями, не делает действий — только текст

    Цена: DeepSeek бесплатно. ChatGPT Plus ~$20/мес. Claude Pro ~$20/мес

    Уровень 2: Агент на ПК (десктоп-приложение)¶

    Ассистент с доступом к компьютеру — ходит по папкам, открывает браузер, делает за тебя

    Примеры: Claude Desktop (Code/Cowork), OpenAI Codex

    Лучшие сценарии: сайт/лендинг, пачка файлов, автоматизация, работа с Notion/Telegram/Google Docs одновременно

    Почему он не рисует? ChatGPT = болтун + художник (DALL-E). Claude Desktop = мощный болтун + руки (файлы). Разные суперсилы.

    Цена: Claude Max ~$100-200/мес. Codex ~$200/мес

    Уровень 3: Терминал / CLI¶

    Механик в яме — залезет куда надо, но ты должен знать куда показать

    Примеры: Claude Code, Aider, Goose, Cline

    Это тот же мозг что в Claude Desktop, просто другой интерфейс. Как авто с механикой vs автоматом.

    Цена: Claude Max ~$100-200/мес

    Уровень 4: Редактор кода (IDE)¶

    Кабинет разработчика — код слева, ИИ справа

    Примеры: Cursor, VS Code + Copilot, Windsurf, JetBrains + AI

    Цена: VS Code бесплатно (+ Copilot ~$10/мес). Cursor ~$20/мес

    БЮДЖЕТ НА ИИ¶

    Сжигаем лимиты (>$200/мес) — Claude Max ($100-200) + Cursor Pro $20 + API. Лучшие модели, максимальная скорость.

    Эконом (~$100/мес) — Claude Pro $20 + Cursor Pro $20 + Gemini CLI бесплатно + n8n. Покрывает 90% задач.

    Супер-эконом (~$20/мес) — Claude Pro $20 ИЛИ Cursor Pro $20. Одна подписка.

    Арбузный (минимум) — Gemini CLI (1000 запросов/день бесплатно) + Cline в VS Code (свои API-ключи) + DuckDuckGo MCP.

    API vs подписка: подписка ($20-200/мес) — фиксированная цена, лимиты. API (pay-as-you-go) — платишь за каждый токен, без лимитов но непредсказуемые расходы. Новичкам: начни с подписки.

    CAVEMAN — РЕЖИМ "ПЕЩЕРНЫЙ ЧЕЛОВЕК"¶

    ИИ тратит до 70% ответа на вежливость и воду. Caveman убирает это: экономия токенов + повышение точности.

    Три режима: Light (убрать вежливость), Full (убрать лишние слова), Ultra (аббревиатуры и стрелочки)

    Для обычного чата (ChatGPT, DeepSeek, Claude): скопируй этот промпт в начало диалога:

    Отвечай максимально кратко. Правила:
1. Без вступлений — никаких "Конечно!", "Рад помочь"
2. Без воды — убирай лишние союзы и вводные
3. Факты, не мнения — вместо "возможно стоит" пиши "делай так:"
4. Причина → следствие через стрелку →
5. Технические термины не упрощай
6. Код не сокращай — сокращай только пояснения
7. Хватит одного слова — отвечай одним словом

    Для агентов (Claude Code/Cursor): npx skills add JuliusBrussee/caveman

    МИФЫ И РЕАЛЬНОСТЬ — ВСЁ ЧТО ВАМ НАВРАЛИ ПРО ИИ¶

    Продуктивность¶

    Миф: ИИ делает в 10x быстрее. Реальность: устойчивое ускорение 1.5-2x, пики 3-5x на конкретных задачах. Исследование METR: опытные разработчики с ИИ были на 19% МЕДЛЕННЕЕ, но думали что на 20% быстрее.

    Миф: Больше PR = больше продуктивность. Реальность: объёмы PR +98%, скорость доставки — плоская. ИИ сдвигает bottleneck, а не убирает.

    Качество кода¶

    Миф: Если код работает — значит правильный. Реальность: 45% ИИ-кода содержит уязвимости. Работает — не значит безопасно.

    Миф: Достаточно "make it secure". Реальность: улучшение только с 56% до 66%. Нужны SAST-инструменты.

    Мультиагенты¶

    Миф: Больше агентов = быстрее. Реальность: при 85% точности на действие, 10-шаговый workflow успешен лишь 20% времени. 41-86% мультиагентных систем фейлятся.

    Миф: Автономная компания агентов. Реальность: полное делегирование — 0-20% задач (Anthropic). Ассистирование ~60%.

    Галлюцинации¶

    Миф: ИИ редко галлюцинирует в коде. Реальность: ИИ галлюцинирует API, функции, параметры и даже зависимости.

    Миф: ИИ может проверить свой код. Реальность: ИИ галлюцинирует корректность и удваивает ставку на ошибки. Никогда не доверяй self-report.

    Риски¶

    Миф: Vibe coding — не нужно понимать код. Реальность: "Стена 18 месяцев" — месяцы 1-3: эйфория. 4-8: растущий overhead. 16-18: разработка встаёт.

    Главный вывод¶

    ИИ не заменит разработчиков в 2026-2027. Он меняет профессию: от "я пишу код" к "я определяю что строить, оркестрирую ИИ, проверяю и несу ответственность".

    КОНСИЛИУМ — ПРОВЕРКА РАБОТЫ ЧУЖИМИ ГЛАЗАМИ¶

    ИИ не может проверить свою работу сам. Но может спавнить других ИИ с другими ролями.

    Как попробовать (в любом чате):

    Написал текст/код — скажи: "Проверь мой текст от лица трёх человек: новичок (не в теме), скептик (устал от хайпа), эксперт (знает тему глубоко). Каждый пусть ответит от первого лица."

    ПАМЯТЬ И КОНТЕКСТ¶

    Проблема "Мементо"¶

    ИИ как герой фильма "Мементо" — каждый разговор с чистого листа. Через 20-50 сообщений теряет начало. Не помнит прошлые сессии.

    Как решать¶

    • CLAUDE.md — файл который агент читает при каждом запуске. Храни архитектуру, решения, приоритеты
    • /compact — сжатие контекста когда диалог длинный
    • Кастомные GPTs / Projects — привязанная инструкция + база знаний
    • Обратный промптинг — получил идеальный результат? Скажи: "Напиши промпт, который даст такой же результат в новом чате"
