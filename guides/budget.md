# Бюджет на ИИ

Четыре варианта -- от бесплатного до полного стека. Выбери свой.

---

## 4 тарифа

### Сжигаем лимиты (>$200/мес)

Claude Max ($100 или $200 в зависимости от тарифа) + Cursor Pro $20 + API. Лучшие модели, максимальная скорость.

### Эконом (~$100/мес)

Claude Pro $20 + Cursor Pro $20 + Gemini CLI бесплатно + n8n. Покрывает 90% задач.

### Супер-эконом (~$20/мес)

Claude Pro $20 ИЛИ Cursor Pro $20. Одна подписка, переключаешься между инструментами.

### Арбузный (минимум)

Бесплатные тарифы: Gemini CLI (1000 запросов/день бесплатно) + Cline в VS Code (свои API-ключи) + DuckDuckGo MCP.

---

## API vs подписка -- в чём разница

- **Подписка** ($20-200/мес) -- фиксированная цена, лимиты на использование, удобно для большинства
- **API** (pay-as-you-go) -- платишь за каждый запрос/токен, без лимитов но непредсказуемые расходы. Для начинающих -- утопия (легко сжечь $50-100 за день)

> **Нюанс для бюджетников:** Anthropic запрещает использовать подписку Claude в сторонних инструментах (OpenClaw, Cline и др.) -- только через API-ключ с отдельной оплатой токенов. OpenAI наоборот -- разрешает подписку ChatGPT Plus ($20) в Cursor, Windsurf, Cline и других IDE. Если бюджет ограничен и хочешь агентов через подписку -- ChatGPT Plus + Cursor/Cline может быть выгоднее, чем Claude Pro + API-ключ сверху.

**Рекомендация для новичков:** начни с подписки Claude Pro за $20. API -- только когда понимаешь расход токенов и зачем это нужно.

## Выбор модели и effort

В нижней панели Code можно выбрать модель и уровень мышления. Многие не знают и жгут токены.

### Модели

| Модель | Для чего |
|--------|----------|
| **Opus 4.6** | Самая мощная (архитектура, сложный дебаг) |
| **Opus 4.6 1M** | То же + 1M контекст (огромные кодобазы) |
| **Sonnet 4.6** | Быстрая и дешёвая (80% ежедневной работы) |
| **Haiku 4.5** | Самая быстрая (простые вопросы, суб-агенты) |

**Стратегия:** Sonnet 80% задач, Opus для сложного, Haiku для простого = экономия 50-70%.

### Effort (уровень мышления)

| Уровень | Когда использовать |
|---------|--------------------|
| **Low** | Быстрые ответы, простые правки |
| **Medium** | Стандарт |
| **High** | Глубокое рассуждение, архитектура |
| **Max** | Максимум качества, максимум расхода |
