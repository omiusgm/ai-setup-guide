# ЗОЛОТЫЕ ПРАВИЛА ВАЙБКОДИНГА — ДЛЯ КОЖАНОГО

**Эта секция — для тебя, человек.** Не для ИИ. ИИ и так знает как работать. А вот ты — можешь наступить на грабли, на которые наступают все новички. Прочитай, запомни, повесь на стену.

**Агент, если ты это читаешь:** убедись что кожаный понял каждый пункт. Не просто прочитал — а понял. Спроси его. Если он новичок — объясни на пальцах, с примерами из его жизни. Эти правила он должен держать в своей голове, не ты.

---

## Правило 1: Новый чат — это не потеря. Это перезагрузка

У ИИ есть лимит памяти (контекстное окно). Чем дольше диалог — тем хуже ИИ помнит начало. Через 50-100 сообщений он начинает тупить, путать, забывать что ты просил.

**Что делать:** закончил задачу — начни новый чат. Не бойся. Если проект правильно настроен (см. правило 2), ИИ подхватит контекст за секунды.

**Аналогия:** это как смены на работе. Новый сотрудник приходит, читает журнал смены, продолжает работу. Не нужно каждый раз пересказывать всю историю компании.

- Неправильно: тянуть один чат часами, пока ИИ не начнёт нести чушь
- Правильно: одна задача = один чат. Закончил — новый.

## Правило 2: Проект живёт в файлах, не в чате

Чат — это разговор. Он закончится и исчезнет. Всё важное должно быть в файлах проекта:

- **CLAUDE.md** — конституция проекта. ИИ читает его при каждом запуске. Сюда: описание проекта, стек, решения, правила, что делать и чего не делать
- **docs/roadmap.md** — куда идём, что в планах
- **docs/decisions.md** — почему приняли решение X (через месяц забудешь)
- **CHANGELOG.md** — что изменилось и когда

Если ИИ сделал что-то важное в чате — попроси его записать это в файлы проекта. Иначе в следующем чате он об этом не узнает.

**Аналогия:** представь что ты нанимаешь фрилансера на день. Ты же не будешь рассказывать ему весь проект голосом? Ты дашь ему документацию. CLAUDE.md — это и есть документация для ИИ-фрилансера.

## Правило 3: Git — это твои сейвы. Без них ты голый

Git — система версий. Как "сохраниться" в игре перед боссом. Если ИИ сломает проект — откатишься к рабочей версии за секунду.

**Что делать:**

- В начале проекта: попроси ИИ инициализировать Git
- Перед большими изменениями: "сделай коммит перед тем как менять"
- Сломалось всё: "откати к последнему рабочему коммиту"

GitHub — это облачное хранилище для Git. Проект не потеряется даже если ноутбук утонет.

- Неправильно: работать без Git и молиться что ничего не сломается
- Правильно: коммит перед каждым крупным изменением

## Правило 4: Сначала план, потом код

Главная ошибка: "напиши мне приложение". ИИ радостно напишет — криво, сложно, не то что нужно.

**Что делать:** сначала попроси план. Обсуди его. Поправь. И только потом — "делай".

В Claude Code есть Plan Mode — режим где ИИ только планирует, не пишет код. Используй его.

- Неправильно: "Сделай мне CRM-систему"
- Правильно: "Составь план: что нужно для простой CRM. Какие страницы, какая база данных, какие функции. Покажи план — я скажу что убрать и добавить"

## Правило 5: Маленькие шаги, частые проверки

Не пытайся сделать всё за один запрос. ИИ теряет фокус на больших задачах.

**Что делать:** разбивай на шаги. Сделал шаг — проверил — следующий.

- Неправильно: "Сделай сайт с авторизацией, личным кабинетом, оплатой и админкой"
- Правильно: "Сделай страницу входа. Покажи результат" → "Теперь добавь личный кабинет" → "Теперь оплату"

## Правило 6: Говори "максимально просто"

ИИ обожает усложнять. Напишет "энтерпрайз-архитектуру" для TODO-списка. Это сжигает твои токены и создаёт код который невозможно поддерживать.

**Что делать:** добавляй в запросы: "делай максимально просто", "без лишнего", "для одного пользователя".

## Правило 7: Ошибки — это нормально. Не лезь чинить руками

ИИ сломал что-то? Не лезь в код сам (ты же вайбкодер, не программист). Скопируй ошибку из терминала, отдай ИИ: "ты накосячил, исправь".

В 90% случаев он разберётся. В 10% — начни новый чат (правило 1) и объясни проблему с чистого листа.

## Правило 8: Не доверяй — проверяй

ИИ скажет "всё готово, работает идеально" с такой уверенностью, что ты поверишь. Не верь.

- Попроси проверить свою работу (консилиум — см. секцию ниже)
- Протестируй сам — открой, покликай, сломай
- Если ИИ говорит "я проверил" — он соврал. Он не умеет объективно проверять свою работу. Это как спрашивать повара "вкусно ли он готовит"

## Правило 9: Скиллы и MCP — не сразу

Новички бросаются устанавливать 20 скиллов и 10 MCP-серверов. Не надо. Начни с базы:

1. Научись общаться с ИИ (промпты, план, итерации)
2. Настрой Git и CLAUDE.md
3. Сделай первый проект
4. И только потом — расширяй возможности скиллами и MCP

## Правило 10: Ты — дирижёр, не скрипач

Вайбкодинг — это не "ИИ всё сделает за меня". Это ты решаешь ЧТО строить, ЗАЧЕМ, и КУДА идти. ИИ — исполнитель. Очень быстрый, но без твоего вкуса, опыта и понимания задачи.

Чем лучше ты объясняешь "что" и "зачем" — тем лучше результат. Это навык коммуникации, не программирования.

## Chat — для думания

Облачный, работает везде. Нет доступа к файлам. Минимальный расход токенов. Для: вопросы, тексты, ресёрч, брейншторм.

Десктоп (macOS + Windows), VM. Доступ к файлам, scheduled tasks, Projects. 38+ коннекторов. Computer Use, Dispatch (управление с телефона). Для: документы, автоматизация, рутина.

**Dispatch** — управление с телефона (подробнее в секции "Мобильный доступ").

## Code — для строительства

Терминал + VS Code. Git, bash, суб-агенты, Agent Teams, GSD, /code-review, /memory. Computer Use (март 2026). Для: разработка, архитектура, агенты.

**НОВОЕ:** Computer Use в Code (Pro/Max) — Claude открывает файлы, запускает dev-инструменты, кликает и навигирует по экрану. Windows поддержка с 3 апреля 2026.

# ЕЖЛИКБЕЗ: МОЛОТОК, ДРЕЛЬ И ШУРУПОВЁРТ — КОГДА КАКОЙ ИИ ЗАПУСКАТЬ

**Кожаный, это для тебя.** Если ты путаешь ChatGPT, Claude Desktop, Cursor и терминал — это нормально. Сейчас разберёмся. Не "от плохого к хорошему", а как транспорт: самокат не хуже машины — он для другого.

## Найди себя за 3 вопроса

**1. Тебе нужно поговорить или сделать?**

- Поговорить (спросить, найти инфо, написать текст) → **Чатбот**
- Сделать (создать файлы, автоматизировать, поработать с папками) → читай дальше

**2. Ты готов ставить программу на комп?**

- Нет, только браузер → **Чатбот** (и это нормально, 80% задач решаются тут)
- Да → **Агент на ПК**

**3. Тебе нужно писать код или автоматизировать по-серьёзному?**

- Нет, я не кодер → **Агент на ПК** (Claude Desktop, Codex) — он сам разберётся
- Да, пишу код → **Редактор кода** (Cursor, VS Code + расширения)

## Уровень 1: Чатбот (браузер)

*Умный собеседник в кафе — обсуждает, советует, но за тебя ничего не делает*

**Примеры:** ChatGPT, DeepSeek, Claude.ai, Gemini, Perplexity

**Лучшие сценарии:** написать/отредактировать текст, найти информацию (ресёрч), объяснить тему, перевести, пересказать, составить план

**Чего НЕ может:** не трогает файлы на компе, не помнит между сессиями (каждый раз заново), не делает действий — только текст, не видит экран

**Картинки:** только ChatGPT (платно, через DALL-E). Claude, DeepSeek, Gemini — нет

**Цена:** DeepSeek — бесплатно. ChatGPT Plus — ~$20/мес. Claude Pro — ~$20/мес

## Уровень 2: Агент на ПК (десктоп-приложение)

*Ассистент с доступом к компьютеру — ходит по папкам, открывает браузер, делает за тебя*

**Примеры:** Claude Desktop (режим Code/Cowork), OpenAI Codex

**Лучшие сценарии:** создать сайт/лендинг, обработать пачку файлов, настроить автоматизацию (боты, рассылки), работать с Notion/Telegram/Google Docs одновременно

**Чего НЕ может (из коробки):** генерить картинки (это другой тип ИИ — текстовый мозг, а не художник), гуглить глубоко (нужны доп. подключения MCP), работать без интернета

**Почему он не рисует?** ChatGPT = болтун + художник (DALL-E) в одном окне. Claude Desktop = мощный болтун + руки (трогает файлы). Разные суперсилы. Как электрик и маляр — оба мастера, но один красит, другой провода тянет.

**Цена:** Claude Max — ~$100-200/мес. Codex — ~$200/мес

## Уровень 3: Терминал / CLI

*Механик в яме — залезет куда надо, но ты должен знать куда показать*

**Примеры:** Claude Code (в терминале), Aider, Goose, Cline

**Лучшие сценарии:** разработка проекта с нуля, автоматизация сложных цепочек, работа с git и серверами, массовый рефакторинг

**Важно:** это тот же мозг что в Claude Desktop, просто другой интерфейс. Как автомобиль с механикой vs автоматом — едут одинаково, управление разное

**Цена:** Claude Max — ~$100-200/мес (включает Desktop и CLI)

## Уровень 4: Редактор кода (IDE)

*Кабинет разработчика — код слева, ИИ справа, всё под рукой*

**Примеры:** Cursor, VS Code + Copilot, Windsurf, JetBrains + AI

**Лучшие сценарии:** код с ИИ-подсказками в реальном времени, навигация по большому проекту, код-ревью, тесты

**Цена:** VS Code — бесплатно (+ Copilot ~$10/мес). Cursor — ~$20/мес

## Скиллы и MCP — приложения для твоего ИИ

MCP-подключения — это как приложения на телефоне. Телефон из коробки звонит и снимает. Поставил Telegram — мессенджер. Поставил банк — кошелёк.

Так же с ИИ: подключил Notion MCP → агент работает с документами. Подключил Telegram MCP → постит в канал. Подключил поисковый MCP → гуглит.

**Вот почему ChatGPT "из коробки" ищет, а Claude Desktop — нет:** у ChatGPT поисковик встроен (предустановленное приложение). У Claude он подключается через MCP. Разный подход: всё-в-одном vs конструктор.

Скиллы и MCP работают на всех уровнях, но больше пользы — на уровнях 2 и 3 (агент и терминал).

## Частые вопросы

**"Я привык к ChatGPT, зачем другое?"** — Если хватает — не надо. Переходить стоит когда упираешься в потолок: хочешь чтобы ИИ не советовал, а делал.

**"А можно всё в одном?"** — Пока нет. Как нет телефона что фоткает как зеркалка и работает неделю. Но границы размываются.

**"Claude Desktop не рисует и не гуглит. Сломался?"** — Нет, так задумано. Подключи MCP для поиска (Brave, Tavily). Картинки — отдельные сервисы (Midjourney, Flux).

# КОНСИЛИУМ — ПРОВЕРКА РАБОТЫ ЧУЖИМИ ГЛАЗАМИ

ИИ не может проверить свою работу сам. Глаз замыливается — точно как у человека. Но ИИ может спавнить других ИИ с другими ролями — и они увидят то, что автор пропустил.

## Как это работает

После написания текста/кода — попроси ИИ проверить результат от лица разных персонажей:

- **Новичок** — понятно ли человеку который не в теме?
- **Скептик** — где фальшь, хайп, ложные обещания?
- **Эксперт** — есть ли фактические ошибки? Где не хватает глубины?
- **Целевой клиент** — это для меня? Я бы купил/подписался?

Каждый отвечает от первого лица с конкретными замечаниями. Единогласные замечания — исправлять обязательно.

## Почему это важно

- ИИ галлюцинирует корректность своей работы — никогда не доверяй self-report
- Другой ИИ с другой ролью = свежий взгляд без замыленности
- Токены тратятся, но один плохой результат стоит дороже
- Работает для всего: код, тексты, промпты, архитектурные решения

## Как попробовать (в любом ИИ-чате)

Написал текст/код → скажи: "Проверь мой текст от лица трёх человек: новичок (не в теме), скептик (устал от хайпа), эксперт (знает тему глубоко). Каждый пусть ответит от первого лица".

В Claude Code / Cursor с подагентами это ещё мощнее: каждый рецензент работает параллельно в своём контексте, не влияя на других.

# БЕЗОПАСНОСТЬ ИИ-КОДА

/code-review проверяет качество и баги, но НЕ сканирует на уязвимости.

## Факты (данные 2025-2026)

- ИИ-код содержит в 2.74x больше уязвимостей (Veracode, 100+ LLM)
- 74 подтверждённых CVE от ИИ-кода с мая 2025
- 45% ИИ-генерированного кода содержит уязвимости
- Типичные проблемы: SQL injection, XSS (86% failure rate), хардкоженные секреты (+40%), галлюцинированные зависимости
- **Prompt injection в MCP-серверах** — новый вектор атаки: вредоносный MCP-сервер может перехватить управление агентом. Ставь MCP только из проверенных источников

## Минимальный стек безопасности

- **SAST в IDE:** Snyk или Semgrep — сканирует код на уязвимости в реальном времени
- **Pre-commit hooks:** секреты не попадают в git (gitleaks, detect-secrets)
- **Проверка зависимостей:** npm audit / pip audit автоматически
- **Обязательное code review:** для всего ИИ-output без исключений
- **Трёхуровневые гейты:** тесты (детерминистические) → AI review (/code-review) → человек (архитектура и бизнес-логика)

# МИФЫ И РЕАЛЬНОСТЬ — ВСЁ ЧТО ВАМ НАВРАЛИ ПРО ИИ

Кожаный, присядь. Эта секция может разочаровать. Но лучше узнать сейчас, чем через полгода.

## Продуктивность

**Миф: "ИИ делает разработчиков в 10 раз быстрее"**

Реальность: Устойчивое ускорение 1.5-2x, пики 3-5x на конкретных задачах. Исследование METR: опытные разработчики с ИИ были на 19% МЕДЛЕННЕЕ, но думали что на 20% быстрее (разрыв восприятия 39 пунктов). Да, ты правильно прочитал — медленнее, но думали что быстрее. Когнитивное искажение в чистом виде.

Источник: [METR Study](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/)

**Миф: "Больше PR = больше продуктивность"**

Реальность: Объёмы PR +98%, скорость доставки — плоская. ИИ сдвигает bottleneck (к ревью), а не убирает его. Rework съедает 15-25% прироста.

Источник: LinearB (8.1M+ PR)

**Миф: "ИИ помогает джуниорам больше, чем сеньорам"**

Реальность: Данные противоречивы. Джуниоры: 1.5-1.8x (ИИ убирает ресёрч). Сеньоры: 1.3x, но тратят время на проверку субтильных ошибок, которые джуниоры пропускают.

Источник: [California Management Review](https://cmr.berkeley.edu/2025/10/seven-myths-about-ai-and-productivity-what-the-evidence-really-says/)

## Качество кода

**Миф: "Если код работает — значит код правильный"**

Реальность: 45% ИИ-кода содержит уязвимости. Работает — не значит безопасно. Как машина без тормозов — едет же. 8x рост дублирования, 60% снижение рефакторинга. Фрустрация номер 1: "решения, которые почти правильные" (45% разработчиков, Stack Overflow).

Источник: GitClear (211M строк), Veracode

**Миф: "Достаточно написать в промпте make it secure"**

Реальность: Улучшение только с 56% до 66%. Нужны SAST-инструменты, pre-commit hooks, ревью.

## Мультиагенты

**Миф: "Больше агентов = быстрее"**

Реальность: При 85% точности на действие, 10-шаговый workflow успешен лишь 20% времени (составная вероятность). 41-86% мультиагентных систем фейлятся, 79% провалов — координационные сбои. Короче, армия агентов из рилсов — это пока скорее армия стажёров.

**Миф: "Можно построить полностью автономную компанию агентов"**

Реальность: Данные Anthropic: полное делегирование 0-20% задач. Ассистирование ~60%. Остальное — только человек. Качество падает с каждым слоем иерархии (CEO→Manager→Worker).

## Галлюцинации

**Миф: "ИИ редко галлюцинирует в коде"**

Реальность: ИИ галлюцинирует API, названия функций, параметры и даже зависимости (атакующие регистрируют их как реальные пакеты). Решение: Context7 MCP (актуальная документация 9000+ библиотек).

**Миф: "ИИ может проверить свой собственный код"**

Реальность: ИИ галлюцинирует корректность, удваивает ставку на ошибки, рационализирует баги как фичи. Никогда не доверяй self-report агента — верифицируй через тесты, git или /code-review. Агент скажет "всё работает" с такой же уверенностью, как стажёр который сломал прод. Проверяй.

Источник: Block AI Research "Adversarial Cooperation"

## Риски

**Миф: "Vibe coding — это когда не нужно понимать код"**

Реальность: "Стена 18 месяцев" — задокументированный паттерн. Месяцы 1-3: эйфория скорости. 4-8: растущий overhead на ревью. 16-18: разработка встаёт — команда не понимает собственную систему.

Источник: [MIT Technology Review](https://www.technologyreview.com/2025/12/15/1128352/rise-of-ai-coding-developers-2026/)

**Миф: "ИИ-агенты — это просто инструмент, зависимости нет"**

Реальность: Исследователи и CTO отмечают признаки зависимости: "Они работают как игровые автоматы". CTO Rootly: не мог спать месяцами, понадобилось медикаментозное лечение.

Источник: [Axios](https://www.axios.com/2026/04/04/ai-agents-burnout-addiction-claude-code-openclaw)

## Главный вывод

ИИ не заменит разработчиков в 2026-2027. Он усиливает продуктивность и меняет профессию. От "я пишу код" к "я определяю что строить, оркестрирую ИИ, проверяю и несу ответственность". И да, ответственность никуда не делась — она всё ещё на тебе, кожаный.

# КОНТЕКСТНОЕ ОКНО И ПОТЕРЯ ПАМЯТИ

## Проблема "Мементо"

ИИ как герой фильма "Мементо" — каждый разговор начинает с чистого листа. Через 20-50 сообщений теряет начало беседы. Не помнит прошлые сессии.

## Как решать

- **CLAUDE.md** — "стикеры на теле" из фильма. Файл который агент читает при каждом запуске. Храни архитектуру, решения, приоритеты.
- **/compact** — команда для сжатия контекста. Используй когда диалог длинный.
- **Auto Memory / Auto Dream** — Claude сам запоминает паттерны между сессиями.
- **Honcho / Mem0** — кросс-сессионная память через MCP.
- **Кастомные GPTs / Projects** — привязанная инструкция + база знаний. Подходит когда нужен стабильно один и тот же результат.

## Обратный промптинг

Если получил идеальный результат и хочешь воспроизвести его стабильно:

→ Скажи: "Напиши промпт, который даст точно такой же результат в новом чате"

ИИ создаст промпт-инструкцию который ты можешь переиспользовать.

## Правила ведения проекта в файлах (не в чате!)

Не храни контекст проекта в чате — он потеряется. Храни в файлах:

- `.claude/CLAUDE.md` — конституция проекта (архитектура, стек, решения)
- `docs/roadmap.md` — куда идём
- `docs/decisions.md` — почему приняли решение X
- `docs/done.md` — что уже сделано
- `CHANGELOG.md` — история изменений

Периодически напоминай агенту: "Прочитай и обнови project docs".

# ИИ-АГЕНТ ДЛЯ CRM: AmoCRM + Битрикс24

**Кожаный, это для тебя.** Если ты РОП, предприниматель или владелец бизнеса с AmoCRM/Битрикс24 — ИИ может забрать рутину с отчётами, мониторингом сделок и аналитикой. Подтверждённый кейс: +22% конверсия, 4 часа/день экономии для РОПа (SaleKit, дистрибьютор, 12 менеджеров, апрель 2026).

## Что умеет ИИ-агент для CRM

**Утренний брифинг (8:30 в Telegram):** новые сделки, просрочки, топ-3 сделки которые вот-вот закроются, конверсия vs прошлая неделя. Экономия ~60 мин/день.

**Мониторинг зависших сделок (каждые 2 часа):** сделка без движения > 48ч → алерт, лид без первого контакта > 24ч → напоминание. Снижение забытых сделок на 90%. Экономия ~1-2 часа/день.

**Еженедельный отчёт:** рейтинг менеджеров (конверсия, средний чек, скорость), узкие места воронки, прогноз выполнения плана.

**Анализ проигранных сделок (ежемесячно):** категоризация причин потерь, паттерны по этапам и менеджерам, тренды.

**Прогноз выручки:** взвешенный pipeline-прогноз на основе исторических конверсий и текущих сделок.

## Как подключить: пошагово

### Шаг 1: Получи API-ключ AmoCRM

Настройки → Интеграции → Ключи → создать приватную интеграцию → скопировать Long-lived Token. Этот токен бессрочный, подходит для одного аккаунта. Храни как пароль — не свети в чатах.

### Шаг 2: Выбери способ подключения

**Вариант А: n8n (рекомендуемый для не-программистов)**

Визуальный конструктор. Собираешь цепочку: таймер (8:30) → запрос в AmoCRM → ИИ анализирует → Telegram отправляет.

- Хостинг: [Beget](https://beget.com) от 210 руб/мес (готовый образ n8n, локация Москва)
- Нода для AmoCRM: `n8n-nodes-amocrm` (Settings → Community Nodes)
- ИИ: нативный нод Anthropic Chat Model или DeepSeek через HTTP
- Вывод: Telegram Bot нода (встроенная)
- Срок запуска: 2-3 дня (даже без опыта)

**Вариант Б: MCP-подключение (для пользователей Claude Desktop/Code)**

ИИ-агент подключается к AmoCRM напрямую. Можно спросить в чате: "Покажи все сделки которые зависли больше 5 дней" и получить ответ.

- [cAIborg-ai/amocrm-mcp](https://github.com/cAIborg-ai/amocrm-mcp) — 36 инструментов, OAuth, rate-limiting из коробки (рекомендуем)
- [ampulex-23/KommoMCP](https://github.com/ampulex-23/KommoMCP) — 54 инструмента, AI-коучинг, прогнозирование, геймификация (максимум функций)
- Установка: `pip install -e .` + указать AMO_SUBDOMAIN и AMO_ACCESS_TOKEN

**Гибридная стратегия (лучший вариант):** n8n для автоматических отчётов по расписанию + MCP-подключение для разовых запросов в чате.

### Шаг 3: Настрой первый сценарий

Начни с утреннего брифинга — он простой и сразу показывает ценность:

1. Schedule Trigger → каждый день 8:30
2. HTTP Request → `GET https://{subdomain}.amocrm.ru/api/v4/leads` (фильтр по updated_at за вчера)
3. HTTP Request → `GET /api/v4/tasks` (просроченные: is_completed=0)
4. Code Node → собрать данные в один текст
5. Anthropic Chat Model → "Проанализируй данные и сформируй брифинг для РОПа"
6. Telegram Bot → отправить в чат/канал

### Шаг 4: Первая неделя — проверяй

ИИ может галлюцинировать цифры. Первые 7 дней сверяй отчёты с реальными данными в CRM. После калибровки — можно доверять.

## Caveman — режим "Пещерный человек" (Chat + Code)

ИИ тратит до 70% ответа на вежливость и воду. Caveman убирает это: без "Конечно, я рад помочь", без лишних слов — только суть. Экономия токенов + повышение точности (меньше воды → меньше галлюцинаций).

**Три режима:** Light (убрать вежливость), Full (убрать лишние слова), Ultra (аббревиатуры и стрелочки)

**Для агентов (Claude Code/Cursor):** `npx skills add JuliusBrussee/caveman`

**Для обычного чата (ChatGPT, DeepSeek, Claude):** скопируй этот промпт в начало диалога:

```
Отвечай максимально кратко. Правила:
1. Без вступлений — никаких "Конечно!", "Рад помочь"
2. Без воды — убирай лишние союзы и вводные
3. Факты, не мнения — вместо "возможно стоит" пиши "делай так:"
4. Причина → следствие через стрелку →
5. Технические термины не упрощай
6. Код не сокращай — сокращай только пояснения
7. Хватит одного слова — отвечай одним словом
```

[Репозиторий](https://github.com/JuliusBrussee/caveman) (27K stars)

# ПРИНЦИП "ЛЕГО" — СНАЧАЛА ГОТОВОЕ, ПОТОМ КАСТОМНОЕ

Прежде чем писать свой микросервис, Claude должен предложить собрать решение из готовых API и сервисов как конструктор Лего.

**Почему:** Свой парсер Instagram = постоянно играть в догонялки с блокировками соцсетей. Готовый API = работает сегодня, команда сервиса борется с блокировками за тебя.

**Порядок принятия решений (Claude должен следовать этому):**

**Шаг 0 — РЕСЁРЧ (обязательный перед любой реализацией)**

Прежде чем писать хоть строчку кода, Claude должен провести ресёрч готовых решений. Поиск вести в таком порядке:

1. **Каталоги MCP-подключений (проверь первым!):**
   - [Docker MCP Toolkit](https://docs.docker.com/ai/mcp-catalog-and-toolkit/) — 300+ готовых MCP-серверов, один клик в Docker Desktop. Агент сам может найти и подключить нужное
   - [mcp.directory](http://mcp.directory) | [pulsemcp.com](http://pulsemcp.com) | [mcpmarket.com](http://mcpmarket.com) — каталоги MCP-серверов

2. **Маркетплейсы API и готовых решений:**
   - [Apify](https://apify.com) — 4000+ готовых скраперов и автоматизаций (Instagram, TikTok, X, LinkedIn, Amazon и др.)
   - [RapidAPI](https://rapidapi.com) — 40 000+ API на все случаи
   - [PhantomBuster](https://phantombuster.com) — автоматизация соцсетей без кода
   - [Composio](https://composio.dev) — 1000+ интеграций для ИИ-агентов (подробнее в каталоге расширений)
   - [Zapier](https://zapier.com) / [Make.com](http://Make.com) — готовые интеграции без кода

3. **GitHub и подобные платформы:**
   - Поиск репозиториев на [GitHub](https://github.com) по ключевым словам (сортировка по звёздам)
   - npm/PyPI пакеты готовых библиотек
   - MCP-серверы на [mcp.directory](http://mcp.directory), [pulsemcp.com](http://pulsemcp.com), [mcpmarket.com](http://mcpmarket.com)
   - Скиллы Claude Code на [antigravity](https://github.com/antigravity)

4. **Веб-поиск:**
   - Поиск в интернете: "[нужная задача] API", "[задача] SaaS", "[задача] n8n integration"
   - Проверка: есть ли готовая нода в n8n для этого сервиса?

**Шаг 1** — Есть готовый API/сервис? → Используй

**Шаг 2** — Есть готовый репозиторий/пакет? → Интегрируй

**Шаг 3** — Можно собрать из комбинации сервисов + n8n? → Комбинируй

**Шаг 4** — Ничего не подходит? → Только тогда пиши свой микросервис

> Если у агента нет MCP-серверов для поиска (Brave, Exa, Tavily) — он ищет плохо и медленно. Claude должен честно предупредить: "У меня сейчас слабый поиск. Погугли сам по ключевым словам: [instagram scraper API], [telegram parser service] — и скинь мне ссылки, я оценю." Лучше попросить пользователя помочь с ресёрчем, чем изобретать велосипед.

# РЕЖИМЫ РАЗРЕШЕНИЙ В CODE

> **ВАЖНО:** По умолчанию Claude Code стоит в режиме Ask permissions и спрашивает подтверждение на КАЖДОЕ действие. Ты не сможешь отойти от компа — Claude будет ждать твоего "да" на каждый шаг. Чтобы это изменить — нужно зайти в настройки.

## Как настроить

Settings → Claude Code → включить:

- **Allow bypass permissions mode** — без этого кнопка Bypass в нижней панели не работает!
- **Draw attention on notifications** — Claude мигает иконкой когда ждёт тебя
- **Preview** — Claude запускает dev-сервер и показывает превью в браузере
- **Persist Preview sessions** — сохраняет cookies/sessions между сессиями
- **Worktree location** — где хранить git worktrees для параллельных агентов

Settings → General:

- **Browser Use → Allow all browser actions** — без этого Claude спрашивает на каждую страницу
- **Computer Use** — управление клавиатурой/мышью
- **Keep computer awake** — комп не уснёт пока Claude работает (для scheduled tasks)
- **Accessibility → Granted** — взаимодействие с UI
- **Screen Recording → Granted** — скриншоты

# ОСОБЕННОСТИ ВАЙБКОДИНГА В РОССИИ

## VPN — доступ к зарубежным сервисам

> *В России ИИ-сервисы не заблокированы. Ограничения доступа — это санкции со стороны самих компаний (Anthropic, OpenAI, Google), которые ограничили доступ из определённых регионов. VPN-сервисы упоминаются как способ решения этой проблемы, не для обхода блокировок РКН. Контент сгенерирован ИИ.*

Некоторые зарубежные ИИ-сервисы ограничивают доступ из РФ по своей инициативе. Чтобы пользоваться их продуктами:

- **2-3 VPN-сервиса** на телефоне про запас — если один недоступен, переключиться
- Happ, Amnezia, собственный сервер (WireGuard/Outline)

## Оплата ИИ-сервисов из РФ

- **Иностранные карты** — самый надёжный вариант. Можно оформить через сервисы виртуальных карт
- **FunPay и подобные** — покупка аккаунтов/подписок. Аккаунты живут не всегда долго, есть риск бана
- **Крипта** — некоторые сервисы принимают напрямую

## Google из РФ

- **Новые учётки** Google банит при регистрации из РФ → разбан: написать с резервной почты (указывай при регистрации!)
- Для надёжности: платите с иностранной карты
- **NotebookLM** — есть MCP-клиент, нужна платная подписка Google (~700 руб через FunPay). Для старых аккаунтов — риск минимальный

## Apple / iCloud

- **Иностранный Apple ID** — можно создать бесплатно из РФ. SMS не всегда приходит сразу, но реально
- Переключаться только в App Store, **НЕ выходить из основного Apple ID в настройках телефона**
- На Mac: 99% софта можно скачать напрямую минуя App Store

## "Арбузный" формат

Для тех кто хочет максимум за минимум:

- Бесплатные аккаунты и абузы подписок через FunPay — работает, но аккаунты не вечные
- **OpenRouter** — один API-ключ, десятки моделей. Можно авторизоваться через все свои подписки
- DeepSeek — работает из РФ без VPN, бесплатный базовый доступ
- Gemini CLI — 1000 бесплатных запросов в день
