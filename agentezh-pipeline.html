Триггеры и контроль

⏰ Cron расписание

  • ezh-publish-loop: 10:00 / 14:00 / 17:00 MSK — основной двигатель, один тик = одно действие.
  • ezh-news-scan: 09:09 MSK — обновляет daily-ai-digest, добавляет идеи в post-queue.
  • ezh-morning-digest: 08:55 MSK — статус в твой DM.
  • ezh-bekaper: 19:05 MSK — бэкап.

🚦 Флаги (файлы в /root/.hermes/state/)

  • ezh_enable_publish — старый PUBLISH stage
  • ezh_enable_consilium — CONSILIUM
  • ezh_enable_design — DESIGN
  • ezh_enable_build — BUILD_DRAFT
  • ezh_publish_live — реальная публикация (без него dry-run)
  • ezh_tg_dry_run — TG calls идут в файлы

💾 Где что лежит

  • docs/post-drafts/*.yaml — все драфты (текущие 26)
  • docs/post-queue.md — backlog идей
  • docs/post-history.md — что опубликовано
  • content/images/*.png — все картинки
  • ezh_pipeline_state.json — daily spend + actions + stuck
  • schedule.json — очередь на публикацию
  • failures_log.md — что отклонил bulldog

🛑 Safety

  • Daily cost cap: $5/день, после — IDLE до следующего дня
  • flock: параллельные тики не запускаются
  • Anti-duplicate: post-history последние 90 дней, >70% overlap → skip
  • Stuck-detector: 3 FAIL подряд → draft помечен stuck
  • Loop-detector: 20+ одинаковых tool calls → kill
Жизненный путь одного поста (пример TaxHacker)
  1. 10:00 MSK — cron, BUILD_DRAFT → 2026-XX-taxhacker-v1.yaml со статусом ready-for-review. → 🔔 TG: «📝 новый драфт».
  2. 14:00 MSK — cron, CONSILIUM (3 критика, avg=8.5, bulldog PASS) → статус ready-for-publish. → 🔔 TG: «✅ avg 8.5».
  3. 17:00 MSK — cron, DESIGN → 3 картинки через Codex. → 🔔 TG: «🎨 3 картинки готовы».
  4. Ты заходишь в preview-site, видишь карточку, выбираешь v2, approve, ставишь время «завтра 10:00». Submit → schedule.json.
  5. Завтра 10:00 — cron, PUBLISH_SCHEDULED → sendPhoto в @agentezh. → 🔔 TG: «🚀 опубликовано msg #N».

От идеи до публикации ~3 cron-тика. Ты дотрагиваешься 1 раз на пост.

Что НЕ автомат — твои зоны
  • Добавление тем в backlog — docs/post-queue.md руками. Digest-сканер тоже подкидывает.
  • Approve/reject + выбор картинки — через preview-site. Без тебя система не публикует.
  • Правки текста — пока через CLI/Claude (preview-site пока не редактирует).
  • Editorial direction — что вообще публикуем. Хранится в memory + post-queue.
