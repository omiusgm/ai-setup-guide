Триггеры и контроль

⏰ Cron расписание

  • ezh-publish-loop: 10:00 / 14:00 / 17:00 MSK — основной двигатель, один тик = одно действие.
  • ezh-news-scan: 09:09 MSK — обновляет daily-ai-digest, добавляет идеи в post-queue.
  • ezh-morning-digest: 08:55 MSK — статус в твой DM.
  • ezh-bekaper: 19:05 MSK — бэкап.

🚦 Флаги (файлы в /root/.hermes/state/)

  • ezh_enable_publish — старый PUBLISH stage включён
  • ezh_enable_consilium — CONSILIUM включён
  • ezh_enable_design — DESIGN включён
  • ezh_enable_build — BUILD_DRAFT включён
  • ezh_publish_live — реальная публикация (без него только preview/dry-run)
  • ezh_tg_dry_run — TG calls идут в файлы вместо API

💾 Где что лежит

  • docs/post-drafts/*.yaml — все драфты (текущие 26)
  • docs/post-queue.md — backlog идей
  • docs/post-history.md — что опубликовано (для anti-dup)
  • content/images/*.png — все картинки
  • /root/.hermes/state/ezh_pipeline_state.json — daily spend + last actions + stuck_drafts
  • /root/.hermes/state/schedule.json — очередь на публикацию
  • .claude/agent-memory/copywriter/failures_log.md — что отклонил bulldog (Failure Alchemy)

🛑 Safety

  • Daily cost cap: $5/день, после — IDLE до следующего дня
  • flock: параллельные тики не запускаются
  • Anti-duplicate: BUILD_DRAFT и PUBLISH читают post-history последние 90 дней, >70% overlap → skip
  • Stuck-detector: 3 FAIL подряд → draft помечается stuck → пропускается
  • Loop-detector: 20+ одинаковых tool calls → kill сессии
Жизненный путь одного поста

Пример с TaxHacker (идея из бэклога с 25 апреля):

  1. 10:00 MSK — cron, pipeline видит TaxHacker без draft → запускает BUILD_DRAFT (~4 мин). Получает 2026-XX-XX-taxhacker-v1.yaml со статусом ready-for-review. → 🔔 TG: «📝 новый драфт».
  2. 14:00 MSK — cron, pipeline видит ready-for-review → CONSILIUM (~2 мин). 3 критика, avg=8.5, bulldog PASS → статус ready-for-publish. → 🔔 TG: «✅ avg 8.5».
  3. 17:00 MSK — cron, pipeline видит ready-for-publish без image_options → DESIGN (~8 мин). Designer subagent генерит 3 картинки через Codex. → 🔔 TG: «🎨 3 картинки готовы, открой preview».
  4. Ты заходишь в preview-site, видишь карточку, выбираешь v2, approve, ставишь время «завтра 10:00». Submit → запись в schedule.json.
  5. Завтра 10:00 MSK — cron, pipeline видит due-entry → PUBLISH_SCHEDULED → sendPhoto в @agentezh. → 🔔 TG: «🚀 опубликовано msg #N».

Итого: от идеи до публикации ~3 cron-тика (10/14/17), всё автоматически кроме твоего approve. Ты дотрагиваешься 1 раз на пост.

Что НЕ автомат — твои зоны
  • Добавление тем в backlog — docs/post-queue.md руками. Digest-сканер тоже подкидывает, но финальный отбор — твой.
  • Approve/reject + выбор картинки — через preview-site. Без тебя система не публикует (если ezh_publish_live снять, dry-run).
  • Правки текста — пока через CLI/Claude напрямую (preview-site не редактирует). В планах: textarea в карточке + кнопка «send rewrite» → новый CONSILIUM-цикл с твоим feedback.
  • Editorial direction — что вообще публикуем (китайские модели — нет, ChatGPT/Claude — да). Хранится в memory + post-queue.
