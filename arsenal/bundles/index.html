    📦 Готовые наборы¶

    🤖 Только для Claude Code

    Наборы скиллов ставятся в агента. Если ты в браузере — начни с готовых промптов.

    Можно собирать свою команду агентов руками. Один скилл скопировал с гитхаба, другой дописал сам, третий настроил под себя. Неделя возни — и у тебя 5 агентов.

    А можно скачать готовый набор где уже собраны 47 агентов, 181 скилл и 79 команд. Одна команда установки — и ты в бою.

    Почему ставить одно проще чем собирать¶

    Совместимость. Когда кто-то собрал 47 агентов вместе — они друг с другом уже работают. Одинаковые форматы, общие утилиты, проверено что не конфликтуют. Когда собираешь сам — пляшешь с бубном.

    Обновления одной командой. Один git pull — и у тебя свежие версии всего набора. В своей сборке надо обновлять каждый репозиторий отдельно, вспоминать какие версии совместимы.

    Покрытие задач. Один человек не догадается что ему нужен «агент-рецензент юридических текстов». В чужом наборе такой уже есть — на случай если пригодится. Не пригодится — не используешь, весу не добавляет.

    Готовые паттерны. В наборах часто уже собраны цепочки: автор → редактор → публикатор. Не надо думать как их связать — бери и используй.

    Бесплатная альтернатива¶

    Если не нужны десятки агентов — не ставь набор:

    Ручное копирование 2-3 скиллов

    Надо humanizer и article-writing — скопировал два файла из их репо в .claude/skills/. Всё. Не тащи 181 скилл если используешь 3.

    Один агент из чужого набора

    Понравился агент-редактор из Everything Claude Code — скопируй его .md себе в .claude/agents/. Остальные 46 не нужны.

    Свой CLAUDE.md вместо роутинга

    В наборах бывает «умный роутинг моделей» — сам решает Haiku/Sonnet/Opus. Это можно написать в CLAUDE.md в 10 строк: «Простое → Haiku. Сложное → Sonnet. Архитектура → Opus». Работает на 80% без наборов.

    Если фишек мало — готовые наборы¶

    • Everything Claude Code — 158K⭐, 47 агентов + 181 скилл + 79 команд
    • Oh My ClaudeCode — 29K⭐, 32 агента + умный роутинг моделей
    • GSD (Get Shit Done) — встроенный паттерн Claude Code, оркестрация проекта

    Как выбрать: - Хочешь всё и сразу → Everything Claude Code, скачиваешь — копируешь нужное - Экономия на моделях → Oh My ClaudeCode (сам решает когда Haiku, когда Opus) - Уже в Claude Code, нужен процесс → GSD (встроено, ничего ставить не надо)
