    🔌 Интеграции (MCP)¶

    🤖 Только для агентов

    MCP-подключения работают через Claude Code / Cursor. В чат-боте такого нет.

    ИИ из коробки умеет болтать. Но не умеет лазить в твой Gmail, обновлять CRM, читать базу. Он даже не знает что у тебя есть Gmail.

    Просишь: «проверь новые письма от клиентов». Он: «Я не могу получить доступ к вашей почте». И ты опять делаешь всё руками.

    Почему так происходит¶

    Языковая модель — это текст-на-входе, текст-на-выходе. Всё. Она не ходит в интернет, не открывает файлы, не дёргает API (способ подключения программ). Ей нужны руки — программные мостики между ней и миром.

    Эти мостики называются MCP (способ дать ИИ руки — подключить к сервисам). Аббревиатура не важна — важно что это переходники. Один MCP = доступ к одному сервису. Gmail MCP — и ИИ читает почту. Notion MCP — и ИИ создаёт страницы.

    Без MCP — ИИ болтун. С MCP — сотрудник.

    Бесплатные обходные пути¶

    До того как ставить MCP — попробуй то что уже работает:

    Копируй-вставляй

    Скопировал из Gmail → вставил в чат → «проанализируй». Медленно, но работает везде. Для разовых задач норм.

    Экспорт в CSV

    CRM, таблицы, базы — всё умеет в CSV. Экспортнул → загрузил файл в Claude/ChatGPT → получил анализ. Не надо никаких интеграций.

    Скриншоты

    Claude и ChatGPT видят изображения. Скрин экрана → «что здесь не так?». Работает для дашбордов, ошибок, интерфейсов.

    Автоматические уведомления в Telegram

    Если надо просто «получить уведомление» — Telegram Bot API даёт это бесплатно и без MCP. Три строки на Python.

    Плагины и расширения ChatGPT

    У ChatGPT есть коннекторы к Gmail, Drive, Calendar прямо в интерфейсе. Не такие гибкие как MCP, но для базовых задач работают.

    Если обходные пути не тянут¶

    • Firecrawl — 110K⭐ сбор данных с сайтов (копирует текст автоматом) для ИИ
    • Composio — 28K⭐, 1000+ готовых интеграций одной установкой
    • Docker MCP — 300+ плагинов в каталоге (Docker — программа-контейнер)
    • AmoCRM MCP — 36 инструментов для AmoCRM (родная русская)
    • n8n-MCP — 18K⭐ Claude управляет n8n workflows
    • :material-recursive: Claude Code MCP — 1.1K⭐ агент запускает другого агента
    • YouTube Insight — кидаешь ссылку на видео, ИИ смотрит и выжимает главное (бесплатно)

    Как выбрать: - Один конкретный сервис (Gmail, Slack, Notion) → ищи готовый MCP по названию - Много всего сразу → Composio (одна установка, 1000+ сервисов) - Сбор данных с сайтов → Firecrawl - Работаешь с Docker (программа-контейнер) → Docker MCP Toolkit
