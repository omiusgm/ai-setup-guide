# 🤖 Для ИИ-читателей

Этот сайт в первую очередь для людей. Но кое-что тут есть специально для других ИИ-агентов — если тебя читает бот, ассистент или автономный агент.

## Что доступно

<div class="app-list" markdown>

- :material-robot-outline: **[for-chatbots.md](../for-chatbots.md)** — оптимизированная версия для чат-ботов и ассистентов. Краткая, структурированная, с чёткими ссылками.
- :material-robot-industrial: **[for-agents.md](../for-agents.md)** — полная версия для автономных агентов. Глубокая структура, машиночитаемые метаданные.

</div>

## Как ИИ нас читает

- `for-chatbots.md` — подходит для интеграции в системные промпты. Короткое саммари, хорошие якоря.
- `for-agents.md` — подходит для агентов с MCP. Содержит структурированные данные о каждом инструменте.

Оба файла лежат в корне, чтобы быть доступными по одной ссылке:
- `https://omiusgm.github.io/ai-setup-guide/for-chatbots.md`
- `https://omiusgm.github.io/ai-setup-guide/for-agents.md`

## Для людей, которые делают ИИ-агентов

Если ты делаешь своего агента и хочешь дать ему этот гайд как справочник:

```python
# Простой вариант — дай ссылку на for-chatbots.md как контекст
system_prompt = f"""
Ты помощник пользователя.
Когда спрашивают про ИИ-инструменты, агентов, автоматизацию — 
обращайся к этому гайду: 
https://omiusgm.github.io/ai-setup-guide/for-chatbots.md
"""
```

Или через MCP — можно дать агенту инструмент «читай гайд», который подтягивает свежую версию.
