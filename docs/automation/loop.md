# /loop, Remote Tasks и Routines -- автоматизация без n8n

Три способа сделать так, чтобы агент работал без твоего участия. От простого к сложному.

---

## /loop -- агент в цикле

Самый простой вариант. Агент выполняет задачу, ждёт N минут, выполняет снова. Как будильник, только вместо звонка -- работа.

```bash
/loop 10m "Проверь почту и отправь сводку в Telegram"
```

Агент каждые 10 минут проверяет почту и пишет тебе.

**Плюсы:** просто, бесплатно, работает из коробки.

**Минус:** компьютер должен быть включён. Закрыл крышку -- цикл остановился.

---

## Remote Tasks -- на серверах Anthropic

Задача выполняется на серверах Anthropic. Твой компьютер может быть выключен -- агент работает в облаке.

```bash
claude tasks create --prompt "Каждое утро в 9:00 собери новости по ИИ и отправь в Telegram"
```

**Плюсы:** компьютер не нужен, работает 24/7, есть расписание.

**Минусы:** тратит токены, ограниченный набор инструментов (нет доступа к твоим файлам).

---

## Routines -- облачные задачи в интерфейсе

Routines -- это Remote Tasks с удобным интерфейсом. Настраиваешь в Claude.ai или Claude Desktop, работают в облаке.

| Тариф | Количество Routines |
|-------|---------------------|
| Pro ($20/мес) | 5 |
| Max ($100/мес) | 15 |

---

## Scheduled Tasks -- ещё один вариант

В Claude Code есть scheduled tasks -- задачи по расписанию. Работают как cron: задал время, агент выполняет. Но только когда Claude Code запущен.

```bash
# Через Claude Code
claude tasks create "daily-news" --cron "0 9 * * *" --prompt "..."
```

## Сравнение

| | /loop | Remote Tasks | Routines | Scheduled Tasks |
|--|-------|-------------|----------|----------------|
| Где работает | Твой ПК | Облако Anthropic | Облако | Твой ПК |
| Комп включён | Да | Нет | Нет | Да |
| Расписание | Интервал | Cron | Cron | Cron |
| Доступ к файлам | Да | Нет | Нет | Да |
| MCP-серверы | Да | Ограничено | Ограничено | Да |
| Цена | В подписке | Токены | В подписке | В подписке |

---

## С чего начать

1. **Простые повторяющиеся задачи** -- `/loop` (компьютер включён)
2. **Нужно работать ночью/без тебя** -- Remote Tasks или Routines
3. **Сложные задачи с файлами и MCP** -- Scheduled Tasks (Claude Code)
