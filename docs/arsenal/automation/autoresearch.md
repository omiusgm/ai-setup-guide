## Зачем это нужно

Карпати тренирует свою мини-модель nanochat и однажды устал руками гонять эксперименты «а что если LR такой / батч такой / архитектура такая». Это вечная боль ML-щика: гипотез десятки, рук две, ночи восемь часов.

Решение — натравить ИИ-агентов друг на друга. Один читает arxiv и Hacker News, второй формулирует гипотезу, третий запускает обучение, четвёртый смотрит на лосс и пишет вывод. Цикл крутится сам, ты приходишь утром к таблице результатов.

Это не «фреймворк для всех» — это рабочий код одного конкретного человека, который он не побрезговал выложить публично. Звёзды накапали потому, что Карпати, и потому что паттерн «агенты копят знания за ночь» применим далеко за пределами nanochat. Ёж ставит точку: пользы 73 тысяч звёзд тут не на 73 тысячи, но идея масштабируется на любой ресёрч-цикл.

## Чем НЕ является

- НЕ универсальный фреймворк — это код под nanochat-эксперименты Карпати
- НЕ no-code — Python, conda, видеокарта (хоть и одна)
- НЕ продакшн-решение — research prototype, ломается, надо чинить руками
- НЕ для тех кто не понимает что такое learning rate и зачем мерить лосс
- НЕ магия «загрузил и работает» — нужно адаптировать под свою задачу

## Что получаешь

- Готовый паттерн «агенты бегут эксперименты ночью» который можно содрать под себя
- Связку «читалка статей → генератор гипотез → запускатор → анализатор»
- Логи, графики, выводы в файлах (а не в чате — выживают между сессиями)
- Подсмотр того как Карпати лично проектирует автономные циклы
- Инспирацию: «а что если так же на мою задачу — копирайтинг, маркетплейсы, стратегия»

## Как поставить

```bash
# 1. Клонируешь
git clone https://github.com/karpathy/autoresearch
cd autoresearch

# 2. Зависимости
pip install -r requirements.txt

# 3. API-ключи в .env (Anthropic / OpenAI — что у тебя)
cp .env.example .env
nano .env

# 4. Запуск
python autoresearch.py
```

Дальше — читать README и адаптировать под свою задачу. Это не «pip install и побежало», это пример который копируешь и переделываешь.
