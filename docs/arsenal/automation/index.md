# ⚡ Арсенал: Автоматизация

!!! info "🤖 В основном для Claude Code"
    Хуки и агентные циклы — это про CLI. В браузере не запустишь.

Одноразовый запуск — это не автоматизация. Нажал `/run` один раз, получил результат, закрыл ноут — и всё опять надо делать руками завтра.

Настоящая автоматизация — когда оно само. Каждое утро в 9:00 собирает дайджест. После каждой правки — форматтер. После каждой задачи — тесты. Ты один раз настроил и забыл.

## Бесплатные фишки

**cron + shell-скрипт.** Если задача простая и ты на Linux/Mac — `cron` (встроенный планировщик) уже есть в системе. Пишешь скрипт, добавляешь в `crontab -e`, готово.

**Telegram Bot API напрямую.** Если надо «отправлять сообщения в канал» — не надо городить автоматизацию. Три строки на Python и всё.

**GitHub Actions.** Если код в гитхабе — Actions даёт расписание и триггеры из коробки. 2000 минут в месяц бесплатно.

**Scheduled tasks в Claude Code.** Встроенная штука — задачи которые Claude запускает по расписанию.
