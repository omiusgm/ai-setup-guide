# 🧠 Арсенал: Память

!!! info "🤖💬 В основном для Claude Code"
    Плагины памяти ставятся в агента. Для чата — длинный системный промпт с контекстом.

Claude забывает что ты делал 5 минут назад. Каждый новый чат — с нуля. Лечится через CLAUDE.md, HANDOFF.md, плагины памяти.

## Бесплатные фишки

**CLAUDE.md в корне проекта.** Claude Code читает этот файл автоматом каждый раз как заходишь в папку. Напиши туда кто ты, что за проект, как писать код.

**Файлы вместо чата.** Не храни контекст в переписке — храни в файлах. Задача → `task.md`, прогресс → `progress.md`, решения → `decisions.md`.

**HANDOFF.md в конце сессии.** Перед закрытием — пишешь сам «вот что сделали, вот что осталось». Читаешь в начале следующей.

**Команда /memory.** В Claude Code есть `/memory` — настраивает что помнить.

## Если фишек мало

- :material-database: **[claude-mem](claude-mem.md)** — 61.5K⭐ плагин памяти для Claude Code, альтернатива HandOff-паттерну (сам пишет, сам читает)

**Как выбрать:**
- Хочешь явный контроль → пиши HANDOFF.md руками
- Лень и работаешь в Claude Code каждый день → claude-mem
