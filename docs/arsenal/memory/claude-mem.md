# claude-mem

<div class="product-hero" markdown>

**Плагин памяти для Claude Code — альтернатива HandOff-паттерну**

Claude забывает между сессиями. Можно вручную вести `HANDOFF.md`, а можно поставить плагин: он сам пишет, сам читает, сам инжектит контекст в новую сессию. Сделан через официальный Claude Agent SDK, не самопал.

## Зачем это нужно

У Claude Code контекст одной сессии — большой, но конечный. Закрыл терминал, открыл завтра — он не помнит ничего из вчерашнего. Решений два:

1. **Руками вести HANDOFF.md** — пишешь сам в конце каждой сессии «вот что сделали, вот что осталось». Работает, бесплатно, но требует дисциплины.
2. **Поставить claude-mem** — плагин делает это автоматом. Ловит каждое действие, сжимает через ИИ, кладёт в базу, в новой сессии — подсовывает релевантные куски обратно.

Второй путь — для тех кто работает в Claude Code каждый день и устал писать саммари руками. 61 тысяча звёзд за день в пике — пик пришёлся на момент когда Claude Code набрал критическую массу пользователей с этой болью.

Антикритик: может работать неидеально (сжимает не то, инжектит не туда), и это твоя ответственность сверять результат с реальностью. Не доверяй слепо — сверяй.

## Чем НЕ является

- НЕ замена правильно написанному CLAUDE.md (он про правила проекта, плагин про историю действий)
- НЕ работает в браузере — только Claude Code CLI
- НЕ универсальная память для всех ИИ — заточен под Claude
- НЕ магия «всё помнит идеально» — сжимает с потерями, инжектит то что считает релевантным
- НЕ заменит HandOff если тебе важен явный контроль (зато claude-mem не требует ручной работы)

## Что получаешь

- Автоматическую запись всех действий сессии (без твоих усилий)
- Сжатие через AI (не сырые логи, а саммари)
- Инжект релевантного контекста в новые сессии
- Поиск по истории — «когда мы трогали этот файл и зачем»
- Альтернативу ручному HandOff-паттерну (см. [Handoff-паттерн](handoff-pattern.md))

## Как поставить

```bash
# Через встроенный плагин-менеджер Claude Code
claude plugin install claude-mem

# Проверка
claude plugin list | grep claude-mem
```

Дальше плагин работает сам — пишет в локальную базу, читает при старте новой сессии. Конфиг — в README репо.

## Кому подходит

- 🤖 Агент (Claude Code)
- Уровень: **опытным** (плагин-менеджер, понимание сессий, готовность к неточностям AI-сжатия)
- Задачи: длинные проекты, частая смена сессий, нежелание вести HANDOFF.md руками

## Совместимость

- Только Claude Code (не работает в Cursor / Codex / браузере)
- Из РФ работает (плагин-менеджер локальный, не блокируется)
- Лицензия: NOASSERTION (см. репо, там может быть кастомная)
