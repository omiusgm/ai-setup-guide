# 🤖 Арсенал: Агенты

!!! info "🤖 В основном CLI / десктоп"
    Агенты работают через терминал или приложение. Есть форки Claude Code — для тех кому нужна независимость от Anthropic.

Обычный чат — это пинг-понг. Ты спросил — он ответил — ты следующий вопрос. Агент — это когда ты говоришь «разберись с этим» и уходишь пить кофе. А он сам думает, сам кликает, сам пишет код.

## Бесплатные фишки до агентов

**Ролевой промпт.** «Ты — senior backend-разработчик. Действуй по шагам: план → структура БД → код → тесты». Срабатывает в обычном ChatGPT на 80% от того что даст настоящий агент.

**Chain-of-Thought.** Добавь «думай шаг за шагом» — модель начинает рассуждать структурно, меньше ошибается.

## Если промптов мало — форки Claude Code

После утечки исходников Claude Code появились open-source форки. Ставь если нужна независимость от Anthropic, доступ из РФ без платёжного моста, или хочешь покопаться во внутрянке.

- :material-source-fork: **[ruvnet/open-claude-code](open-claude-code-ruvnet.md)** — 191⭐ декомпилированный исходник Claude Code, MIT-лицензия
- :material-source-branch: **[Gitlawb/openclaude](openclaud-gitlawb.md)** — 22.3K⭐ форк с поддержкой 200+ моделей (DeepSeek, Gemini, OpenAI, Ollama)

**Как выбрать:**
- Хочешь изучить как устроен Claude Code изнутри → ruvnet (MIT, чище код)
- Хочешь работать из РФ через DeepSeek/Ollama без VPN → Gitlawb (200+ провайдеров)

!!! warning "Юридический нюанс"
    Оба — форки после утечки исходников. Юридически серая зона. Anthropic может прислать DMCA, репо снесут. Используй с пониманием рисков.
