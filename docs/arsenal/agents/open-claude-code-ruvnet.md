## Зачем это нужно

Официальный Claude Code — закрытый продукт Anthropic. Ты получаешь бинарник, не видишь как он работает внутри, не можешь поменять. Если завтра Anthropic решит «больше нельзя из РФ» — ты в пролёте.

Open-source форк решает три проблемы:
1. **Прозрачность** — видишь весь код, понимаешь что делает
2. **Кастомизация** — можешь переписать любую часть под себя
3. **Независимость** — если оригинал перестанет работать или изменит лицензию, у тебя есть копия

Минус — это форк после утечки. Юридически серая зона. Anthropic может прислать DMCA, репо снесут. Морально — ты пользуешься тем что не было выложено публично официально.

Ёж: 191 звезда — это нишевая штука для энтузиастов и тех кто принципиально хочет open-source. Большинству — официальный Claude Code хватит. Но если интересно «как это устроено внутри» или «хочу своё с такой же логикой» — посмотреть стоит.

## Чем НЕ является

- НЕ официальный продукт Anthropic — форк после утечки
- НЕ замена Claude Code для прода — экспериментальный, ломается
- НЕ legal-safe — юридически серая зона (DMCA-риск)
- НЕ для тех кто не понимает что такое декомпиляция
- НЕ единственный форк — есть [Gitlawb/openclaude](openclaud-gitlawb.md) и другие

## Что получаешь

- Декомпилированный исходник Claude Code (можно читать, изучать)
- Возможность собрать свой бинарник
- Понимание как Anthropic реализовал агентскую логику
- Платформу для своих экспериментов поверх
- Резерв на случай если оригинал перестанет работать

## Как поставить

```bash
# 1. Клонируешь
git clone https://github.com/ruvnet/open-claude-code
cd open-claude-code

# 2. Зависимости
npm install

# 3. Билд
npm run build

# 4. Запуск
./bin/open-claude
```

Подробности — в README, проект в активной разработке.

## Кому подходит

- 🤖 Агент (для тех кто понимает что делает)
- Уровень: **опытным** (JS/Node, понимание агентов, готовность к багам)
- Задачи: изучение внутрянки Claude Code, эксперименты, резерв на случай блокировки оригинала

## Совместимость

- Кросс-платформа (как Node.js)
- Из РФ работает (если есть API-ключ Anthropic — нужен платёжный мост)
- Лицензия: MIT (можно использовать как угодно — но это форк, см. дисклеймер про DMCA выше)
