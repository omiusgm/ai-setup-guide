## Зачем это нужно

Экосистема Claude Code растёт быстро. Каждую неделю кто-то выкатывает новый скилл, плагин, MCP-сервер. Уследить руками — нереально. Гуглить «лучший плагин для X» — половина результатов мёртвые репо.

Awesome-list решает: один человек (мейнтейнер) фильтрует, сортирует, держит в курсе. Ты приходишь раз в неделю, смотришь что нового, тащишь к себе. Это не магия — просто человек делает работу за тебя.

Минус — субъективность мейнтейнера. Что-то стоящее может не попасть, а что-то модное — попадёт. Ёж: бери как стартовую точку, не как истину в последней инстанции. Свои топ-5 ты всё равно соберёшь сам.

## Чем НЕ является

- НЕ инструмент — это README с ссылками
- НЕ полный список (мейнтейнер субъективен, что-то пропустит)
- НЕ актуален в реальном времени (обновляется по мере PR)
- НЕ замена этому гайду (тут на русском и с фильтром «без VPN, для РФ»)
- НЕ ставится как плагин — открываешь и читаешь
