# 📦 Арсенал: Готовые наборы

!!! info "🤖 Только для Claude Code"
    Наборы скиллов и агентов ставятся в CLI. В браузере — начни с готовых промптов.

Можно собирать свою команду агентов руками. Один скилл скопировал с гитхаба, другой дописал сам, третий настроил под себя. Неделя возни — и у тебя 5 агентов.

А можно скачать готовый набор где уже собраны десятки агентов и сотни скиллов. Одна команда установки — и ты в бою.

## Бесплатная альтернатива

**Ручное копирование 2-3 скиллов.** Надо humanizer и article-writing — скопировал два файла из чужого репо в `.claude/skills/`. Не тащи 181 скилл если используешь 3.

**Один агент из чужого набора.** Понравился агент-редактор — скопируй его `.md` себе в `.claude/agents/`. Остальные не нужны.
