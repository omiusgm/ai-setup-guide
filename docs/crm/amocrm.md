# ИИ-агент для CRM: AmoCRM + Битрикс24

Пошаговое подключение ИИ к CRM-системе. Кейс: +22% конверсия, 4 часа/день экономии для РОПа (SaleKit, дистрибьютор, 12 менеджеров, апрель 2026).

---

## Что умеет ИИ-агент для CRM

**Утренний брифинг (8:30 в Telegram):** новые сделки, просрочки, топ-3 сделки которые вот-вот закроются, конверсия vs прошлая неделя. Экономия ~60 мин/день.

**Мониторинг зависших сделок (каждые 2 часа):** сделка без движения > 48ч -- алерт, лид без первого контакта > 24ч -- напоминание. Снижение забытых сделок на 90%. Экономия ~1-2 часа/день.

**Еженедельный отчёт:** рейтинг менеджеров (конверсия, средний чек, скорость), узкие места воронки, прогноз выполнения плана.

**Анализ проигранных сделок (ежемесячно):** категоризация причин потерь, паттерны по этапам и менеджерам, тренды.

**Прогноз выручки:** взвешенный pipeline-прогноз на основе исторических конверсий и текущих сделок.

## Как подключить: пошагово

### Шаг 1: Получи API-ключ AmoCRM

Настройки --> Интеграции --> Ключи --> создать приватную интеграцию --> скопировать Long-lived Token. Этот токен бессрочный, подходит для одного аккаунта. Храни как пароль -- не свети в чатах.

### Шаг 2: Выбери способ подключения

**Вариант А: n8n (рекомендуемый для не-программистов)**

Визуальный конструктор. Собираешь цепочку: таймер (8:30) --> запрос в AmoCRM --> ИИ анализирует --> Telegram отправляет.

- Хостинг: [Beget](https://beget.com) от 210 руб/мес (готовый образ n8n, локация Москва)
- Нода для AmoCRM: `n8n-nodes-amocrm` (Settings --> Community Nodes)
- ИИ: нативный нод Anthropic Chat Model или DeepSeek через HTTP
- Вывод: Telegram Bot нода (встроенная)
- Срок запуска: 2-3 дня (даже без опыта)

**Вариант Б: MCP-подключение (для пользователей Claude Desktop/Code)**

ИИ-агент подключается к AmoCRM напрямую. Можно спросить в чате: "Покажи все сделки которые зависли больше 5 дней" и получить ответ.

- [cAIborg-ai/amocrm-mcp](https://github.com/cAIborg-ai/amocrm-mcp) -- 36 инструментов, OAuth, rate-limiting из коробки (рекомендуем)
- [ampulex-23/KommoMCP](https://github.com/ampulex-23/KommoMCP) -- 54 инструмента, AI-коучинг, прогнозирование, геймификация (максимум функций)
- Установка: `pip install -e .` + указать AMO_SUBDOMAIN и AMO_ACCESS_TOKEN

**Гибридная стратегия (лучший вариант):** n8n для автоматических отчётов по расписанию + MCP-подключение для разовых запросов в чате.

### Шаг 3: Настрой первый сценарий

Начни с утреннего брифинга -- он простой и сразу показывает ценность:

1. Schedule Trigger --> каждый день 8:30
2. HTTP Request --> `GET https://{subdomain}.amocrm.ru/api/v4/leads` (фильтр по updated_at за вчера)
3. HTTP Request --> `GET /api/v4/tasks` (просроченные: is_completed=0)
4. Code Node --> собрать данные в один текст
5. Anthropic Chat Model --> "Проанализируй данные и сформируй брифинг для РОПа"
6. Telegram Bot --> отправить в чат/канал

### Шаг 4: Первая неделя -- проверяй

ИИ может галлюцинировать цифры. Первые 7 дней сверяй отчёты с реальными данными в CRM. После калибровки -- можно доверять.

## Битрикс24

REST API Битрикса работает аналогично AmoCRM API -- те же принципы: получаешь токен, дёргаешь эндпоинты, отдаёшь данные ИИ на анализ. Можно подключить через n8n + ИИ по той же схеме что и AmoCRM выше.

Готовых MCP-серверов для Битрикс пока нет, но REST API позволяет делать всё то же самое: сделки, контакты, задачи, воронки. Просто через HTTP-запросы в n8n вместо MCP.

[REST API Битрикс24](https://dev.1c-bitrix.ru/rest_help/)
