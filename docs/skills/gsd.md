# Get Shit Done -- оркестрация проекта

Скилл для тех, кто хочет не просто "задай вопрос ИИ", а "ИИ, сделай мне проект от и до". GSD превращает Claude Code из помощника в проектного менеджера: план, задачи, исполнение, контроль.

---

## Что делает

1. **Разбивает задачу на шаги** -- ты говоришь "сделай мне лендинг для курса", а он создаёт план из 15 подзадач
2. **Выполняет по очереди** -- каждую подзадачу делает сам, проверяет результат, двигается дальше
3. **Спрашивает когда надо** -- если нужно решение (дизайн, текст, бюджет) -- спросит, а не придумает сам
4. **Документирует** -- пишет что сделано, что осталось, какие решения приняты

---

## Как включить

GSD встроен в Claude Code (не нужно ставить отдельно). Просто опиши задачу достаточно подробно:

```
Создай Telegram-бота для записи на стрижку.
Стек: Python + aiogram + Supabase.
Функции: выбор мастера, выбор времени, подтверждение.
```

Claude Code сам создаст план, разобьёт на файлы, напишет код, протестирует.

---

## Когда использовать

- Новый проект с нуля (бот, сайт, автоматизация)
- Рефакторинг существующего проекта
- Миграция (перенести с одного стека на другой)
- Любая задача где шагов больше пяти

---

## Советы

- **Давай контекст** -- чем подробнее опишешь задачу, тем меньше будет переделок
- **Не мешай** -- если план выглядит разумным, дай агенту работать. Микроменеджмент замедляет
- **Проверяй контрольные точки** -- после каждого крупного блока смотри результат
- **CLAUDE.md -- твой друг** -- запиши туда архитектуру, стек, ограничения. Агент будет читать при каждом запуске

---

## GSD + субагенты

В сложных проектах GSD может порождать субагентов -- параллельные потоки, каждый делает свою часть. Один пишет фронтенд, другой -- бэкенд, третий -- тесты. Оркестратор собирает всё вместе.
