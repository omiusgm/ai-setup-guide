# Humanizer -- убирает следы ИИ из текста

ИИ пишет узнаваемо. "Конечно!", "Безусловно", "Давайте рассмотрим", "В заключение хочется отметить" -- эти маркеры видны невооружённым глазом. Humanizer находит и убирает их.

---

## Зачем

- Текст не палится как ИИ-сгенерированный
- Проходит детекторы ИИ-текста (GPTZero, Originality.ai)
- Звучит как написанный живым человеком, а не роботом

---

## Что именно убирает

| Маркер ИИ | Пример |
|-----------|--------|
| Восторженные вступления | "Отличный вопрос!" |
| Канцелярит | "В рамках данного контекста" |
| Шаблонные переходы | "Давайте рассмотрим", "Стоит отметить" |
| Избыточная вежливость | "Я буду рад помочь вам с этим" |
| Перечисления ради перечислений | Списки из 5+ пунктов на каждый чих |
| Подытоживание | "Подводя итог", "В заключение" |

---

## Для агентов (Claude Code)

Скилл встроен в Claude Code. Используй команду:

```
/humanizer
```

Или попроси агента: "Перепиши этот текст, убери следы ИИ".

---

## Для чата (ChatGPT, Claude, DeepSeek)

Добавь в промпт:

```
Перепиши текст. Правила:
1. Убери все маркеры ИИ-текста (вступления, "конечно", "давайте рассмотрим")
2. Замени канцелярит на разговорный язык
3. Убери избыточные списки -- оставь прозу
4. Не подытоживай в конце
5. Добавь 1-2 разговорных оборота
6. Длина ответа = длина оригинала, не раздувай
```

---

## Важно

Humanizer не делает текст хуже -- он делает его естественнее. Суть, факты, структура сохраняются. Меняется только стилистика -- из "робот отвечает" в "человек объясняет".
