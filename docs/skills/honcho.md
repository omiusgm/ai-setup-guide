# Honcho -- внешняя память с reasoning

ИИ забывает всё между сессиями. Honcho решает это -- внешняя память, которая не просто хранит факты, а думает о них. Агент запоминает контекст, паттерны и предпочтения между чатами.

[honcho.dev](https://honcho.dev)

---

## Проблема

Открыл новый чат -- ИИ не помнит прошлый разговор. Объясняешь контекст заново. Каждый. Раз.

Встроенная память (Auto Memory в Claude) помогает, но ограничена: запоминает факты, но не рассуждает о них.

---

## Что делает Honcho

- **Запоминает между сессиями** -- что обсуждали, какие решения приняли, что сработало
- **Reasoning над памятью** -- не просто "факт X", а "пользователь предпочитает Y потому что Z"
- **Кросс-сессионный контекст** -- агент знает историю работы с тобой

---

## Установка

```
npx skills add plastic-labs/honcho
```

После установки агент автоматически сохраняет и подгружает контекст между сессиями.

---

## Когда это нужно

- Работаешь с агентом над проектом неделями -- чтобы не объяснять контекст заново
- Несколько агентов работают с одним проектом -- общая память
- Хочешь чтобы агент учился твоим предпочтениям (стиль кода, тон текста, предпочтения)

---

## Honcho vs CLAUDE.md

| | CLAUDE.md | Honcho |
|--|-----------|--------|
| Где хранится | Файл в проекте | Внешний сервис |
| Кто обновляет | Ты руками | Агент автоматически |
| Что хранит | Инструкции, архитектура | Паттерны, предпочтения, контекст |
| Reasoning | Нет | Да -- думает о запомненном |

Они не конкуренты -- дополняют друг друга. CLAUDE.md для жёстких правил проекта, Honcho для мягкого контекста и обучения.
