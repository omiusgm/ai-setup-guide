# Remotion -- видео через код

Видео без After Effects, без Premiere. Пишешь код (React) -- получаешь видео. Звучит дико, но 42K звёзд на GitHub говорят что людям зашло.

[Репозиторий](https://github.com/remotion-dev/remotion) (42K stars)

---

## Зачем это нужно

- **Шаблонные видео** -- отчёты, дашборды, визуализации данных. Один раз настроил -- генерируешь сотни
- **Динамический контент** -- подставляешь данные из API, и видео обновляется само
- **Без ручного монтажа** -- код = воспроизводимый результат. Не "подвинь тут на 2 пикселя"

---

## Как это работает

Remotion использует React для описания кадров. Каждый кадр -- это React-компонент. Агент пишет компоненты, Remotion рендерит в видео.

```
npx skills add remotion-dev/skills
```

После установки агент может:

- Создавать видео по описанию
- Менять текст, цвета, анимации через параметры
- Рендерить в MP4, GIF, PNG-последовательности

---

## Примеры

- Еженедельный видео-отчёт для команды (данные из Google Sheets)
- Анимированные карточки товаров для маркетплейса
- Визуализация статистики канала
- Intro/outro для YouTube

---

## Ограничения

- Нужно понимать React (или иметь агента который понимает)
- Рендер тяжёлых видео занимает время
- Не замена полноценному видеомонтажу -- это для программного создания видео
