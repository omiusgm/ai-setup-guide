# 🟢 Ты не кодишь — начни здесь

Тебе говорят «ИИ может всё», а ты видишь терминал, github, MCP — и закрываешь вкладку. Знакомо? Эта страница — для тебя.

Всё что тут написано работает БЕЗ кода. В браузере. С телефона. Из РФ без VPN.

## Что тебе нужно по минимуму

### 1. Выбери один чат-ИИ

Работают из РФ без VPN:

- **[DeepSeek](../apps/infra/deepseek.md)** — чат как ChatGPT, бесплатно, регистрация на email. Модель сильная, для русского хорошая.
- **YandexGPT** — встроен в Алису, в поиске. Самый безопасный способ для начала.
- **GigaChat** — от Сбера. Работает, но послабее DeepSeek.

**Совет:** начни с DeepSeek. Бесплатно, без лимитов, русский отличный.

### 2. Разберись как писать запросы (промпты)

Три правила, от которых толк в 80% случаев:

**Правило 1. Говори кто ты и кто он.**

Плохо:
```
напиши пост про кофейню
```

Хорошо:
```
Ты SMM-специалист с 5-летним опытом. 
Я владелица кофейни в Москве (средний чек 600 руб, ЦА — молодёжь 20-35).
Напиши пост для инстаграм о новом сезонном меню.
```

**Правило 2. Дай контекст и пример.**

Плохо:
```
напиши письмо клиенту
```

Хорошо:
```
Напиши письмо клиенту, который не отвечает 2 недели.
Контекст: договорились о встрече, он пропал.
Тон: дружелюбный, без давления.
Длина: 3-4 предложения.
Пример стиля, который мне нравится: 
"Привет! Помню, договаривались созвониться. Если ещё актуально — скажи, когда удобно. Если нет — тоже норм, просто чтобы я не писал впустую."
```

**Правило 3. Скажи что НЕ делать.**

Добавляй в конце:
- «Не используй слова: конечно, отличный, давайте рассмотрим»
- «Без длинных вводных, сразу суть»
- «Пиши как живой человек, не как бот»

## Готовые шаблоны

Скопируй — вставь в чат — подставь свои данные.

### Пост в инстаграм / телеграм

??? example "Шаблон"
    ```
    Ты опытный SMM. Напиши пост для моего Instagram.

    Обо мне: [кто ты, чем занимаешься]
    Аудитория: [кто читает]
    О чём пост: [тема]
    Цель поста: [продать / развлечь / обучить]
    Тон: [дружелюбный / деловой / провокационный]
    Длина: [короткий / средний / длинный]

    Добавь 3-5 хештегов в конце.
    Не используй канцелярит, «давайте рассмотрим», «отличный вопрос».
    ```

### Деловое письмо

??? example "Шаблон"
    ```
    Напиши деловое письмо.
    
    От меня: [имя, должность, компания]
    Получатель: [имя, должность, компания, ваши отношения]
    Повод: [зачем пишешь]
    Главная цель: [что хочешь получить]
    Длина: не больше 5 предложений
    
    Тон: вежливый, уверенный, без заискиваний.
    ```

### План на день / неделю

??? example "Шаблон"
    ```
    Ты опытный коуч по продуктивности. Помоги спланировать день.
    
    Мои задачи:
    - [задача 1]
    - [задача 2]
    - [задача 3]
    
    Встречи:
    - [встреча 1 во сколько]
    
    Важно: [что не должно пропасть]
    
    Сделай расписание с 9:00 до 19:00.
    Оставь буфер на непредвиденное.
    Выдели 30 минут на обед.
    Напиши простым списком, без таблиц.
    ```

### Ответ клиенту

??? example "Шаблон"
    ```
    Помоги ответить клиенту.
    
    Он написал: [скопируй его сообщение]
    
    Ситуация: [контекст — что было до]
    
    Что я хочу: [цель ответа]
    Чего не хочу: [обещать скидку / оправдываться / и т.д.]
    
    Тон: [какой]
    Длина: короткий, не больше 3 абзацев.
    ```

## Три ошибки новичков

**1. Слишком короткий промпт.** «Напиши пост» — ИИ пишет абстракцию. Дай контекст: кто, о чём, для кого.

**2. Не проверяешь факты.** ИИ иногда врёт. Любые цифры, имена, даты — проверяй.

**3. Принимаешь первый ответ.** ИИ даст средненький вариант по умолчанию. Нажми «сделай короче», «более разговорно», «добавь иронии» — 2-3 итерации и ответ в разы лучше.
