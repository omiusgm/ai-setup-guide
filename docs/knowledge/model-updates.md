## Claude Opus 4.7 (вышел 16 апреля 2026)

Самая мощная модель Anthropic на момент написания. Работает в Claude.ai (интерфейс чата), API, Claude Code.

### Что реально изменилось

**Визуал стал прорывом.** С 54.5% до 98.5% на тесте visual navigation. Разрешение изображений выросло с 1.15 до 3.75 мегапикселей. На практике — кидаешь скриншот личного кабинета Wildberries, Ozon, 1С, CRM — читает таблицы, цифры, даже серый текст на сером фоне. Раньше было «я вижу таблицу», теперь — конкретные числа.

**Код улучшился.** SWE-bench Verified поднялся с 80.8% до 87.6%. В реальных задачах — меньше переделок, реже «создаёт класс когда просил функцию».

**Появилась команда `/ultrareview` в Claude Code.** Запускает параллельно четырёх специализированных агентов (безопасность, логика, производительность, стиль) и синтезирует единый отчёт по коду. Pro и Max-подписчики получают 3 бесплатных прогона в месяц.

### Важно: тихое подорожание на 35%

Цена за токен осталась прежней — $5 за миллион входных, $25 за выходные. Но **новый токенизатор режет текст мельче**. Тот же самый текст теперь содержит на 30-35% больше токенов.

На практике:
- Задача, стоившая 100 рублей — теперь 130-135
- Max-план ($200/мес) будет расходоваться быстрее

Формально Anthropic цены не повышал. Фактически — повышение есть, просто без объявления.

### Конспирология сообщества

На Reddit и Hacker News обсуждают: «это не новая модель, это 4.6 которого перестали придушивать». Разработчица AMD Стелла Лауренцо проанализировала 6852 своих сессий с Claude Code за февраль-март 2026. Выводы:
- Глубина размышлений модели упала с 2200 до 600 символов (минус 73%)
- Файлов читала 6 перед правкой — стала читать 2
- 80% недельного лимита Max-плана ($200/мес) сгорало впустую за 2.5 дня

Вывод сообщества — Anthropic сам «прикрутил» 4.6 в марте, а теперь подаёт «исходное состояние» как новую версию.

Мы не берёмся подтверждать или опровергать эту теорию. Но факт остаётся: те, кто жаловался на деградацию 4.6 в марте, сейчас говорят, что 4.7 ведёт себя как «старый добрый 4.6». Что думать — решай сам.

### Что делать

- **Если пользуешься через браузер (Claude.ai, ChatGPT-подобные):** ничего делать не надо, обновление прилетает само. Просто заметишь что ответы на сложных задачах стали чище, скриншоты читает точнее.
- **Если сидишь в Claude Code (терминал):** переключись на 4.7, попробуй `/ultrareview`, посмотри подходит ли.
- **Если считаешь каждый рубль:** пересмотри бюджет. Тот же промпт теперь дороже на ~30%.
- **Если Max-план кончается быстрее нужного:** поставь [Oh-My-ClaudeCode](../apps/agents/sisyphus.md) — smart-routing моделей экономит 40-70% токенов.

## Что изменилось в Claude Code

### Автоматический режим (Automode)

Флаг `--dangerously-skip-permissions` стал надёжнее. Раньше агент часто «застревал» или делал много лишних шагов. В 4.7 работает заметно точнее. Для длинных ночных задач (пока ты спишь) — теперь реально полезен.

### `/ultrareview` — мульти-агент ревью

Запускаешь после крупной работы — четыре агента параллельно смотрят твой код:
- **Security** — ищет уязвимости, утечки, проблемы с аутентификацией
- **Logic** — логические баги, edge cases, битая обработка ошибок
- **Performance** — узкие места, лишние запросы, неэффективные алгоритмы
- **Style** — читаемость, следование конвенциям проекта

В конце синтезирует один отчёт. Лучше чем один проход — ловит то что один пропускает.

### Новый уровень усилий: `xhigh`

Появился средний между `high` и `max`. Лучшее соотношение качества и токенов чем `max`. Тратит больше чем `high`, но результат стабильнее. Для задач где важна точность — попробуй, может заменить `max` по цене/качеству.

## GPT-5.4 (вышел в марте 2026)

Главный конкурент Opus 4.7. По бенчмаркам:
- **Opus лучше** на SWE-bench Pro (64.3% vs 57.7%) — реальные задачи разработки
- **GPT лучше** на Terminal-Bench — консольные задачи и shell-скрипты
- **Примерно равны** на обычных задачах рассуждения

Практический вывод: для кода — Claude стабильно выше. Для браузерных агентов и поисковых задач — GPT чуть впереди. Если пользуешься обоими — нормально.

## Mythos (закрытая модель Anthropic)

Упоминается во всех пресс-релизах про Opus 4.7 как бенчмарк сравнения. Что известно:
- SWE-bench 93.9% (выше чем у Opus 4.7)
- Умеет автономно находить zero-day уязвимости
- **Публично недоступна** — только для партнёров в области defensive cybersecurity через Project Glasswing

Парадокс: Anthropic в каждом анонсе 4.7 сравнивает с Mythos — моделью которую никто из пользователей не увидит. Gizmodo саркастически: «bold strategy to promote your new release as less capable than options no one can access».

Для практики — не наша тема. Но знать полезно, чтобы понимать контекст анонсов.
