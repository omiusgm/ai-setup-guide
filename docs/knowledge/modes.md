# 3 режима Claude -- Chat, Cowork, Code

Claude -- не одна программа, а три. Точнее -- три режима для разных задач. Как молоток, отвёртка и дрель -- каждый для своего.

---

## Chat -- для думания

**claude.ai** в браузере или приложение Claude Desktop.

Когда использовать:

- Обсудить идею, покрутить стратегию
- Написать текст, письмо, пост
- Проанализировать документ
- Спросить "а что если..."

Это как разговор с умным коллегой. Ты спрашиваешь -- он отвечает. Файлы можно прикреплять, но ИИ не может ничего делать на твоём компьютере.

---

## Cowork -- для делания (не код)

**Claude Desktop + MCP-серверы** (способ дать ИИ руки — подключить к сервисам) или **Claude Code в Cowork mode**.

Когда использовать:

- Автоматизировать рутину: разобрать почту, обновить таблицу, собрать данные
- Работать с файлами: переименовать 100 фоток, разложить документы по папкам
- Подключить сервисы: Notion, Google Sheets, Telegram

Разница с Chat: здесь ИИ не просто советует, а делает. Подключаешь MCP-серверы -- и он получает руки. Может сам открыть Notion, записать туда данные, отправить сообщение в Telegram.

---

## Code -- для строительства

**Claude Code** в терминале (чёрное окно с командами).

Когда использовать:

- Создать сайт, бота, приложение
- Настроить автоматизацию с нуля
- Управлять сервером, базой данных
- Работать с Git, деплоить проект

Это полноценный агент-разработчик. Видит весь проект, пишет код, запускает команды, коммитит в Git. Может порождать подагентов (субагенты для параллельных задач), работать с MCP-серверами (подключениями к сервисам), и вообще делать почти всё что делает программист.

---

## Как выбрать

| Задача | Режим |
|--------|-------|
| "Напиши мне текст для рассылки" | Chat |
| "Разбери мои файлы по папкам" | Cowork |
| "Сделай мне лендинг" | Code |
| "Помоги разобраться в теме" | Chat |
| "Отправь отчёт в Notion каждый день" | Cowork / Code |
| "Настрой CI/CD для проекта" | Code |

---

## Можно переключаться

Не обязательно выбирать один режим навсегда. Chat -- для размышлений утром, Cowork -- для рутины днём, Code -- для проектов вечером. Подписка одна ($20 Pro или $100 Max), все три режима включены.
