# 4 уровня ИИ -- от чатбота до IDE

Не все ИИ одинаковые. Есть разница между "поболтать с ChatGPT" и "агент пишет код за тебя". Вот 4 уровня -- от простого к сложному.

---

## Уровень 1: Чатбот в браузере

ChatGPT, Claude.ai, DeepSeek, Gemini -- открыл вкладку, написал вопрос, получил ответ. Это как спросить умного друга в мессенджере. Он знает много, но не может ничего сделать на твоём компьютере.

**Что может:** писать тексты, отвечать на вопросы, анализировать документы, генерить картинки.

**Что НЕ может:** открыть файл, создать папку, запустить программу, зайти на сайт за тебя.

---

## Уровень 2: Агент на компьютере

Claude Desktop, ChatGPT Desktop, Copilot -- приложение на ПК. Через MCP-серверы (способ дать ИИ руки — подключить к сервисам) видит файлы, гуглит, подключается к сервисам.

**Что может:** всё из уровня 1 + работать с файлами, искать в интернете, подключаться к Notion/Slack/Gmail.

**Что НЕ может:** писать код в терминале (чёрное окно с командами), управлять Git, запускать сборку проекта.

---

## Уровень 3: Терминал / CLI

Claude Code, Gemini CLI, Codex CLI -- агент в командной строке (терминал — чёрное окно с командами). Видит весь проект, может создавать файлы, коммитить в Git, запускать тесты.

**Что может:** всё из уровня 2 + писать и запускать код, работать с Git, ставить пакеты, деплоить.

**Нюанс:** нужен терминал. На Windows -- через WSL или PowerShell. На Mac/Linux -- из коробки.

---

## Уровень 4: IDE

Cursor, VS Code + Claude, Windsurf -- агент встроен в редактор кода. Видит файлы, подсвечивает ошибки, предлагает исправления прямо в коде.

**Что может:** всё из уровня 3 + визуальная навигация по проекту, Tab-подсказки, дифф-вью правок.

---

## Сравнение

| | Чатбот | Агент ПК | Терминал | IDE |
|--|--------|----------|----------|-----|
| Текст / вопросы | + | + | + | + |
| Файлы на диске | - | + | + | + |
| MCP-серверы | - | + | + | + |
| Git / код | - | - | + | + |
| Визуальный редактор | - | - | - | + |
| Порог входа | Ноль | Низкий | Средний | Средний |
| Цена от | $0 | $0 | $20/мес | $0-20/мес |

---

## С чего начать

- **Не кодишь вообще** -- начни с уровня 1 (ChatGPT/Claude в браузере). Когда упрёшься в лимиты -- двигайся на уровень 2.
- **Хочешь автоматизацию** -- уровень 2 (Claude Desktop + MCP).
- **Хочешь делать проекты** -- уровень 3 (Claude Code).
- **Уже кодишь** -- уровень 4 (Cursor или VS Code).
