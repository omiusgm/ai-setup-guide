# 🏪 Кейс РОПа: ИИ-помощник для руководителя отдела продаж

> Реальный кейс: РОП в B2B-компании построил себе ИИ-помощника за вечер. Утром получает сводку по отделу. Ищет забытых клиентов. Пишет follow-up. Всё через Claude Code + AmoCRM MCP.

## Ситуация

РОП. Отдел из 8 менеджеров. AmoCRM забит, но никто не смотрит отчёты. Каждое утро идут в бой без понимания: что в воронке, кто что закрыл, кого теряем.

На сбор сводки по отделу уходило 40-60 минут каждый день. Результат — отчёт, который никто не читает.

## Решение

Связка:

- **Claude Code** — мозг, который общается голосом и текстом
- **[AmoCRM MCP](../../apps/integrations/amocrm-mcp.md)** — даёт Claude прямой доступ к CRM (36 инструментов)
- **Wahelp** — отправка результатов в WhatsApp (то, что реально читают менеджеры)

## Что умеет

### Утренняя сводка

Промпт в Claude:

```
Собери сводку по отделу продаж за вчера:
- Сколько новых лидов, от какого менеджера
- Сколько сделок сдвинулось, кем, на какую сумму
- Сделки >500К: статус каждой
- Лиды без активности >3 дней — список

Формат: короткими буллетами, без воды.
Отправь в WhatsApp РОПу через Wahelp.
```

Claude:
1. Через AmoCRM MCP собирает данные
2. Анализирует
3. Пишет сводку на 15 строк
4. Отправляет через Wahelp

Утро начинается с готовой карты отдела в телефоне.

### Поиск забытых клиентов

```
Найди в AmoCRM всех клиентов на этапе «Переговоры» без активности >7 дней.
Для каждого проверь:
- Сумма сделки
- Кто менеджер
- Последнее касание (звонок/письмо)

Топ-10 по сумме сформируй с рекомендациями follow-up.
```

Раз в неделю — список из 10 самых дорогих «забытых». С готовыми текстами follow-up.

### Отчёт по менеджеру

```
Проанализируй менеджера Петрова за последние 2 недели:
- Закрытые сделки (суммы и клиенты)
- Упущенные сделки (причины)
- Активность: звонки, письма
- Скрытые паттерны: когда он хорошо работает / когда плохо

Напиши как коучинг-встречу — вопросы которые я ему должен задать.
```

РОП приходит на 1-on-1 не с пустой головой, а с конкретными вопросами.

## Что понадобилось

### Технически

1. **Claude Pro** — $20/мес
2. **AmoCRM MCP** — [GitHub](https://github.com/cAIborg-ai/amocrm-mcp), бесплатно
3. **Wahelp** — отправка в WhatsApp, от 500 руб/мес
4. **Токен AmoCRM** — получить в админке CRM (Настройки → Интеграции → API)

### По времени

- Установка Claude Code: 15 минут
- Подключение AmoCRM MCP: 30 минут (нужно разобраться с токеном)
- Настройка Wahelp: 20 минут
- Написание промптов: 1 час

**Итого: вечер.**

## Что получилось в цифрах

- Сбор утренней сводки: **40-60 минут → 3 минуты** (Claude работает сам)
- «Забытые» клиенты: было 20-30 висящих → стало ~5 (фильтр работает раз в неделю)
- Доход отдела: +12% за 2 месяца (из-за проактивной работы с «забытыми»)

## Нюансы

- Токен AmoCRM даёт много прав — храни в `.env`, не в коде
- Claude иногда неправильно интерпретирует воронки — сверь первые отчёты руками
- Wahelp отправляет через API WhatsApp — для массовых рассылок лучше другой тариф

## Как повторить

1. [Установи Claude Code](https://claude.com/claude-code)
2. [Подключи AmoCRM MCP](../../apps/integrations/amocrm-mcp.md) — там пошагово
3. Возьми промпты сверху, адаптируй под свою воронку
4. Начни с утренней сводки — это самое простое и полезное
