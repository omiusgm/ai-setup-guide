# 📸 Кейс SMM: 50 карточек WB за 35 минут

> SMM-щица делала карточки для Wildberries руками — 2 часа на штуку. С ИИ-связкой — 50 штук за вечер. Как это устроено.

## Ситуация

Интернет-магазин на Wildberries. 50 новых товаров — одежда. Нужны карточки:
- Инфографика на главное фото (название, ключевая фишка)
- Детали (состав, размер, уход)
- Блок «с чем носить»
- Финальный слайд CTA

Руками (Photoshop, Figma) — 1.5-2 часа на карточку. 50 товаров = **5 рабочих дней**.

SMM-щица загуглила «как ускорить», попала в Telegram-канал, попробовала связку. Сделала за вечер.

## Решение

Связка:

1. **ChatGPT** (можно и DeepSeek) — генерация текстов
2. **Midjourney** (можно и Flux) — генерация изображений фона
3. **Canva** — сборка карточек с шаблоном

## Процесс

### Шаг 1. Генерация текстов (7 минут на 50 товаров)

Промпт:

```
Я SMM в интернет-магазине одежды на WB.
Мне нужно для 50 товаров сгенерировать текстовые блоки 
в едином стиле для карточек.

Вот список:
1. Платье из шифона, синее, размеры XS-XL, состав 100% полиэстер
2. Джинсы mom-fit, чёрные, размеры 26-32, 95% хлопок + 5% эластан
... [и так далее 50 позиций]

Для каждого товара дай:
- Название для главного слайда (2-4 слова, цепляющее)
- Ключевая фишка (1 короткая фраза)
- Состав кратко
- Размеры
- «С чем носить» — 3 варианта образа
- CTA для финального слайда

Формат: таблица в Markdown, колонки по пунктам выше.
Стиль текста: дружелюбный, но не слащавый. Без «Дорогая подружка» и «Побалуй себя».
```

ChatGPT выдаёт таблицу за 2 минуты. Ещё 5 минут — проверка, 2-3 правки.

### Шаг 2. Генерация фонов (15 минут на 50 карточек)

В Midjourney параллельно генерируется 10-15 фонов:

```
/imagine minimalist product photography background, 
soft pastel peach, subtle texture, 
clean studio lighting --ar 3:4 --style raw
```

Вариантов фона 10-15 — используются на ротацию.

### Шаг 3. Сборка в Canva (13 минут)

Один шаблон карточки в Canva. 5 слайдов:

1. Главный: фото товара + название
2. Фишка: крупный текст + иконка
3. Детали: состав, размеры
4. С чем носить: 3 мини-иллюстрации
5. CTA: «Купить сейчас»

Через Canva Magic Batch (или Apps → CSV Import) — загрузила таблицу из ChatGPT → все 50 карточек сгенерились автоматически.

## Итого по времени

- **Текст (ChatGPT):** 7 минут
- **Фоны (Midjourney):** 15 минут (фоном, пока другое)
- **Сборка (Canva):** 13 минут
- **Итого: 35 минут на 50 карточек**

Против 100 часов руками. Экономия времени — в 170 раз.

## Что понадобилось

- **ChatGPT Plus** — $20/мес (или DeepSeek бесплатно)
- **Midjourney** — $10/мес базовый тариф
- **Canva Pro** — 380 руб/мес (с Magic Batch)

**Итого: ~$30/мес** против найма дизайнера (30-50 тыс. руб/мес).

## Нюансы

- **Не все карточки идеальны.** Где-то ИИ ошибается с тональностью. 3-5 из 50 пришлось поправить руками.
- **WB требует оригинальные фото товаров.** Фон можно ИИ, но сам товар — настоящая фотография.
- **Один раз настроил шаблон Canva — дальше тиражируется.** Первая карточка занимает час, остальные минуты.

## Как повторить

1. Собери свой список товаров в единый Excel/Sheets
2. Адаптируй промпт под свой стиль бренда
3. Создай шаблон в Canva (один раз, пригодится на годы)
4. Используй Canva Magic Batch для массовой генерации
5. Проверяй глазами, правь ошибки
