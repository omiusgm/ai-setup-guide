# 🛵 Delivery Hero: 200 часов в месяц сэкономили через n8n

> Один workflow в n8n. 5 часов на разработку. Результат — 200 сэкономленных часов IT-отдела каждый месяц по всей компании.

## Задача

Было:
- **800 заявок в месяц** на разблокировку учёток сотрудников
- Обработка **вручную**: сотрудник пишет → IT смотрит → проверяет → разблокирует
- Среднее ожидание сотрудника — **35 минут**
- IT-отдел тонет в тикетах, сотрудники злятся

Хотелось:
- Убрать ручную рутину с IT
- Сократить время ожидания до разумного
- Не потерять контроль (разблокировка — вещь чувствительная, нельзя на автомате кому попало)

## Решение

**Один** n8n workflow. Процесс:

1. Сотрудник подаёт заявку
2. n8n автоматически отправляет запрос менеджеру сотрудника
3. Менеджер одобряет кнопкой в мессенджере
4. После одобрения n8n через API (способ подключения программ) дёргает:
   - **Okta** — систему управления доступами
   - **Jira** — тикет-систему (отметить обработку)
   - **Google Workspace** — учётку сотрудника

Всё. Ни одного человека из IT не требуется, если менеджер одобрил.

Команда:
- **Dennis Zahrt** — Director IT
- **Slimani Ghaith** — разработчик
- **Dorina Ababii** — разработчица

Время на разработку workflow: **5 часов**.

## Результат

- Время ожидания сотрудника: **35 минут → 20 минут**
- **200 часов в месяц** сэкономленного времени IT-отдела по всей компании
- IT освободился от рутины — занимается сложными инцидентами
- Менеджер получает понятный запрос: одна кнопка — одобрить или отклонить

## Подводные камни

Честные наблюдения:

- Не все одобряют сразу — бывает, что менеджер в отпуске. Пришлось добавить эскалацию
- Okta API иногда залипает — нужна обработка ошибок
- Аудит важен: каждое одобрение логируется, иначе безопасники против

Урок: **простая автоматизация в нужном месте = огромная экономия**. Не нужен сложный ИИ, нужно найти рутину, которая ест часы.
