# 📉 Мониторинг цен на WB и Ozon — ИИ делает за тебя

> Предприниматель, 300 SKU на Wildberries. Раньше жена проверяла цены конкурентов вручную 2 часа в день. Теперь ИИ делает за 10 минут.

## Задача

Было:
- 300 товаров, у каждого 5-10 конкурентов
- Каждый день — руками в таблицу: цена, наличие, рейтинг
- 2 часа рутины, только чтобы понять кто демпингует

Хочется:
- Утром открыть отчёт: «у этих 12 товаров конкуренты снизили цену, надо реагировать»
- Не тратить время на сам поиск
- Алерты когда кто-то ставит ниже твоей минимальной цены

## Как сделал

Стек: **Browser Use** (для обхода защиты WB) + **Claude API** (способ подключения программ, через DeepSeek, бесплатно из РФ) + **Google Sheets** для отчётов.

Шаги:
1. Взял [Browser Use](../../apps/agents/browser-use.md) — автономный агент который управляет браузером как человек
2. Скормил ему список артикулов и запрос: «для каждого артикула найди 5 ближайших конкурентов, сравни цены и рейтинг»
3. Результат → Google Sheet, подсветка красным где мы дороже на 10%+
4. Поставил `/loop 1h` в Claude Code — обновляется каждый час пока комп работает
5. Ночью — задача по расписанию (будильник для команд) в 7:00 утра, сводный отчёт в Telegram

## Результат

- 2 часа рутины → 10 минут на проверку сводки
- Скорость реакции на демпинг — 1 час вместо дня
- Нашёл 23 товара где мог безболезненно поднять цену (конкуренты стояли выше)
- +8% маржи за первый месяц

## Стоимость

| Статья | В месяц |
|--------|---------|
| DeepSeek API (способ подключения программ, бесплатно до лимита) | 0 ₽ |
| Если перешёл на Claude | ~300 ₽ |
| Сервер для Browser Use (локально) | 0 ₽ |
| **Итого** | **0-300 ₽/мес** |

## Подводные камни

- **Wildberries блокирует частые запросы** — Browser Use справляется, но лучше ставить задержку 5-10 секунд между товарами
- **Цены меняются динамически** — одна проверка в час достаточно, чаще не имеет смысла
- **Не доверяй ИИ на 100%** — первую неделю проверял руками, находил расхождения в 2-3% случаев
