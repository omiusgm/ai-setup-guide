# 📝 500 описаний товаров за вечер вместо 2 недель

> Продавец детской одежды на Ozon. 500 карточек. Раньше платил копирайтеру 100₽ за описание. Итого: 50 000 ₽ за партию.

## Задача

Было:
- 500 новых SKU в сезон
- Каждое описание: характеристики + преимущества + ключевые слова для поиска
- Копирайтер: 3 дня ожидания, 100 ₽ штука, качество «так себе»
- Каждый сезон — 50 000 ₽ в карман фрилансеру

Хочется:
- Описания которые реально продают (а не «качественная одежда высшего качества»)
- Под SEO Ozon (ключевые слова в заголовке, в тегах)
- За вечер, не за 3 дня

## Как сделал

Стек: **ChatGPT Plus ($20/мес)** или **DeepSeek (бесплатно)** + один хороший промпт.

Промпт:
```
Ты опытный коммерческий копирайтер для Ozon, специализация — детская одежда.
Пиши описания по шаблону:

[Название товара — SEO-оптимизированное]

✅ Преимущества (3-5 буллетов, конкретика, не вода):
— Материал: хлопок 100%, дышит, не скатывается после стирки
— Крой: свободный, не жмёт в подмышках, подходит активным детям

🎯 Для кого: [возраст, сезон, случай]

📏 Размеры и уход: [инструкция]

Без «качественная», «инновационный», «уникальный».
Только конкретика и польза.
```

Процесс:
1. Выгрузил все SKU в CSV (название + характеристики)
2. Скармливал по 10 штук за раз ChatGPT с промптом выше
3. Описания копировал обратно в Ozon
4. **Ключевой момент:** первую партию в 20 штук проверил руками, правил промпт 3 раза пока не зашло

## Результат

- 500 описаний за один вечер (5-6 часов)
- Экономия: 50 000 ₽ на копирайтере
- CTR карточек в поиске вырос на 15% (конкретика продаёт лучше воды)
- В следующем сезоне повторил с обновлениями — время сократилось до 3 часов

## Стоимость

| Вариант | В месяц |
|---------|---------|
| ChatGPT Plus | 1 800 ₽ ($20) |
| DeepSeek API (способ подключения программ) | 0-200 ₽ |
| **Итого за партию 500 карточек** | **0-1800 ₽** (вместо 50 000 ₽) |

## Подводные камни

- **Галлюцинации размеров** — один раз ИИ написал «подойдёт для 3-6 лет» для детской шапки 0-2. Всегда проверяй характеристики
- **Стилистика «забывается» на длинных сессиях** — после 50 описаний ChatGPT начинает лить воду. Начинай новый чат каждые 20-30 товаров
- **Ключевые слова Ozon** — свой алгоритм, промпт надо адаптировать под конкретную нишу
- **Не пытайся автоматизировать 100%** — минимум 10% времени на ручную проверку первых и последних партий
