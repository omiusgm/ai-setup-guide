# 💻 dev_family: 46 000 строк на Claude Code за полтора месяца

> Минская студия сделала вдвоём за полтора месяца то, на что раньше уходило 4-5 месяцев командой. 46 000 строк рабочего кода. Клиент пользуется.

## Задача

Было:
- Стандартный проект — CRM с автоматизацией для клиента
- Обычный срок с командой — 4-5 месяцев
- Бюджет и сроки не резиновые

Хотелось:
- Уложиться быстрее и меньшими силами
- Не просто демо, а реально рабочий продукт в продакшене

## Решение

Два разработчика. Claude Code как основной исполнитель.

Стек:

- **NestJS** (бэкенд на TypeScript)
- **NextJS** (фронтенд)
- **PostgreSQL** (база данных)
- **MCP** (способ дать ИИ руки — подключить к внешним сервисам)

Ключ — не просто «пишем промпты», а продуманная архитектура работы с Claude:

- Детальный `CLAUDE.md` в корне проекта (инструкции для ИИ: что за проект, какие правила)
- Модульная документация — каждая фича описана отдельно
- MCP-серверы для задач, где Claude нужен прямой доступ к сервисам

## Результат

- **46 000 строк** рабочего кода
- **1.5 месяца** вместо 4-5
- **2 человека** вместо команды
- Клиент пользуется, проект в продакшене

Цитата от команды:

> «Проект работает, клиент пользуется»

Не «запустили демо», не «показали прототип» — реально работающая CRM.

## Подводные камни

Без настройки Claude «забывает» контекст. Пришлось серьёзно вложиться в структуру:

- Если `CLAUDE.md` поверхностный — Claude делает каждую фичу будто с нуля, игнорирует существующий стиль
- Модульная документация обязательна — иначе в большом проекте Claude путается
- Первые недели — много времени ушло на настройку workflow, а не на код

Вывод команды: вайб-кодинг работает, но это не «кидай промпты — получай код». Это инженерная работа по настройке ИИ-помощника под проект.
