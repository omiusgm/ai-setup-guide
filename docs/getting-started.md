# Быстрый старт

Три шага чтобы ИИ начал реально помогать. Без терминала, без кода, за 5 минут.

---

## Шаг 1: Выбери ИИ-чат

| Сервис | Цена | Плюсы | Минусы |
|--------|------|-------|--------|
| **DeepSeek** | Бесплатно | Не хуже платных, работает из РФ | Иногда медленный |
| **ChatGPT** | Бесплатно / $20 | Его все уже видели | Ограничения на бесплатном, скоро реклама |
| **Gemini** | Бесплатно | 2M токенов контекста | Нужен VPN |
| **Claude** | $20 / $100 | Лучший для текстов и кода | Ограничивает доступ из РФ |

**Совет:** начни с DeepSeek (бесплатно, из РФ без VPN) или ChatGPT (привычный интерфейс).

---

## Шаг 2: Скопируй промпт

Вставь это в начало чата — ИИ перестанет лить воду и начнёт отвечать по делу:

```
Отвечай максимально кратко. Правила:
1. Без вступлений — никаких «Конечно!», «Рад помочь», «Отличный вопрос»
2. Без воды — убирай лишние союзы, местоимения, вводные конструкции
3. Факты, не мнения — вместо «возможно стоит рассмотреть» пиши «делай так:»
4. Причина → следствие через стрелку →
5. Технические термины не упрощай
6. Код и ошибки не сокращай — сокращай только пояснения
7. Если хватит одного слова — отвечай одним словом
```

---

## Шаг 3: Прочитай правила

Три самых важных из [десяти](guides/rules.md):

!!! tip "Правило 1: Новый чат — это перезагрузка"
    Длинный диалог = тупой ИИ. Закончил задачу — начни новый чат.

!!! tip "Правило 3: Контекст — это всё"
    ИИ не читает мысли. Чем больше ты расскажешь (роль, цель, ограничения), тем лучше ответ.

!!! tip "Правило 7: ИИ врёт красиво"
    Галлюцинации — это норма. Всегда проверяй факты, особенно цифры и ссылки.
