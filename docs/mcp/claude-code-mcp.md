# Claude Code MCP -- агент-в-агенте

Агент запускает другого агента. Звучит как рекурсия, но на практике -- мощная штука. Один Claude Code может запустить другой Claude Code как инструмент.

[Репозиторий](https://github.com/steipete/claude-code-mcp)

---

## Зачем это нужно

Допустим ты работаешь в Claude Desktop (удобный интерфейс, чатик). Но нужно сделать что-то в терминале -- создать файлы, поправить код, запустить команды. Вместо переключения -- Claude Desktop вызывает Claude Code как инструмент.

Или: твой основной агент занят большой задачей, а тебе нужно параллельно что-то проверить. Запускаешь субагента.

---

## Как работает

```bash
claude mcp add claude-code -- npx -y @anthropic-ai/claude-code-mcp
```

После этого любой MCP-клиент (Claude Desktop, Cursor, другой агент) может вызывать Claude Code как инструмент.

---

## Сценарии

| Основной агент | Вызывает Claude Code для |
|----------------|-------------------------|
| Claude Desktop | Работа с файлами, Git, код |
| Cursor | Параллельная задача в другом проекте |
| n8n workflow | Автоматическая генерация кода |
| Другой Claude Code | Субагент для изолированной задачи |

---

## Пример

Ты в Claude Desktop обсуждаешь стратегию проекта. Посреди разговора:

> "Кстати, создай мне структуру проекта для этого -- папки, файлы, package.json, README"

Claude Desktop сам вызовет Claude Code, тот создаст всё в файловой системе, вернёт результат обратно в чат.

---

## Ограничения

- Claude Code MCP запускает полноценного агента -- это тратит токены
- Каждый вызов -- новая сессия (нет памяти между вызовами)
- Нужна подписка Claude Pro/Max (не бесплатный тариф)

---

## Альтернативы

- **Субагенты** (встроены в Claude Code) -- для параллельных задач внутри одной сессии
- **Agent Teams** (экспериментально) -- несколько агентов с общей перепиской
