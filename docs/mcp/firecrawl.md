# Firecrawl -- скрапинг сайтов для ИИ

Ты говоришь агенту "собери информацию с этого сайта" -- а он не может. Страницы в интернете -- это HTML, JavaScript, куки-баннеры. Firecrawl превращает любой сайт в чистый текст, который ИИ может прочитать.

[Репозиторий](https://github.com/mendableai/firecrawl) (106K stars)

---

## Что делает

- **Скрапинг** -- достаёт текст с любой страницы (даже JavaScript-рендеренной)
- **Краулинг** -- обходит весь сайт по ссылкам, собирает все страницы
- **Мэппинг** -- карта сайта: все URL одним списком
- **Извлечение данных** -- структурированные данные (цены, контакты, описания) в JSON

---

## Установка

```bash
claude mcp add firecrawl -e FIRECRAWL_API_KEY=... -- npx -y firecrawl-mcp
```

API-ключ берёшь на [firecrawl.dev](https://firecrawl.dev) -- 500 страниц бесплатно, потом от $16/мес.

## Примеры

| Задача | Что делает Firecrawl |
|--------|---------------------|
| "Собери цены конкурентов" | Краулит каталог, достаёт цены в таблицу |
| "Прочитай документацию этой библиотеки" | Скрапит все страницы docs, отдаёт агенту |
| "Что пишут на этом форуме про X" | Собирает посты, агент анализирует |
| "Переведи этот сайт" | Скрапит все страницы, агент переводит |

---

## Firecrawl vs просто "открой ссылку"

Обычный веб-запрос получает сырой HTML. Firecrawl:

- Рендерит JavaScript (SPA, React-сайты)
- Убирает мусор (навигация, реклама, футеры)
- Отдаёт чистый Markdown
- Обходит базовую защиту от ботов
