# n8n MCP -- Claude управляет автоматизацией

n8n -- визуальный конструктор автоматизаций (вроде Zapier, но бесплатный и self-hosted). n8n MCP позволяет агенту Claude создавать и запускать автоматизации через n8n голосом/текстом.

[Репозиторий](https://github.com/czlonkowski/n8n-mcp) (18K stars)

---

## Зачем

Без MCP: ты сам открываешь n8n, тащишь ноды мышкой, настраиваешь каждый, тестируешь.

С MCP: говоришь агенту "когда придёт письмо от клиента -- создай карточку в CRM и отправь уведомление в Telegram", и агент сам создаёт workflow в n8n.

---

## Что может агент

- Создавать новые workflow
- Редактировать существующие
- Запускать и останавливать
- Читать логи выполнения
- Дебажить ошибки

---

## Установка

Сначала нужен работающий n8n (локально или на сервере). Потом:

```bash
claude mcp add n8n-mcp -e N8N_API_KEY=... -e N8N_BASE_URL=http://localhost:5678 -- npx -y n8n-mcp
```

---

## Примеры автоматизаций

| Что говоришь | Что создаёт агент |
|--------------|-------------------|
| "Каждое утро собирай новости и отправляй дайджест" | RSS -> фильтр -> Telegram |
| "Когда новый лид в CRM -- пришли в Slack" | Webhook -> AmoCRM -> Slack |
| "Бекап базы каждый день в полночь" | Cron -> PostgreSQL -> Google Drive |
| "Мониторь сайт, если упал -- пиши мне" | HTTP Request -> условие -> Telegram |

---

## n8n MCP vs запускать n8n руками

| Руками | Через агента |
|--------|-------------|
| Тащишь ноды мышкой | Описываешь текстом |
| Настраиваешь каждый нод | Агент настраивает |
| Дебажишь по логам | Агент читает логи |
| 30 минут на workflow | 2 минуты на промпт |

---

## Нюансы

- n8n должен быть запущен (локально или на VPS)
- Для полноценного использования -- n8n Cloud ($24/мес) или свой сервер
- Self-hosted n8n бесплатный, но нужен VPS ($5-10/мес)
