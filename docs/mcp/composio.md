# Composio -- 1000+ интеграций для ИИ-агентов

Вместо того чтобы ставить 20 отдельных MCP-серверов (один для Gmail, один для Slack, один для GitHub), Composio даёт всё сразу. Один инструмент -- тысяча интеграций.

[Репозиторий](https://github.com/ComposioHQ/composio)

---

## Что подключает

- **Почта**: Gmail, Outlook
- **Мессенджеры**: Slack, Discord, Telegram
- **Код**: GitHub, GitLab, Bitbucket
- **Документы**: Google Docs, Notion, Confluence
- **CRM**: HubSpot, Salesforce
- **Управление**: Jira, Linear, Trello, Asana
- **Файлы**: Google Drive, Dropbox
- ...и ещё сотни сервисов

---

## Как ставить

```bash
claude mcp add composio -e COMPOSIO_API_KEY=... -- npx -y composio-mcp
```

Ключ берёшь на [composio.dev](https://composio.dev) -- есть бесплатный тариф.

---

## Зачем если есть отдельные MCP

| Отдельные MCP | Composio |
|---------------|----------|
| Ставишь каждый сервер отдельно | Один сервер -- все интеграции |
| Каждый настраиваешь отдельно | Одна авторизация через OAuth |
| 5 серверов = 5 процессов | 1 процесс |
| Надо искать MCP для каждого сервиса | Каталог внутри |

---

## Когда Composio лучше

- Нужно подключить 5+ сервисов
- Не хочешь возиться с настройкой каждого MCP
- Нужны сервисы для которых нет отдельного MCP
- Хочешь OAuth-авторизацию (не токены вручную)

## Когда отдельные MCP лучше

- Нужен только один сервис (проще поставить один MCP)
- Нужна максимальная гибкость конкретного сервиса
- Бесплатность важнее удобства

---

## Пример

```
"Когда в Jira появляется баг с приоритетом Critical --
 создай задачу в Notion, отправь в Slack канал #bugs,
 и напиши мне в Telegram"
```

Одна инструкция -- три сервиса. Composio подключает все три.
