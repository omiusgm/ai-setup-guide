# Docker MCP Toolkit -- 300+ плагинов в каталоге

Представь магазин приложений, где агент сам выбирает что установить. Docker MCP Toolkit -- это каталог из 300+ MCP-серверов, которые ИИ может подключать на лету.

---

## Как работает

Обычно: ты руками ставишь каждый MCP-сервер, прописываешь конфиг, перезапускаешь.

С Docker MCP: агент видит каталог из 300+ серверов и сам подключает нужный для задачи. Ты говоришь "найди информацию на сайте" -- агент подключает Firecrawl. Говоришь "отправь в Slack" -- подключает Slack MCP.

---

## Установка

Нужен Docker Desktop на компьютере. Дальше:

```bash
claude mcp add docker-mcp -- docker run -i --rm docker/mcp-toolkit
```

---

## Что в каталоге

Серверы для всего:

- Поиск и браузер
- Базы данных (PostgreSQL, MongoDB, Redis)
- Облака (AWS, GCP, Azure)
- Мессенджеры и почта
- Файловые хранилища
- DevOps инструменты
- И многое другое

---

## Плюсы

- **Изоляция** -- каждый MCP в отдельном контейнере, не ломает систему
- **Автообнаружение** -- агент сам находит нужный сервер
- **Безопасность** -- контейнеры изолированы друг от друга
- **Не засоряет систему** -- удалил контейнер = удалил MCP

## Минусы

- Нужен Docker Desktop (бесплатный, но ест ресурсы)
- Некоторые серверы требуют настройки (API-ключи)
- На слабых машинах Docker может тормозить

---

## Кому подходит

Тем, кто подключает много разных MCP и не хочет возиться с настройкой каждого. Или тем, кто ценит безопасность -- контейнеры не имеют доступа к файлам вне Docker.
