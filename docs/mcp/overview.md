# Что такое MCP и зачем он нужен

MCP (Model Context Protocol) -- это "магазин приложений" для ИИ. Как App Store для телефона -- хочешь фоторедактор, ставишь приложение. Хочешь чтобы ИИ гуглил -- ставишь MCP-сервер для поиска.

---

## Проблема

Claude из коробки не умеет:

- Искать в интернете
- Открывать файлы на твоём компьютере
- Отправлять сообщения в Telegram
- Работать с Google Sheets, Notion, Slack

Он умный, но без рук. MCP даёт ему руки.

---

## Как работает

MCP-сервер -- это мини-программа, которая подключает ИИ к внешнему сервису. Один сервер = одна способность.

Примеры:

- `brave-search` -- веб-поиск
- `notion` -- чтение/запись в Notion
- `telegram-channel` -- отправка сообщений в Telegram
- `firecrawl` -- скрапинг сайтов

---

## Как ставить

В Claude Code (терминал):

```bash
claude mcp add имя-сервера -- команда-запуска
```

В Claude Desktop -- через файл настроек `claude_desktop_config.json`.

## Сколько серверов подключать

Начни с 2-3 базовых:

1. **Поиск** -- Brave Search или DuckDuckGo (бесплатный)
2. **Файлы** -- filesystem (встроен в Claude Code)
3. **Что-то для работы** -- Notion, Google Sheets, Telegram -- что используешь

Потом добавляй по мере необходимости. 10+ серверов одновременно -- перебор, агент начинает путаться какой инструмент использовать.

---

## MCP vs плагины ChatGPT

По сути -- одно и то же, только MCP -- открытый стандарт (работает с разными ИИ), а плагины ChatGPT -- только для ChatGPT.
