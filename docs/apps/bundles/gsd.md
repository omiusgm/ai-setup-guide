# 🚀 GSD (Get Shit Done)

!!! info "🤖💬 Для чатботов И агентов"
    Работает и в браузере (облачная версия / альтернатива), и через агента (установка). Ниже оба варианта.

> Встроенный паттерн Claude Code для оркестрации больших проектов. План → задачи → исполнение. Агент сам разбивает и делает.

## Что делает

Не внешний пакет, не репозиторий. GSD — это рабочий процесс, который живёт в Claude Code. Активируется командой или промптом.

Идея: большие задачи пугают ИИ (и людей). Поэтому GSD разбивает проект на три фазы:

1. **Планирование** — агент изучает контекст, составляет план
2. **Декомпозиция** — план режется на задачи
3. **Исполнение** — агент идёт по задачам, каждую закрывает, ведёт прогресс

## Кому подходит

- ✅ Большие проекты где надо думать перед делать
- ✅ Работаешь в Claude Code
- ✅ Хочешь структурированный подход, а не хаос
- ❌ НЕ подходит для простых задач — избыточно
- ❌ Если уже используешь свой процесс — GSD его заменит

## Как попробовать без чёрного окна с командами

GSD это паттерн работы, а не программа. Можешь использовать его в любом ИИ — ChatGPT, Claude, DeepSeek. Просто скопируй промпт в начало разговора:

```
Работай по методу GSD (Get Shit Done):
1. Сначала составь план (PLAN.md в голове)
2. Разбей на задачи в виде чеклиста (TODO.md)
3. Иди по задачам, каждую отмечай как done
4. В конце сделай саммари что сделано

Моя задача: [опиши что надо]
```

ИИ сам пойдёт по шагам: план → задачи → исполнение → отчёт. Работает в любом чате без установок.

??? note "Для программистов (команда в Claude Code)"

    Если работаешь в Claude Code — команда встроена:

    ```
    /gsd Перепиши модуль авторизации на JWT + добавь тесты
    ```

    **Что произойдёт:**

    1. Агент создаёт PLAN.md — читай, правь если надо
    2. Агент создаёт TODO.md — список задач
    3. Начинает выполнять по очереди, отмечая прогресс
    4. В конце — FINAL.md с отчётом

## Файлы, которые создаёт

```
PROJECT_ROOT/
├── PLAN.md        # Обзор и стратегия
├── TODO.md        # Чеклист задач
├── HANDOFF.md     # Прогресс между сессиями
└── FINAL.md       # Итоговый отчёт
```

## Нюансы

- Для маленьких задач лишний — просто задай вопрос
- Работает лучше когда есть CLAUDE.md с контекстом проекта
- Можно кастомизировать этапы под свои процессы
