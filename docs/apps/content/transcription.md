# Транскрибация аудио

<div class="product-hero" markdown>

**Любая запись (звонок, встреча, голосовое) → текст с таймкодами и метками «кто что сказал». 5 классов решений — от «загрузил в браузер» до локального бесплатного на своём компе.**

Главное правило: **сначала смотри что уже есть бесплатно или встроено**. NotebookLM, Gemini, Bitrix24 — часто решают задачу за 0 ₽ и без установок. Cloud API и локальный стек — для регулярного потока или своего продукта.

## 1. Залить ИИ-боту (самое простое, для разовых задач)

Если запись разовая (одна встреча, один звонок, один файл) — не надо ничего ставить. Грузишь файл в чат с ИИ — получаешь транскрипт и саммари сразу. Бесплатно или почти.

**🎯 Google NotebookLM** — лучший вариант под русский. Бесплатно. notebooklm.google.com → добавляешь источник → грузишь mp3/wav → готовый транскрипт + саммари + Q&A по содержанию (можно задать любой вопрос — «что обсуждали про цену?»). Лимит источников бесплатно — 100 на блокнот, можно фильмы по 2 часа.

**🎯 Google AI Studio (Gemini 2.5 Flash)** — aistudio.google.com → новый чат → прикрепить аудио → промпт «транскрибируй с указанием говорящих, выдели action items». До 9.5 часов на один файл. Бесплатно в free-тире (500 запросов/день). Встроенная диаризация без настройки.

**ChatGPT Plus** — загрузи файл в чат, транскрибирует ($20/мес). Без диаризации.

**Telegram Premium** — голосовые автоматом транскрибируются (₽3-5 в мес).

**Плюсы:** ничего не ставить, бесплатно или дёшево, диаризация в Gemini/NotebookLM «из коробки».
**Минусы:** ручной процесс — для каждого файла нажимать кнопки. Не для регулярного потока 100+ записей.

## 2. Встроено в CRM или АТС (для регулярных звонков)

Если у тебя СРМ или облачная телефония — 80% шансов что транскрибация уже встроена или подключается за 5 минут. Текст сам падает в карточку сделки, ничего писать не надо.

**Российские СРМ и АТС:**

- **Bitrix24** — «Распознавание звонков» в тарифах Стандарт+. Движок — Yandex SpeechKit, русский отлично. Автоматом транскрибирует входящие/исходящие, текст в карточке. Диаризация работает на стерео-записях.
- **AmoCRM** — своего встроенного нет, но есть готовые виджеты: **CallGear**, **Callibri**, **Roistat**, **Zadarma**, **СИПУНИ**. Установка 5 минут, текст в примечаниях к сделке. Многие добавляют анализ тональности и ключевых слов.
- **MANGO OFFICE** — «Речевая аналитика», 5 ₽/мин. Транскрипт + теги по скрипту продаж.
- **Zadarma** — «Расшифровка звонков» в AI-тарифе, ~2.9 ₽/мин.
- **UIS / Ringostat / Callibri** — все имеют транскрибацию с диаризацией.

**Встречи (Zoom / Meet / Teams):**
- Zoom AI Companion — бесплатно на Pro+
- Google Meet + Gemini (Workspace Business+)
- MS Teams + Copilot

**Плюсы:** ничего не ставить, текст привязан к карточке автоматом, оплата в рублях.
**Минусы:** платно помесячно, данные идут провайдеру, мало контроля.

**Через API:** все эти СРМ и АТС отдают готовый транскрипт по API — в Claude Code/n8n забираешь и делаешь что угодно: саммари, теги, алерты РОПу.

## 3. Cloud API (для своего продукта или больших объёмов)

Когда: СРМ не умеет, нужно интегрировать в свой продукт, объём больше встроенных лимитов, нужна другая модель.

| Сервис | Цена/час | Диаризация | Русский | Особенность |
|---|---|---|---|---|
| **🏆 Gemini 2.5 Flash** | **$0.13** | ✅ | отлично | До 9.5 ч на файл, саммари + action items в одном вызове |
| **Deepgram Nova-2** | $0.26 | ✅ | отлично | Самая низкая задержка, потоковая |
| **AssemblyAI Universal-2** | $0.37 | ✅ | хорошо | На 30% меньше галлюцинаций, чем Whisper |
| **Whisper API (OpenAI)** | $0.36 | ❌ | отлично | Простой, без диаризации |
| **Groq Whisper** | 0 ₽ | ❌ | хорошо | Прототипы, 7200 сек/день Free |
| **Yandex SpeechKit** | ~60 ₽ | ✅ | лучший | Российская карта, юр. лицо |

**🏆 Gemini 2.5 Flash — лучшая цена + диаризация в одной модели.** За $0.13/час получаешь транскрипт, диаризацию, саммари и action items в одном API-вызове. Это в 2 раза дешевле Deepgram и в 3 раза — Whisper API.

**Типовой пайплайн:** cron или webhook → скачивает аудио → POST в API → JSON с текстом → сохраняет куда надо.

**Плюсы:** ноль железа, стабильное качество, масштабируется.
**Минусы:** оплата иностранной картой (Gemini, Deepgram, AssemblyAI), данные уходят наружу — проверь 152-ФЗ.

## 4. Локально (приватность + большой объём)

Когда: данные не отдаёшь наружу (юр. ограничения, NDA, коммерческая тайна), либо >5000 минут/месяц — локально дешевле чем cloud-API.

**WhisperX** — топовое open-source решение. Whisper для текста + pyannote для диаризации в одной установке.

```bash
pip install whisperx
whisperx call.mp3 --model large-v3 --diarize --hf_token hf_xxx --language ru
```

На выходе JSON с сегментами, где каждой фразе присвоен `SPEAKER_00`, `SPEAKER_01` и таймкоды.

HuggingFace token бесплатный: hf.co → Settings → Access Tokens → согласиться с условиями `pyannote/speaker-diarization-3.1`.

**Железо:**
- Mac M1/M2/M3 — через MPS, ≈ 0.3× длины записи
- NVIDIA GPU (8 ГБ VRAM) — 0.1×
- CPU без GPU — 1-2×, работает на любом ноуте

**Плюсы:** полная приватность, 0 ₽ после настройки, можно дообучить.
**Минусы:** нужно железо и час на настройку.

**Для русского:** базовый `large-v3` даёт WER ~9.84%. Fine-tuned `antony66/whisper-large-v3-russian` на HuggingFace — WER 6.39% (заметно лучше для бизнес-задач).

**Репозитории:**
- [WhisperX](https://github.com/m-bain/whisperX) · 21 352⭐
- [whisper.cpp](https://github.com/ggerganov/whisper.cpp) · 48 696⭐ — на C++, быстрее на CPU
- [pyannote-audio](https://github.com/pyannote/pyannote-audio) · 9 773⭐ — движок диаризации

## 5. Из Claude Code через MCP

Если хочешь чтобы Claude сам анализировал аудио — без копи-паста — подключи MCP-сервер. После установки в чате просто кидаешь путь к файлу, Claude вызывает API и приносит транскрипт.

**Готовые MCP-серверы:**

- **`@rlabs-inc/gemini-mcp`** — самый функциональный для Gemini: анализ аудио/видео, Deep Research, TTS (30 голосов), генерация изображений. Подключение одной командой:
  ```bash
  claude mcp add gemini -s user -- env GEMINI_API_KEY=ВАШ_КЛЮЧ npx -y @rlabs-inc/gemini-mcp
  ```
- **`aliargun/mcp-server-gemini`** (248⭐) — текстовая генерация, анализ изображений, эмбеддинги, подсчёт токенов
- **`cogell/assembly-ai-mcp`** — AssemblyAI с диаризацией до 50 говорящих, async-обработка длинных файлов
- **`SmartLittleApps/local-stt-mcp`** — локальный Whisper через whisper.cpp с диаризацией, оптимизирован под Apple Silicon. Бесплатный, приватный
- **`BigUncle/Fast-Whisper-MCP-Server`** — локальный, CUDA-ускоренный, модели от tiny до large-v3, VAD-фильтрация
- **`forayconsulting/zoom_transcript_mcp`** — доступ к Zoom Cloud Recording, поиск по записям, фильтры по дате/участникам

**MVP за 30 минут без MCP:** Claude Code умеет в bash → curl. Можно прямо из чата дёргать Gemini Files API + `gemini-2.5-flash:generateContent`. Полный bash-скрипт на 30 строк, файл загружается через resumable upload, в ответ — JSON с транскриптом и диаризацией. Скажи Claude «напиши bash-скрипт для transcribe meeting.mp3 через Gemini 2.5 Flash» — он сделает.

## Дерево решений: что выбрать

<div class="decision-tree" markdown>

**Один файл, без кода, бесплатно?**
→ NotebookLM или Google AI Studio (Gemini 2.5 Flash). Загрузил → готово.

**У тебя CRM или облачная АТС с регулярным потоком звонков?**
→ Включи встроенный транскриб (Bitrix, MANGO, Zadarma, виджеты AmoCRM). Текст сам падает в карточку.

**Нужно интегрировать в свой продукт?**
→ Gemini 2.5 Flash через API ($0.13/час, лучшая цена + диаризация). Альтернативы: Deepgram, AssemblyAI.

**Данные нельзя отдавать наружу?** Есть Mac M1+ или NVIDIA GPU?
→ WhisperX локально. Бесплатно, приватно.

**Хочешь чтобы Claude сам разбирал аудио?**
→ MCP-сервер: `@rlabs-inc/gemini-mcp` (Gemini 2.5 Flash) или `local-stt-mcp` (локальный Whisper).

**Нужно 1-2 раза в неделю руками?**
→ MacWhisper Pro ($59) или Buzz (бесплатно).

## GUI для разовых задач

Если код не пишешь и нужно раз в неделю разобрать запись.

- **[MacWhisper Pro](https://goodsnooze.gumroad.com/l/macwhisper)** — $59, macOS only, drag-and-drop, есть диаризация
- **[Buzz](https://github.com/chidiwilliams/buzz)** — 18 716⭐, бесплатно, Win/Mac/Linux, GUI на whisper.cpp
- **[Hyprnote](https://github.com/fastrepl/hyprnote)** — 8 266⭐, бесплатно, специально для Zoom/Meet с саммари через локальный LLM

## Нюансы для всех способов

- **Диаризация** нужна когда один говорит за другим без разделения каналов. Если запись в стерео (менеджер и клиент в разных каналах) — диаризация не нужна, каждый канал = отдельный говорящий.
- **Русский** — лучшее качество: Yandex SpeechKit > Whisper large-v3-russian (fine-tuned) > Gemini 2.5 Flash > Deepgram > Whisper base.
- **Короткие записи (<30 сек)** — диаризация может путать. Лучше отключить и роль присваивать по контексту.
- **Фон, шум, музыка ожидания** — снижают точность на 20-30%. Прогони через RNNoise или DeepFilterNet перед транскрипцией.
- **152-ФЗ (РФ)** — запись звонков с клиентами только при согласии. Стандартно в договоре или автоинформаторе «разговор будет записан». Без этого — незаконно.
- **Длина файла:** NotebookLM до ~2 часов на источник; Gemini 2.5 Flash до 9.5 ч на запрос; Whisper API — до 25 МБ; локальный — без лимитов.

## Кому подходит

- 🤖 **Агент (Claude Code)** — MCP-сервер Gemini/AssemblyAI/Whisper или прямой curl-вызов API
- 💬 **Чатбот (NotebookLM, AI Studio, ChatGPT)** — загрузка файла вручную
- **Для бизнеса:** отделы продаж, поддержка, HR-интервью, медицина, юристы, аналитики
- **Для контента:** подкасты (таймкоды), журналисты (цитаты), SMM (нарезки из эфиров), консультанты (записи сессий → отчёты)

## Совместимость

- **NotebookLM, Google AI Studio, Gemini API** — нужен VPN для регистрации/входа в notebooklm.google.com и aistudio.google.com (российский IP не пускает). Сами API-запросы после регистрации работают и из РФ
- **Встроенное в российские CRM и АТС** — без VPN, оплата в рублях
- **WhisperX локально** — без VPN, модели Whisper иногда через зеркало HuggingFace
- **Cloud API (Gemini, Deepgram, AssemblyAI, OpenAI)** — запросы без VPN; оплата только иностранной картой
- **Yandex SpeechKit** — российская карта, юр.лицо
