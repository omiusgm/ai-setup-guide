## Два уровня: транскрипт + диаризация

**Транскрипт** — превращение аудио в текст. Это делает Whisper (модель OpenAI, открытая, бесплатная).

**Диаризация** — кто из говорящих что сказал. Делает pyannote-audio: слушает тембр, ритм, интонации, присваивает каждому куску речи метку `SPEAKER_00`, `SPEAKER_01`.

WhisperX объединяет оба в одной установке — ставишь pip-пакет, получаешь обе фичи сразу.

## Способ 1. WhisperX (локально, бесплатно, с диаризацией)

```bash
pip install whisperx
whisperx call.mp3 \
  --model large-v3 \
  --diarize \
  --hf_token hf_xxx \
  --language ru \
  --output_format json
```

На выходе JSON с сегментами:

```json
{
  "segments": [
    {"start": 0.0, "end": 4.2, "text": "Добрый день, Алексей, вы интересовались...", "speaker": "SPEAKER_00"},
    {"start": 4.3, "end": 7.1, "text": "Да, но цена высокая для меня", "speaker": "SPEAKER_01"}
  ]
}
```

Дальше агент Claude Code парсит JSON и понимает: SPEAKER_00 = менеджер (задаёт первый вопрос), SPEAKER_01 = клиент.

**HuggingFace токен** нужен для pyannote — бесплатно: hf.co → Settings → Access Tokens → согласиться с условиями на странице `pyannote/speaker-diarization-3.1`. 3 минуты разовой настройки.

**Железо:**
- Mac M1/M2/M3 — работает через MPS, реальное время ≈ 0.3× длины записи
- NVIDIA GPU (RTX 3060+, 8 ГБ VRAM) — 0.1×
- CPU (без GPU) — 1-2×, но работает на любом ноуте

## Способ 3. Hyprnote (для внутренних встреч)

Локальный GUI для macOS. Подключается к Zoom / Google Meet / Teams, записывает, транскрибирует, пишет саммари через Ollama (локальный ИИ). Для планёрок и ретро — идеально, ничего в облако не уходит.

## Кейс: РОП + AmoCRM (пайплайн на 80 строк Python)

**Дано:** AmoCRM хранит записи звонков в облаке.
**Надо:** каждый звонок → текст с метками менеджер/клиент → ИИ даёт выводы → заметка в карточке сделки.

**Как собирать:**

1. **Webhook AmoCRM** на событие «завершён звонок» — AmoCRM дёргает твой endpoint с ID записи
2. **Скачивание аудио** из AmoCRM Files API по токену
3. **WhisperX с `--diarize`** — JSON с ролями и таймкодами
4. **Claude API:** промпт «Это стенограмма звонка. SPEAKER_00 задаёт вопросы первым — это менеджер. Определи: тема, возражения клиента, закрылась ли сделка, следующий шаг. Верни JSON»
5. **AmoCRM Notes API** — закинуть результат в карточку сделки как заметку

Полный скрипт напишет агент Claude Code за час — дашь спеку, получишь рабочий код. Нужны: AmoCRM API key, HuggingFace token, Claude API key (или OpenAI).

## Нюансы

- **Короткие звонки (<2 мин)** — диаризация путает голоса. Лучше обходиться без неё, роль ставить по факту (звонящий = менеджер)
- **Один канал vs два канала** — если запись стерео с разделёнными каналами (менеджер в левом, клиент в правом) — диаризация не нужна, каждый канал = отдельный говорящий
- **Фон/шум/музыка на ожидании** — снижает точность на 20-30%. Перед транскрипцией прогнать через RNNoise или DeepFilterNet
- **Русский язык** — Whisper large-v3 даёт WER 6-8% (из 100 слов 6-8 с ошибками). Для бизнес-задач хватает, для юридических документов — нет
- **Юридически (РФ, 152-ФЗ)** — записывать звонки с клиентами можно только при согласии. Обычно в договоре или автосообщении при дозвоне «разговор будет записан». Не пропускай этот момент

## Бесплатные фишки до установки

- **yt-dlp + Whisper** — скачать YouTube-ролик, транскрибировать локально. Для ресёрча, не для бизнеса.
- **ChatGPT Plus** — загрузить аудио в чат, транскрибирует сам. Без диаризации, платно ($20/мес).
- **Telegram Premium** — голосовые автоматически транскрибируются (без диаризации, только короткие).
- **MacWhisper Free** — GUI для Mac на whisper.cpp, drag-and-drop файла. Без диаризации в бесплатной версии, $59 за Pro с диаризацией.

## Кому подходит

- 🤖 **Агент** (Claude Code) — WhisperX ставится через pip, дальше Claude сам вызывает команду и парсит JSON
- 💬 **Чатбот** — загрузи аудио в ChatGPT Plus или используй Telegram-бот для коротких голосовых
- **Для бизнеса:** отделы продаж, поддержка, HR-интервью, врачи (записи приёмов), юристы (переговоры)
- **Для контента:** подкастеры (таймкоды по главам), журналисты (цитаты из интервью), SMM (нарезки из эфиров)

## Совместимость

- Работает из РФ без VPN (pip работает; модели Whisper качаются с HuggingFace, иногда через зеркало)
- Ollama для Hyprnote ставится локально, тоже без VPN
- Cloud-API (Deepgram, AssemblyAI) — оплата возможна через зарубежную карту; российские карты не принимают
- Для NVIDIA GPU нужны драйверы CUDA, для Apple Silicon — MPS работает из коробки
