# Транскрибация аудио

<div class="product-hero" markdown>

**Любая запись (звонок, встреча, голосовое) → текст с таймкодами и метками «кто что сказал». 4 класса решений — от «ничего не ставить» до локального бесплатного на своём компе.**

Главное правило: **сначала проверь что уже встроено в твою систему**. СРМ, телефония, Zoom — у многих транскрибация уже есть, просто выключена. Внешние API и локальная установка — только если встроенного нет или оно плохо подходит.

## 1. Встроено в твоей системе (самое простое)

Если у тебя уже есть СРМ или облачная телефония — 80% шансов что транскрибация там уже встроена или подключается за 5 минут. Текст сам падает в карточку сделки, ничего писать не надо.

**Российские СРМ и АТС:**

- **Bitrix24** — «Распознавание звонков» в тарифах Стандарт+. Движок — Yandex SpeechKit, русский отлично. Автоматом транскрибирует входящие/исходящие, текст в карточке. Диаризация работает на стерео-записях.
- **AmoCRM** — своего встроенного нет, но есть готовые виджеты: **CallGear**, **Callibri**, **Roistat**, **Zadarma**, **СИПУНИ**. Установка 5 минут, текст в примечаниях к сделке. Многие добавляют анализ тональности и ключевых слов.
- **MANGO OFFICE** — «Речевая аналитика», 5 ₽/мин. Транскрипт + теги по скрипту продаж.
- **Zadarma** — «Расшифровка звонков» в AI-тарифе, ~2.9 ₽/мин.
- **UIS / Ringostat / Callibri** — все имеют транскрибацию с диаризацией.

**Встречи (Zoom / Meet / Teams):**
- Zoom AI Companion — бесплатно на Pro+
- Google Meet + Gemini (Workspace Business+)
- MS Teams + Copilot

**Плюсы:** ничего не ставить, текст привязан к карточке автоматом, оплата в рублях.
**Минусы:** платно помесячно, данные идут провайдеру, мало контроля над качеством модели.

**Через API:** все эти СРМ и АТС отдают готовый транскрипт по API — в Claude Code/n8n можно забирать текст и делать что угодно: саммари, теги, алерты РОПу.

## 2. Cloud API (когда встроенного нет или нужна гибкость)

Когда: СРМ не умеет, нужно интегрировать в свой продукт, объём больше встроенных лимитов, нужна другая модель.

| Сервис | Цена/мин | Диаризация | Русский | Для чего |
|---|---|---|---|---|
| **Deepgram Nova-2** | $0.0043 | ✅ | отлично | 100+ звонков/день, свой продукт |
| **AssemblyAI** | $0.0065 | ✅ | хорошо | транскрипт + саммари в одном запросе |
| **Whisper API (OpenAI)** | $0.006 | ❌ | отлично | разовые задачи |
| **Groq Whisper** | 0 ₽ | ❌ | хорошо | прототипы, 7200 сек/день Free |
| **Yandex SpeechKit** | ~1 ₽ | ✅ | лучший | российская карта, юр. лицо |

**Типовой пайплайн:** cron или webhook → скачивает аудио → POST в API → JSON с текстом → сохраняет куда надо.

**Плюсы:** ноль железа, стабильное качество, масштабируется.
**Минусы:** оплата иностранной картой (Deepgram, AssemblyAI), данные уходят наружу — проверь 152-ФЗ.

## 3. Локально (приватность + большой объём)

Когда: данные не отдаёшь наружу (юр. ограничения, NDA, коммерческая тайна), либо >1000 минут/месяц — локально дешевле чем cloud-API.

**WhisperX** — топовое open-source решение. Whisper для текста + pyannote для диаризации, одна установка.

```bash
pip install whisperx
whisperx call.mp3 --model large-v3 --diarize --hf_token hf_xxx --language ru
```

На выходе JSON с сегментами, где каждой фразе присвоен `SPEAKER_00`, `SPEAKER_01` и таймкоды. Claude Code парсит и понимает кто говорил.

HuggingFace token бесплатный: hf.co → Settings → Access Tokens → согласиться с условиями `pyannote/speaker-diarization-3.1`.

**Железо:**
- Mac M1/M2/M3 — через MPS, реальное время ≈ 0.3× длины записи
- NVIDIA GPU (8 ГБ VRAM) — 0.1×
- CPU без GPU — 1-2×, но работает на любом ноуте

**Плюсы:** полная приватность, 0 ₽ после настройки, можно дообучить на своём домене.
**Минусы:** нужно железо и час на настройку, качество на сложных акцентах чуть ниже cloud.

**Репозитории:**
- [WhisperX](https://github.com/m-bain/whisperX) · 21 352⭐
- [whisper.cpp](https://github.com/ggerganov/whisper.cpp) · 48 696⭐ — на C++, быстрее на CPU
- [pyannote-audio](https://github.com/pyannote/pyannote-audio) · 9 773⭐ — сам движок диаризации

## 4. GUI для разовых задач

Если код не пишешь и нужно раз в неделю разобрать запись.

- **[MacWhisper Pro](https://goodsnooze.gumroad.com/l/macwhisper)** — $59, macOS only, drag-and-drop, есть диаризация
- **[Buzz](https://github.com/chidiwilliams/buzz)** — 18 716⭐, бесплатно, Win/Mac/Linux, GUI на whisper.cpp, без диаризации
- **[Hyprnote](https://github.com/fastrepl/hyprnote)** — 8 266⭐, бесплатно, специально для встреч Zoom/Meet с саммари через локальный LLM

## Дерево решений: что выбрать

<div class="decision-tree" markdown>

**У тебя уже есть CRM или облачная АТС?**
→ Включи встроенный транскриб (Bitrix, MANGO, Zadarma). Готово, больше ничего не надо.

**Нет СРМ или встроенное плохое?** Записей много (>100/день)?
→ Cloud API: Deepgram (международная карта) или Yandex SpeechKit (российская).

**Данные нельзя отдавать наружу?** Есть Mac M1+ или NVIDIA GPU?
→ WhisperX локально. Бесплатно, приватно.

**Нужно 1-2 раза в неделю разово?**
→ MacWhisper Pro ($59) или Buzz (бесплатно).

**Хочешь сам в своём приложении?**
→ Whisper API / AssemblyAI — самая быстрая интеграция.

</div>

## Нюансы для всех способов

- **Диаризация** нужна когда один говорит за другим без разделения каналов. Если запись в стерео (менеджер и клиент в разных каналах звуковой дорожки) — диаризация не нужна, каждый канал = отдельный говорящий.
- **Русский** — лучшее качество: Yandex SpeechKit > Whisper large-v3 > Deepgram > Google Speech-to-Text.
- **Короткие записи (<30 сек)** — диаризация может путать. Для коротких лучше отключить и роль присваивать по контексту (кто инициатор звонка = менеджер).
- **Фон, шум, музыка ожидания** — снижают точность на 20-30%. Прогони через RNNoise или DeepFilterNet перед транскрипцией.
- **152-ФЗ (РФ)** — запись звонков с клиентами только при согласии. Стандартно — в договоре или автоинформаторе «разговор будет записан» при дозвоне. Без этого запись незаконна.
- **Стоимость vs объём:** до ~500 мин/мес cloud-API дешевле; >1000 мин/мес локально окупает железо; встроенное в СРМ — часто самое выгодное при интеграции в рабочий процесс.

## Бесплатные фишки до любой установки

- **Telegram Premium** — голосовые автоматом транскрибируются (₽3-5 в мес)
- **ChatGPT Plus** — загрузи аудио в чат, транскрибирует сам ($20/мес, без диаризации)
- **YouTube автосубтитры + yt-dlp** — транскрипт любого YouTube-ролика без установок
- **Zoom Free** — базовое транскрибирование встреч до 40 минут

## Сравнение всех классов решений

| Решение | Цена | Диаризация | Приватность | Для кого |
|---|---|---|---|---|
| **Встроено в CRM** | ₽-подписка | ✅ | данные у провайдера | Все у кого есть Bitrix/AmoCRM/облачная АТС |
| **Cloud API** | $0.004-0.007/мин | ✅ | данные у провайдера | Свой продукт, нет встроенного |
| **Локально (WhisperX)** | бесплатно | ✅ | полная | Приватно + много записей |
| **GUI (MacWhisper / Buzz)** | 0-$59 разово | зависит | локально | Разовые задачи, без кода |

## Кому подходит

- 🤖 **Агент (Claude Code)** — через API встроенной СРМ (проще всего), cloud API (гибко) или локальный WhisperX (приватно)
- 💬 **Чатбот (ChatGPT/Claude в браузере)** — загрузка файла вручную, без автоматизации
- **Для бизнеса:** отделы продаж, поддержка, HR-интервью, медицина, юристы
- **Для контента:** подкасты (таймкоды), журналисты (цитаты), SMM (нарезки из эфиров)

## Совместимость

- **Встроенное в российские CRM и АТС** — работает из РФ без VPN, оплата в рублях
- **WhisperX локально** — без VPN, модели Whisper иногда через зеркало HuggingFace
- **Cloud API (Deepgram, AssemblyAI, OpenAI)** — запросы идут без VPN; оплата — только иностранной картой. Для Yandex SpeechKit работает российская карта и юр.лицо.
