# 🎬 Remotion

!!! info "🤖 Для агентов (Claude Code / Cursor / Codex)"
    Этот инструмент требует установки и файлового доступа. Если ты в браузере с ChatGPT — см. [альтернативы](#как-попробовать-без-чёрного-окна-с-командами) ниже.

> Делаешь видео кодом, а не в Premiere. Пишешь React-компонент — получаешь ролик. Шаблонизация на максималках.

## Что делает

Надо делать однотипные видео: превью YouTube, рилсы, отчёты. Руками каждый раз — месяц жизни. Remotion превращает видео в код: компонент принимает данные, рендерит кадры, собирает MP4.

Пример: каждую неделю дайджест новостей в видеоформате. С Remotion ты берёшь текст и картинки — а Remotion за 30 секунд собирает полноценный ролик с анимациями.

44 тысячи звёзд. Активно используется в продакшне — студии, медиа, соцсети.

## Кому подходит

- ✅ Умеешь React (или готов разобраться — базово не сложно)
- ✅ Нужно много однотипных видео (шаблоны, автогенерация)
- ✅ Хочешь чтобы ИИ генерил видео по тексту
- ❌ НЕ подходит для разовых роликов — быстрее в Premiere
- ❌ Если совсем не кодишь — порог входа высокий

## Как попробовать без чёрного окна с командами

Remotion это код-инструмент — без чёрного окна с командами и React его не запустить. Но для шаблонного видео с ИИ есть более простые варианты:

- **[Canva](https://canva.com)** — в 2025 добавили AI video generator. Описал словами — получил ролик. Без кода
- **[Runway](https://runway.ml)** — text-to-video от OpenAI-конкурентов, работает в браузере
- **[Descript](https://descript.com)** — редактор видео с ИИ, можно собирать ролик как документ
- **[Pika](https://pika.art)** / **[Kling AI](https://kling.ai)** — генерация видео из текста

Если цель «автоматизировать однотипные ролики» — Remotion сильнее, но Canva хватит для большинства задач.

??? note "Для программистов (через чёрное окно с командами)"

    ```bash
    npx create-video@latest
    ```

    Выберешь шаблон (Hello World, TikTok, YouTube) — получишь готовый проект.

    **Первый запуск:**

    1. `npx create-video@latest my-video`
    2. `cd my-video && npm start` — открывается студия в браузере
    3. В папке `src/` — твои React-компоненты (это кадры)
    4. Правишь компоненты — видишь превью в реальном времени
    5. Готово → `npm run build` — получаешь MP4

## Связка с ИИ

Пишешь Claude: «сгенерируй Remotion-компонент для 15-секундного ролика с текстом Х и фоном Y». Агент пишет компонент — ты рендеришь.

Комбо: ИИ генерит сценарий → ИИ пишет Remotion-код → рендер → публикация.

## Нюансы

- Рендер тяжёлый — 1 минута видео может рендериться 2-5 минут
- Можно выгрузить в облако (Remotion Lambda) — параллельно работает на AWS
- Документация на английском, русских гайдов мало
