# 🔌 Интеграции (MCP)

MCP — это способ дать ИИ доступ к твоим сервисам. Gmail, Slack, GitHub, CRM, базы данных. ИИ не просто советует, а САМ делает: отправляет письма, создаёт задачи, читает документы.

Без MCP — ИИ это болтун. С MCP — это сотрудник.

## Популярное

- :material-puzzle: **[Composio](composio.md)** — 28K⭐, 1000+ готовых интеграций

- :material-recursive: **[Claude Code MCP](claude-code-mcp.md)** — 1.1K⭐ агент запускает другого агента

</div>

## Как выбрать

- **Нужен один конкретный сервис** → ищи готовый MCP (Gmail, Slack, Notion…)
- **Много всего сразу** → Composio (один установ — 1000+ сервисов)
- **Скрапинг / парсинг сайтов** → Firecrawl
- **Работаешь с Docker** → Docker MCP Toolkit (каталог внутри)
