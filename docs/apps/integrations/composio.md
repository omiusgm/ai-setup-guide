# 🔌 Composio

> Один установ — и у ИИ-агента сразу 1000+ готовых интеграций. Gmail, Slack, GitHub, Jira, Notion, HubSpot — всё подключается через MCP.

## Что делает

Вместо того чтобы каждый сервис подключать отдельно — ставишь Composio, и у агента сразу доступ ко всему. Отправить письмо через Gmail? Создать задачу в Jira? Прочитать документ в Notion? Всё через одну API.

28 тысяч звёзд. ComposioHQ активно развивают, новые интеграции появляются каждую неделю. Поддержка Claude Code, LangChain, автоматизация CrewAI.

## Кому подходит

- ✅ Бизнесу: нужно подключить много сервисов сразу
- ✅ Агент должен работать с Gmail, Slack, CRM, таск-трекером
- ✅ Хочешь один стандарт для всех интеграций
- ❌ НЕ подходит если нужен один-два сервиса — проще взять отдельные MCP
- ❌ Для простых промптов — избыточно

## Установка

```bash
pip install composio-core
```

Для Claude Code:

```bash
composio add claude
```

## Первый запуск

1. Создал аккаунт на [composio.dev](https://composio.dev)
2. Получил API ключ
3. `composio login` — привязал аккаунт
4. Подключил сервисы через OAuth: `composio add gmail`, `composio add slack`
5. В агенте — сразу доступны 1000+ инструментов

## Примеры задач

- «Найди в Gmail письма от клиента X, создай по ним задачи в Linear»
- «Посмотри вчерашние PR в GitHub, напиши саммари в Slack»
- «Возьми данные из HubSpot, собери отчёт в Notion»

## Нюансы

- Требует OAuth к каждому сервису — с SaaS-аккаунтами работает, с корпоративными может быть сложнее
- Есть платный план — но для старта бесплатного хватает
- Некоторые интеграции в РФ недоступны из-за санкций (Jira Cloud, Slack)
