# 🔗 n8n-MCP

> Claude Code сам создаёт, редактирует и запускает n8n workflows. ИИ собирает автоматизации, ты только проверяешь.

## Что делает

n8n — визуальный конструктор автоматизаций. Обычно ты сам мышкой двигаешь блоки. С n8n-MCP это делает Claude: описал задачу словами — агент сгенерил весь workflow.

18 тысяч звёзд. Автор — czlonkowski. Интеграция через MCP-протокол.

Пример: «Когда в Gmail приходит письмо от клиентов — проанализируй тональность через ИИ, если негатив — отправь в Slack канал поддержки». Агент создаст цепочку блоков в n8n, подключит, запустит.

## Кому подходит

- ✅ У тебя уже есть n8n (self-host или облако)
- ✅ Хочешь описывать автоматизации словами, а не мышкой
- ✅ Много похожих workflows — ИИ тиражирует быстрее
- ❌ НЕ подходит если n8n пока нет — сначала поставь его
- ❌ Для простых цепочек — быстрее мышкой

## Как попробовать без терминала

n8n-MCP нужен чтобы Claude Code собирал workflows за тебя. Но если не хочешь возиться с терминалом — n8n прекрасно управляется мышкой и без ИИ:

1. **[n8n Cloud](https://n8n.cloud)** — веб-интерфейс, перетаскиваешь блоки
2. В n8n встроен **AI Assistant** (в правом нижнем углу интерфейса) — можешь описать workflow словами, он предложит структуру. Без MCP, без Claude Code
3. Готовые шаблоны в **[n8n Templates](https://n8n.io/workflows)** — сотни примеров, клонируешь и правишь под себя

Для простых автоматизаций этого хватает. MCP нужен только если хочешь генерить workflows пачками и сразу деплоить.

??? note "Для продвинутых (терминал)"

    ```bash
    npm install -g @czlonkowski/n8n-mcp
    ```

    Подключить к Claude Code:

    ```bash
    claude mcp add n8n -- n8n-mcp
    ```

    В `.env` указать:

    ```
    N8N_URL=https://твой-n8n.ru
    N8N_API_KEY=твой-ключ
    ```

    **Первый запуск:**

    1. В n8n включил API доступ (Settings → API)
    2. Скопировал API ключ в `.env`
    3. Перезапустил Claude Code
    4. В агенте: «создай workflow: каждый день в 9 утра собирай метрики с Google Analytics и пиши в Slack»
    5. Агент генерит блоки, подключает, тестирует

## Примеры

- «Скопируй мой workflow Х, но замени Gmail на Outlook»
- «Собери workflow для мониторинга моего сайта каждые 5 минут»
- «Добавь блок уведомления в Telegram к workflow продаж»
