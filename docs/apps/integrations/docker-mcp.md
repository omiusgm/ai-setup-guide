# 🐳 Docker MCP Toolkit

> 300+ готовых MCP-плагинов в каталоге Docker Desktop. Установка в один клик — никаких npm, pip, терминала.

## Что делает

Docker Desktop добавил раздел «MCP Toolkit». Открываешь — видишь каталог на 300+ MCP-серверов: Gmail, Slack, GitHub, базы данных, AWS, платежки. Каждый ставится в один клик. Не надо возиться с конфигами.

Сами MCP запускаются в Docker-контейнерах — изолированно, не мусорят в системе. Удалил — ничего не осталось.

## Кому подходит

- ✅ Docker Desktop уже стоит
- ✅ Хочешь пробовать MCP без боли с установкой
- ✅ Работаешь с корпоративными сервисами (AWS, Azure, GCP)
- ❌ НЕ подходит если не хочешь ставить Docker
- ❌ На слабом компе — Docker ест ресурсы

## Установка

1. Скачай Docker Desktop с [docker.com](https://www.docker.com/products/docker-desktop)
2. Установи (обычный установщик)
3. Открой — слева в панели появится «MCP Toolkit»

## Первый запуск

1. Открыл MCP Toolkit вкладку
2. Видишь каталог плагинов: GitHub, Gmail, Postgres, AWS, Jira…
3. Нажал Install на нужный
4. Плагин запустился в контейнере
5. Теперь он доступен в Claude Code / другим MCP-клиентам

## Примеры

- **GitHub MCP** — ИИ читает/пишет issue, PR, код
- **Postgres MCP** — ИИ выполняет SQL-запросы
- **AWS MCP** — ИИ управляет облаком
- **Gmail MCP** — читает/пишет письма

## Нюансы

- Docker Desktop ест 2-4 ГБ RAM — на слабых компах тяжело
- Некоторые MCP требуют API ключи — подставь в настройках
- Не все MCP одинаково качественные — смотри рейтинг в каталоге
