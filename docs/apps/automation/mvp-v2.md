# MVP v2: контент-пайплайн

!!! info "🤖 Суть"
    Это не 24/7-Claude. Это **24/7-система**, которая собирает сигналы, а Claude включается только там, где нужен текст, редактура и выводы.

## Цель

Собрать рабочий контур, где:

1. новые сигналы попадают в базу
2. мусор отфильтровывается правилами
3. полезное хранится в Google Sheets
4. Claude превращает находки в посты и дайджесты
5. результат уходит на сайт и в Telegram

## Поток данных

```text
sources → filter → Google Sheets → Claude editor → publish
```

## Таблица как опорный слой

Подробная схема таблицы описана здесь:

- [Google Sheets: рабочая база](google-sheets-schema.md)

### 1) Sources

Источники, которые стоит подключать первыми:

- GitHub: новые репозитории по AI / agents / vibe-coding
- RSS и блоги: релизы, апдейты, changelog-посты
- Hacker News / ленты новостей
- YouTube через Gemini
- вручную добавленные находки из чата и заметок

### 2) Filter

Фильтр отвечает за вопрос: **стоит ли тащить это дальше?**

Claude здесь не нужен.

Подход:

- keyword match
- простые правила приоритета
- дедупликация
- score по теме, новизне и практической пользе

Пример сигнала:

- `score >= 70` → в работу
- `score 40–69` → в таблицу, но без публикации
- `< 40` → архив / игнор

### 3) Google Sheets

Таблица — это рабочая база.

Минимальные колонки:

- `date`
- `type`
- `title`
- `source`
- `url`
- `raw_note`
- `summary`
- `score`
- `status`
- `owner`
- `published_url`

Статусы можно держать простыми:

- `new`
- `review`
- `approved`
- `published`
- `archived`

### 4) Claude editor

Claude нужен как:

- копирайтер
- редактор
- аналитик текста
- сборщик итогов недели

Что он делает:

- объясняет, почему находка важна
- переписывает сырой сигнал в понятный пост
- делает короткий summary
- собирает weekly digest
- помогает с формулировками для сайта

Что он не делает:

- не держит систему 24/7
- не принимает решение о важности сам по себе
- не заменяет фильтр и правила

### 5) Publish

Публикация может идти в несколько каналов:

- MkDocs-сайт
- Telegram
- Google Sheets как журнал
- позже — другие каналы, если они понадобятся

## Что считается успехом

- система сама приносит новые сигналы
- таблица обновляется без ручного таскания всего в чат
- Claude пишет только на верхнем слое
- сайт и Telegram получают готовый результат

## Антипаттерны

- пытаться сделать всё через один большой агент
- тащить Claude в роль круглосуточного диспетчера
- хранить данные только в чате
- не иметь статусов и не понимать, что уже опубликовано
