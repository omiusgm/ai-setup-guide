# ☁️ Routines (Claude Code)

> Облачный аналог `/loop`. Задачи выполняются на серверах Anthropic. Комп выключен — задача работает.

## Что делает

Новая фича Claude Code (апрель 2026). Планируешь задачу через `/schedule` — она уходит в облако Anthropic и выполняется по расписанию. Комп может быть выключен, ноут в сумке — всё равно работает.

Пример: каждое утро в 9:00 собирает для тебя сводку по новостям из 10 источников. Или каждый час проверяет состояние продакшена. Или раз в неделю переписывает README на основе последних коммитов.

## Кому подходит

- ✅ Есть подписка Claude Pro / Max / Team
- ✅ Нужны задачи 24/7 без компа
- ✅ Простые повторяющиеся скрипты
- ❌ НЕ подходит если надо интерактив — облако не спрашивает подтверждений
- ❌ Если нужен сложный workflow — [n8n](n8n.md) гибче

## Как попробовать без терминала

Routines работают прямо на **[claude.ai](https://claude.ai)** в браузере — никакой установки. Нужна только подписка Claude:

- **Pro** — 5 задач/день
- **Max** — 15 задач/день
- **Team** — 25 задач/день

**Запуск:**

1. Зайди на [claude.ai](https://claude.ai), открой любой диалог
2. Напиши: «создай Routine — каждое утро в 9:00 собирай топ-5 новостей из HackerNews и сохраняй саммари в Google Doc»
3. Claude спросит детали, подтвердишь — задача уходит в облако
4. Результаты приходят в диалог, проверяешь когда удобно

Всё через веб-интерфейс, без команд.

??? note "Для продвинутых (через /schedule в Claude Code)"

    Если работаешь в Claude Code или на claude.ai через API — вот команда:

    ```
    /schedule daily 9:00
    Задача: собери топ-5 новостей из HackerNews и напиши саммари в Markdown.
    Результат сохрани в notes/daily-digest.md
    ```

    1. Ввёл команду — появилось подтверждение
    2. Указал: расписание (cron), что делать, где сохранять результат
    3. Облако выполняет, результаты приходят в Claude

## Примеры

- Ежедневный сводный отчёт по метрикам
- Мониторинг цен конкурентов раз в неделю
- Утренний дайджест новостей по теме
- Автобэкап важных данных

## Нюансы

- Лимит задач/день привязан к плану — следи
- Нет полного доступа к твоей файловой системе — только к подключённым MCP
- Фича свежая, кое-где баги
