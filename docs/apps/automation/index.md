# ⚡ Автоматизация

Одноразовый запуск — это не автоматизация. Нажал `/run` один раз, получил результат, закрыл ноут — и всё опять надо делать руками завтра.

Настоящая автоматизация — когда оно само. Каждое утро в 9:00 собирает дайджест. Каждое новое письмо — проверяет на срочность. Каждую ночь — бэкап. Ты один раз настроил и забыл.

## Почему `/run` недостаточно

Команда запуска — это старт одного шага. Автоматизация требует трёх вещей:

**Расписание или триггер.** Что-то должно дёрнуть задачу. Либо время (cron, каждый день в 9:00), либо событие (пришло письмо, появился коммит).

**Цикл.** Задача не одноразовая. Она повторяется день за днём, иногда с правками. Значит нужно место где она живёт.

**Обработка ошибок.** Пропустил день? Упал API? Надо логировать, ретраить, алертить. Иначе автоматизация тихо ломается и ты узнаёшь через месяц.

Просто запустить скрипт один раз — это не автоматизация. Это напоминание.

## Бесплатные фишки

**cron + shell-скрипт**

Если задача простая и ты на Linux/Mac — `cron` уже есть в системе. Пишешь скрипт, добавляешь в `crontab -e`, готово:

```bash
# Каждый день в 9:00
0 9 * * * /Users/me/scripts/daily.sh
```

Нормально для: бэкапы, синк файлов, отправка отчётов. Не нужен ни n8n, ни Zapier.

**Telegram Bot API напрямую**

Если надо «отправлять сообщения в канал» — не надо городить автоматизацию. Три строки на Python:

```python
import requests
requests.post(f"https://api.telegram.org/bot{TOKEN}/sendMessage",
              json={"chat_id": CHANNEL, "text": "Привет"})
```

Работает везде, бесплатно, без подписок.

**GitHub Actions**

Если код в гитхабе — Actions даёт cron и триггеры из коробки. 2000 минут в месяц бесплатно. Работает когда комп выключен, сам тянет репо, запускает.

**Scheduled tasks в Claude Code**

Встроенная штука — задачи которые Claude запускает по расписанию. Есть в самом Claude Code, отдельно ничего ставить не надо.

## Если фишек мало

- :material-connection: **[n8n](n8n.md)** — 184K⭐ визуальный конструктор, собираешь мышкой
- :material-loop: **[/loop](loop.md)** — встроенная команда Claude Code, агент крутится в цикле
- :material-calendar-clock: **[Routines](routines.md)** — Claude Code в облаке, работает когда комп выключен

**Как выбрать:**
- Вообще не кодишь → n8n, визуальный, self-host на Beget за 210 руб/мес
- Цикл на своём компе → /loop, включил, ушёл, вернулся к результату
- 24/7 без компа → Routines (Pro: 5/день, Max: 15/день)
