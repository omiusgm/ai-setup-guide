# ⚡ Автоматизация

Всё что тебе скучно повторять — можно отдать машине. Эти инструменты заставят ИИ работать, пока ты спишь, ешь, смотришь сериал.

Собрал цепочку один раз — она крутится сама. Проверяет почту, обновляет CRM, пишет отчёты.

## Три пути

<div class="app-list" markdown>

- :material-connection: **[n8n](n8n.md)** — 184K⭐ визуальный конструктор, собираешь мышкой
- :material-loop: **[/loop](loop.md)** — встроенная команда Claude Code, агент крутится в цикле
- :material-calendar-clock: **[Routines](routines.md)** — Claude Code в облаке, работает когда комп выключен

</div>

## Что выбрать

- **Вообще не кодишь** → n8n. Визуальный, есть шаблоны, self-host на Beget за 210 руб/мес
- **Хочешь цикл на своём компе** → /loop. Включил, ушёл, вернулся к результату
- **Хочешь чтобы работало 24/7 без компа** → Routines (Pro: 5/день, Max: 15/день)

---

*Автоматизация — не магия. Это повторяющиеся шаги, которые кто-то должен делать. Пусть делает машина.*
