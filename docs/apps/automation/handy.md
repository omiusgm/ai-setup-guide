## Зачем это нужно

Печатать медленнее чем говорить. Исследования показывают: средняя скорость печати — 40 слов в минуту, средняя скорость речи — 150 слов в минуту. **Разница в 3-4 раза.**

При этом большинство голос-в-текст решений:

- **Платные** — Superwhisper, MacWhisper, Wispr Flow — от $10-30/мес
- **Облачные** — отправляют голос на сервер (конфиденциальность? что ты сказал в чат — уже не у тебя)
- **Корявые** — встроенный диктофон в macOS медленный, не понимает технические термины
- **Привязаны к системе** — Siri/Google Assistant жёстко в рамках экосистемы

Handy решает все четыре проблемы сразу. Бесплатный, open-source, локальный, работает в любом приложении.

## Как это работает

**Push-to-talk режим (по умолчанию):**

1. Зажимаешь горячую клавишу (например, правый ⌥ Option)
2. Говоришь пока держишь
3. Отпускаешь → текст вставляется в активное поле

**Toggle режим:**

1. Нажал → начал запись
2. Говоришь свободно
3. Нажал ещё раз → запись остановлена, текст вставлен

Под капотом работает **Whisper от OpenAI** — модель лежит локально на твоём ноуте, голос никуда не улетает.

## Почему это топ

Из всех инструментов которые мы смотрели для сайта — Handy один из тех которые **реально меняют повседневку**. Устанавливается за 2 минуты, работает в любом приложении, и через неделю ты уже не представляешь как раньше жил без него.

Пример практики: написать пост в Telegram или сообщение в чат — говоришь 10 секунд, получаешь готовый абзац. Редактировать голосом промпт для ChatGPT — 30 секунд вместо 2 минут набора. Диктовать Claude Code инструкции пока смотришь в код — руки остаются на клавиатуре для правок.

## Кому подходит

- ✅ **Много пишешь в чаты/соцсети/мессенджеры** — экономия часов в неделю
- ✅ **Пишешь промпты ИИ** — голосом быстрее + естественнее
- ✅ **Копирайтер, SMM, блогер** — черновики диктуешь, потом правишь
- ✅ **Работаешь с Claude Code / Cursor** — многословные инструкции голосом быстрее
- ✅ **Важна приватность** — всё локально, голос не уходит в облако
- ❌ НЕ подходит если у тебя старый ноут без мощного CPU/GPU — Whisper требует ресурсов
- ❌ НЕ подходит для специфических медицинских/юридических терминов без дообучения модели

## Нюансы ДО установки

**Размер модели:** Whisper поставляется в разных размерах. `base` = 150 МБ, но хуже с русским. `small` = 500 МБ, нормально для русского. `medium` = 1.5 ГБ, отлично. Скачивается один раз при первом запуске.

**Ресурсы:** На Apple Silicon (M1/M2/M3) — очень быстро. На Windows/Linux с CUDA — быстро. На старых Intel-маках — работает, но с задержкой 1-2 сек.

**Хоткей:** Выбирай такой который не конфликтует с системой. Частые варианты: правый ⌥ Option (Mac), правый Ctrl (Win/Linux). НЕ ставь Cmd+Space — там Spotlight/поиск.

**Язык:** Whisper мультиязычный, русский понимает хорошо. При первом запуске выбери русский в настройках, иначе будет транскрибировать как английский.
