# 🔁 /loop

> Встроенная команда Claude Code. Агент крутится в цикле, пока не сделает задачу. Ты ушёл спать — он работает.

## Что делает

Обычный агент делает один проход: спросил — ответил. `/loop` превращает это в цикл: «делай X каждые 30 минут», «проверяй Y пока не пофиксишь». Агент продолжает работать без твоего участия.

Это не внешний инструмент и не скилл. Это встроенная возможность Claude Code. Просто запускаешь команду `/loop` — указываешь интервал и задачу.

## Кому подходит

- ✅ Уже в Claude Code
- ✅ Есть повторяющаяся задача: мониторинг, проверка, обновление
- ✅ Хочешь «пусть работает, пока я сплю»
- ❌ НЕ подходит если нужно 24/7 с выключенным компом (используй [Routines](routines.md))
- ❌ Для сложных ветвлений — лучше [n8n](n8n.md)

## Установка

Ничего не надо — команда встроена в Claude Code. Если у тебя стоит Claude Code, она уже доступна.

Проверить: в чате введи `/loop` — должна подсказка появиться.

## Первый запуск

```
/loop 1h проверь новые issue в GitHub и напиши сводку
```

Что произойдёт:

1. Агент выполнит задачу первый раз
2. Подождёт 1 час
3. Выполнит снова
4. И так до остановки (Ctrl+C)

Второй вариант — без интервала, агент сам решает когда продолжать:

```
/loop проверяй продакшн пока не будет зелёным
```

## Примеры

- `/loop 30m проверь метрики сайта, алерт если падение >20%`
- `/loop 1h сканируй Twitter на упоминания бренда`
- `/loop пока не пофикшены все тесты — ищи ошибки и правь`

## Нюансы

- Комп должен быть включён — если заснёт, цикл остановится
- Жрёт токены непрерывно — следи за балансом
- Для долгих циклов лучше [Routines](routines.md) — облачный аналог
