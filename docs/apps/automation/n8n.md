# 🔗 n8n

!!! info "🤖💬 Для чатботов И агентов"
    Работает и в браузере (облачная версия / альтернатива), и через агента (установка). Ниже оба варианта.

> Визуальный конструктор автоматизаций. Собираешь цепочку мышкой: бот ответил — таблица обновилась — отчёт улетел.

## Что делает

Представь Zapier, но бесплатный и с открытым кодом. В n8n ты соединяешь сервисы как блоки: «когда приходит письмо → вытащи вложение → отправь в ИИ → результат запиши в Notion».

Код не нужен. Вся цепочка (workflow) рисуется стрелочками. Внутри блока — настройки (ключ для подключения, фильтр, условия). Всё.

184 тысячи звёзд. Один из самых популярных no-code инструментов (автоматизация без программирования) в мире. В апреле 2026 добавили фичу «агенты общаются между собой» — один ИИ может дёргать другого.

## Кому подходит

- ✅ Бизнес: автоматизация отчётов, лидов, CRM
- ✅ Не кодишь, но хочешь убрать рутину
- ✅ Нужен контроль — можно установить у себя, данные у тебя
- ❌ НЕ подходит для разовых задач — лучше скрипт написать
- ❌ Если совсем не любишь разбираться — порог входа не нулевой

## Как попробовать без чёрного окна с командами

**Самый быстрый способ — n8n Cloud:**

1. Заходи на [n8n.cloud](https://n8n.cloud) — 14 дней бесплатный триал, дальше $20/мес
2. Регистрация по email, ничего ставить не надо
3. Через 30 секунд — готовое рабочее окно с автоматизациями

Это тот же самый n8n, просто на их серверах. Можно собирать автоматизации, подключать сервисы, экспериментировать. Если захочешь установить у себя — цепочки переносятся экспортом в файл.

??? note "Для программистов (установка у себя через Docker)"

    **На сервере (Beget за 210 руб/мес подойдёт). Docker — это программа-контейнер, запускает приложения в изоляции:**

    ```bash
    docker run -it --rm \
      --name n8n \
      -p 5678:5678 \
      -v ~/.n8n:/home/node/.n8n \
      docker.n8n.io/n8nio/n8n
    ```

    Дальше открываешь `localhost:5678` (или адрес Beget) и работаешь.

    Плюсы установки у себя: данные у тебя, без подписки. Минусы: нужен сервер (VPS) и минимум 1 ГБ RAM.

## Первый запуск

1. Открыл `localhost:5678` (или адрес Beget)
2. Создал аккаунт
3. Новая автоматизация — перетаскиваешь блоки из панели
4. Первый блок — триггер (что запускает цепочку)
5. Дальше — шаги (читай Gmail → проанализируй ИИ → запиши в Google Sheets)
6. Сохранил, включил — работает 24/7

## Примеры

- **SMM:** Новый коммент → анализ тональности ИИ → негативные в Slack тебе
- **Лиды:** Форма на сайте → обогащение через ИИ → запись в AmoCRM
- **Отчёты:** Каждое утро → собираем продажи из базы → ИИ пишет саммари → в Telegram

## Нюансы

- Установка у себя требует сервера — минимум 1 ГБ RAM
- Для связки с Claude нужен [n8n-MCP](../integrations/n8n-mcp.md) — чтобы ИИ сам собирал цепочки (MCP — это способ дать ИИ руки, подключить его к внешним программам)
- Фича «агенты общаются» пока в бета-версии, не на продакшне
