# 🔗 n8n

> Визуальный конструктор автоматизаций. Собираешь цепочку мышкой: бот ответил — таблица обновилась — отчёт улетел.

## Что делает

Представь Zapier, но бесплатный и open-source. В n8n ты соединяешь сервисы как блоки: «когда приходит письмо → вытащи вложение → отправь в ИИ → результат запиши в Notion».

Код не нужен. Весь workflow рисуется стрелочками. Внутри блока — настройки (API ключ, фильтр, условия). Всё.

184 тысячи звёзд. Один из самых популярных no-code инструментов в мире. В апреле 2026 добавили agent-to-agent фичу — агенты могут дёргать друг друга.

## Кому подходит

- ✅ Бизнес: автоматизация отчётов, лидов, CRM
- ✅ Не кодишь, но хочешь убрать рутину
- ✅ Нужен контроль — можно self-host, данные у тебя
- ❌ НЕ подходит для разовых задач — лучше скрипт написать
- ❌ Если совсем не любишь разбираться — порог входа не нулевой

## Как попробовать без терминала

**Самый быстрый способ — n8n Cloud:**

1. Заходи на [n8n.cloud](https://n8n.cloud) — 14 дней бесплатный триал, дальше $20/мес
2. Регистрация по email, ничего ставить не надо
3. Через 30 секунд — готовое рабочее окно с workflow

Это тот же самый n8n, просто на их серверах. Можно собирать автоматизации, подключать сервисы, экспериментировать. Если захочешь self-host — workflows переносятся экспортом JSON.

??? note "Для продвинутых (self-host через Docker)"

    **На сервере (Beget за 210 руб/мес подойдёт):**

    ```bash
    docker run -it --rm \
      --name n8n \
      -p 5678:5678 \
      -v ~/.n8n:/home/node/.n8n \
      docker.n8n.io/n8nio/n8n
    ```

    Дальше открываешь `localhost:5678` (или адрес Beget) и работаешь.

    Плюсы self-host: данные у тебя, без подписки. Минусы: нужен VPS и минимум 1 ГБ RAM.

## Первый запуск

1. Открыл `localhost:5678` (или адрес Beget)
2. Создал аккаунт
3. Новый workflow — перетаскиваешь блоки из панели
4. Первый блок — триггер (что запускает цепочку)
5. Дальше — шаги (читай Gmail → проанализируй ИИ → запиши в Google Sheets)
6. Сохранил, включил — работает 24/7

## Примеры

- **SMM:** Новый коммент → анализ тональности ИИ → негативные в Slack тебе
- **Лиды:** Форма на сайте → обогащение через ИИ → запись в AmoCRM
- **Отчёты:** Каждое утро → собираем продажи из БД → ИИ пишет саммари → в Telegram

## Нюансы

- Self-host требует сервера — минимум 1 ГБ RAM
- Для интеграции с Claude нужен [n8n-MCP](../integrations/n8n-mcp.md) — чтобы ИИ сам строил workflows
- Agent-to-agent фича пока бета, не на проде
