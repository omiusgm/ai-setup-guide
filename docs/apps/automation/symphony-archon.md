# Symphony + Archon

!!! info "🤖 Два разных слоя"
    **Symphony** распределяет работу и следит за процессом. **Archon** проверяет качество и не даёт закрыть задачу, пока результат не проходит проверки.

Это полезный паттерн для автономного стека:

- **Symphony** = оркестратор / менеджер
- **Archon** = quality gate / строгий техлид
- **Linear** = очередь задач
- **Claude / Codex** = исполнитель

## Как это работает

### 1) Появляется тикет

Кто-то создаёт задачу в Linear.

### 2) Symphony подхватывает тикет

Symphony:

- видит новую задачу
- создаёт изолированное рабочее пространство
- назначает исполнителя
- передаёт краткий бриф
- отслеживает статус задачи

Важно: Symphony **не обязан** разбираться в коде глубоко. Его задача — логистика и координация.

### 3) Агент пишет код

Claude / Codex / другой исполнитель делает работу в своей папке или ветке.

### 4) Archon проверяет результат

Archon запускает quality gate:

- линтеры
- typecheck
- тесты
- базовые проверки архитектуры
- при необходимости AI-review

Если что-то упало — задача не закрывается.

### 5) Петля исправлений

Archon возвращает ошибки обратно исполнителю.

Агент исправляет код и снова проходит проверки.

### 6) Только потом Done

Когда quality gate пройден:

- Symphony переводит тикет в `Done`
- результат считается готовым

## Главная ошибка

Если есть только Symphony без Archon, получится опасная схема:

- агент написал плохой код
- сказал «готово»
- Symphony поверил
- тикет закрыт

Это нельзя считать автономностью. Это просто автоматическое самообмана.

## Правильная связка

```text
Linear ticket → Symphony → isolated workspace → agent → Archon → fix loop → Done
```

## Где это пригодится

- автономные dev-задачи
- багфиксы
- документация с проверкой сборки
- контент-пайплайны, где есть строгий review
- любые задачи, где важен не только запуск, но и проверка результата

## Что должен помнить проект

- оркестратор не равен проверке качества
- агент не должен сам себе ставить `Done`
- quality gate должен быть обязательным
- лучше одна плохая петля с проверкой, чем быстрый но мусорный done
