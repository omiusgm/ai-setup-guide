# 💰 Экономия токенов

ИИ тратит 70% ответа на «Конечно! Я с радостью помогу вам с этой задачей. Давайте разберёмся по порядку...». А ты сидишь, ждёшь пока он доберётся до сути.

И платишь за каждое слово. Если по API — деньгами. Если в чате — временем и раздражением.

## Почему так происходит

Модель училась на миллиардах примеров — и большинство из них были вежливые, структурные, подробные. Академические статьи, туториалы, корпоративная переписка. Отсюда манера — вступление, план, пункты, заключение.

Второе: **токены = деньги**. Один символ ≈ 0.3-0.5 токена. Чем длиннее ответ, тем больше ты заплатил. Плюс чем длиннее твой **ввод** — тем дороже. Загрузил в чат 50 страниц PDF и болтаешь с ним час? Это уже сотни рублей.

Третье: **длинный диалог = тупой ИИ**. Когда контекст забит, модель начинает терять детали, повторяться, путать имена. Она не «устала» — просто уже не видит начало разговора.

## Бесплатные фишки

**Промпт «отвечай кратко»**

Вставь в начало чата:

```
Отвечай кратко, без вступлений и извинений. 
Код — сразу. Объяснения — только если спрашиваю.
```

Срабатывает в ChatGPT, Claude, Gemini. Экономит 50-60% на ровном месте.

**Новый чат вместо 100+ сообщений**

Контекст съедает токены быстрее, чем ты печатаешь. 50 сообщений — уже пора закрывать и открывать новый. Саммари через файл, не через переписку.

**Выбор модели**

Не всё нужно гонять через Opus:

- **Haiku** — простые задачи, ответ в 2 строки, массовые запросы. В 50-100 раз дешевле Opus
- **Sonnet** — обычная работа, код, тексты. Обычно хватает
- **Opus** — сложный дизайн, анализ, длинные цепочки рассуждений

Claude 4.5 Sonnet в 5 раз дешевле Opus. В большинстве задач разница незаметна.

**Кэширование промптов**

Если гоняешь один и тот же системный промпт — включи prompt caching. Платишь один раз, дальше 90% скидка на повторное чтение. Это API-штука, в чатах нет.
