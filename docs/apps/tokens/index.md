# 💰 Экономия токенов

Токены — это деньги. Каждое слово, которое говорит ИИ — стоит. Если модель льёт воду, ты платишь за воду.

Эти инструменты заставляют ИИ отвечать по делу. Экономят до 70% токенов — и твоего времени на чтение.

## Инструменты

<div class="app-list" markdown>

- :material-scissors-cutting: **[Caveman](caveman.md)** — 35K⭐ скилл/промпт для краткости, «говори по-пещерному»
- :material-account: **[Humanizer](humanizer.md)** — 14K⭐ убирает следы ИИ из текста, экономит правки

</div>

## Когда нужно

- **Платишь за API** → Caveman обязательно. Экономит 70% в больших задачах
- **Пишешь для людей** → Humanizer, чтобы текст не пах GPT
- **Хочешь читать быстрее** → Caveman: ответы короче, по сути

---

*Caveman работает даже в обычном ChatGPT — как промпт. Просто вставь в начало чата.*
