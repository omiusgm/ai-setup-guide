# 🦴 Caveman

> Скилл и промпт, который заставляет ИИ отвечать коротко и по делу. Экономит до 70% токенов.

## Что делает

Знаешь как ИИ любит лить воду? «Это отличный вопрос! Давайте рассмотрим несколько аспектов…» На самом деле нужна одна строка ответа. Caveman решает это: вставляешь короткий промпт — ИИ начинает отвечать по-пещерному. Коротко. По делу. Без «конечно, с радостью помогу».

Работает как скилл в Claude Code, либо как обычный промпт в любом чате (ChatGPT, Claude, DeepSeek). Просто копируешь текст — вставляешь в начало диалога.

35 тысяч звёзд. Автор — Julius Brussee.

## Кому подходит

- ✅ Платишь за API — сэкономишь прям заметно
- ✅ Читаешь много ответов ИИ — устал от воды
- ✅ Хочешь чтобы ИИ был как коллега, а не как секретарша
- ❌ НЕ подходит если пишешь художественные тексты — нужна развёрнутая речь

## Как попробовать без терминала

**Скопируй промпт и вставь в ChatGPT / Claude / DeepSeek:**

```
You are a caveman. Keep answers short, direct, no fluff.
No "of course", no "certainly", no preamble.
Just answer. One sentence when possible.
Русский: коротко. По делу. Без воды.
```

1. Новый диалог → вставил промпт первым сообщением
2. Задаёшь вопрос
3. Ответ будет в 3-5 раз короче обычного

Работает с любой моделью: GPT, Claude, DeepSeek, Qwen. Никаких установок.

??? note "Для продвинутых (скилл для Claude Code)"

    ```bash
    npx skills add JuliusBrussee/caveman
    ```

    1. Ставишь через npx — скилл появится в списке
    2. Агент автоматически начнёт отвечать короче
    3. Если забудет — напомни: «caveman mode!»

## Нюансы

- Иногда ИИ забывает и снова начинает лить — напомни («caveman mode!»)
- Для сложных задач лучше отключить — нужен развёрнутый ответ
- Работает с любой моделью: GPT, Claude, DeepSeek, Qwen
