# 🎓 Hermes Agent

> Агент от Nous Research, который учится на скиллах. Работает с любой LLM — OpenAI, Anthropic, локальная через Ollama.

## Что делает

Большинство агентов — одноразовые. Дал задачу, он решил, забыл. Hermes отличается: у него есть «скиллы» — файлы где сохранены удачные паттерны работы. Сделал что-то хорошо — запомнил. В следующий раз делает лучше и быстрее.

Разработчики — Nous Research, это те же люди, что выпускают серию моделей Hermes (Llama-тюны). Репутация серьёзная, не накрутчики звёзд.

93 тысячи звёзд. Работает с любой моделью — от GPT до Qwen на Ollama.

## Кому подходит

- ✅ Нужен агент для регулярных задач — со временем станет точнее
- ✅ Хочешь агента с открытым кодом для своих модификаций
- ✅ Работаешь с локалкой через Ollama
- ❌ НЕ подходит для одноразовых задач — без повторов смысла нет
- ❌ Если ты новичок в агентах — начни с десктопного Goose

## Установка

Через pip:

```bash
pip install hermes-agent
```

Либо clone с GitHub и ставишь из исходников:

```bash
git clone https://github.com/NousResearch/hermes-agent
cd hermes-agent
pip install -e .
```

## Первый запуск

1. `hermes init` в папке проекта
2. Указываешь провайдера модели (OpenAI, Anthropic, Ollama)
3. `hermes chat` — открывается сессия
4. Первые задачи решаются «по-обычному»
5. После нескольких удачных решений сам предлагает сохранить как скилл
6. Скиллы в `.hermes/skills/` — можно править руками

## Нюансы

- Первые 5-10 сессий не увидишь разницы — обучение идёт постепенно
- Если скиллы получились кривые — удали папку и начни заново
- Документация местами хардкорная, требует навыка гугления
