# 🤖 Cline

> Бесплатный агент, который живёт прямо в VS Code. Работает с любой моделью — Claude, GPT, Gemini, локальная через Ollama.

## Что делает

Открыл VS Code, нажал на иконку Cline в боковой панели — и у тебя агент, который читает твои файлы, пишет код, запускает команды. Всё в одном окне, без переключения.

Отличие от Copilot: Copilot — подсказки. Cline — полноценный агент. Ставишь задачу «добавь авторизацию», он сам выбирает файлы, пишет код, запускает тесты. Можешь подсмотреть, что он делает, в любой момент.

60 тысяч звёзд. Бесплатный, код открыт. Платишь только за токены модели (или вообще не платишь, если локалка).

## Кому подходит

- ✅ Уже сидишь в VS Code, не хочешь менять привычку
- ✅ Хочешь агента без подписки — плати только за API
- ✅ Работаешь с локальной моделью через Ollama
- ❌ НЕ подходит если ты не в VS Code — в других редакторах не работает
- ❌ Для новичков в коде — сначала лучше что-то с десктопом (Goose)

## Установка

В VS Code:

1. Открой Extensions (Cmd+Shift+X)
2. Вбей «Cline»
3. Нажми Install

Или через командную строку:

```bash
code --install-extension saoudrizwan.claude-dev
```

## Первый запуск

1. В боковой панели появится иконка робота — нажми
2. Выбери провайдера: Anthropic, OpenAI, Google, OpenRouter, Ollama…
3. Вставь API ключ (или укажи локальный Ollama сервер)
4. Напиши задачу в поле — агент начнёт
5. Каждый шаг требует подтверждения — удобно на старте

## Нюансы

- Cline покажет план перед выполнением — можешь поправить до того, как он начнёт
- Запрос подтверждений замедляет, но первое время лучше не отключать
- Токены улетают быстро — большие задачи дробь на части
