# 🤖 Автономные AI-агенты

!!! info "🤖 Большинство нужно ставить в Claude Code / Cursor"
    Есть альтернативы в браузере (Goose desktop app, Browser Use Cloud).

Обычный чат — это пинг-понг. Ты спросил — он ответил — ты следующий вопрос. И так 40 раз чтобы сделать одну задачу.

Агент — это когда ты говоришь «разберись с этим» и уходишь пить кофе. А он сам думает, сам кликает, сам пишет код, сам проверяет результат. Возвращаешься — готово.

## Чем агент отличается от чата

Три вещи:

**Цикл вместо ответа.** Чат отвечает один раз и ждёт тебя. Агент работает в цикле: подумал → сделал шаг → проверил результат → подумал → следующий шаг. Пока не добъётся цели или не упрётся.

**Инструменты.** У чата — только текст. У агента — доступ к файлам, терминалу (чёрное окно с командами), браузеру, API (способ подключения программ). Он может читать, писать, запускать, кликать.

**Планирование.** Чат реагирует на твой запрос. Агент разбивает большую задачу на шаги, сам решает порядок, сам переделывает если не получилось.

## Бесплатные фишки до агентов

Не всегда нужен настоящий агент — часто хватает хорошего промпта:

**Ролевой промпт**

```
Ты — senior backend-разработчик с 10 годами опыта. 
Твоя задача — написать REST API для задачника. 
Действуй по шагам: план → структура БД → код → тесты.
Пиши без вопросов, просто делай.
```

Срабатывает в обычном ChatGPT на 80% от того что даст настоящий агент. Бесплатно, без установок.

**Chain-of-Thought**

Добавь «думай шаг за шагом» или «распиши план перед тем как делать». Модель начинает рассуждать структурно, меньше ошибается.

**Разбивай сам**

Большую задачу — на 5 маленьких. Каждую — отдельным промптом. Да, это ручная оркестрация. Но если задача одна — проще, чем ставить агента.

## Если промптов мало — настоящие агенты

- :material-code-tags: **[Codex CLI](codex-cli.md)** — 76K⭐ OpenAI в терминале, открытый код
- :material-robot: **[OpenHands](openhands.md)** — 71K⭐ автономный ИИ-инженер, 87% на SWE-bench
- :material-web: **[Browser Use](browser-use.md)** — 88K⭐ ИИ сам кликает по сайтам
- :material-school: **[Hermes Agent](hermes-agent.md)** — 93K⭐ агент, который учится на скиллах
- :material-microsoft-visual-studio-code: **[Cline](cline.md)** — 60K⭐ VS Code-агент, бесплатный
- :material-duck: **[Goose](goose.md)** — 42K⭐ десктоп + CLI, работает с локальными моделями

**Как выбрать:**
- Не хочешь кодить → Goose (есть десктоп)
- Сидишь в VS Code → Cline
- Уже в терминале → Codex CLI
- Собирать данные с сайтов (копирует текст автоматом) / оформлять заказы → Browser Use
- Сложные задачи на неделю → OpenHands
