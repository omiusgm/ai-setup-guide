# 🤖 Автономные AI-агенты

Агенты работают сами — дал задачу, пошёл пить кофе, вернулся к результату. Не надо сидеть в чате и подсказывать на каждом шагу.

Главное отличие от обычного чата: агент САМ разбивает задачу на шаги, САМ решает в какой порядке делать, САМ запускает команды и читает файлы. Ты ставишь цель — он добирается.

## Топ по звёздам

- :material-duck: **[Goose](goose.md)** — 42K⭐ десктоп + CLI, работает с локальными моделями

</div>

## Как выбрать

- **Не хочешь кодить** → Goose (есть десктоп-приложение)
- **Сидишь в VS Code** → Cline
- **Уже в терминале** → Codex CLI
- **Надо скрапить сайты / оформить заказы** → Browser Use
- **Сложные задачи на неделю** → OpenHands

---

*Все агенты бесплатны. Часть работает с локальными моделями через [Ollama](../../knowledge/budget.md) — можно из РФ без VPN.*
