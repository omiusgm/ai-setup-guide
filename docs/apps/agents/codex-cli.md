# ⌨️ Codex CLI

> OpenAI выпустили свой агент с открытым кодом. Живёт в терминале, работает со всеми OpenAI-моделями.

## Что делает

То же что Claude Code, но от OpenAI и бесплатный (только за токены платишь). Запустил `codex` в терминале — появилась сессия, пишешь задачу — агент работает.

Читает файлы, правит код, запускает команды. Может работать в двух режимах: интерактивный (подтверждает каждый шаг) и автономный (делает всё сам).

76 тысяч звёзд — один из самых популярных агентов на гитхабе. OpenAI вложились: активно развивают, обновления каждую неделю.

## Кому подходит

- ✅ Уже работаешь с OpenAI (ChatGPT Plus, API ключ)
- ✅ Любишь терминал — минимум UI, максимум скорости
- ✅ Нужен агент без привязки к редактору
- ❌ НЕ подходит если боишься терминала
- ❌ Если нет OpenAI API — подключить другие модели сложнее

## Установка

```bash
npm install -g @openai/codex
```

Нужен Node.js. Если нет — поставь с [nodejs.org](https://nodejs.org).

## Первый запуск

1. В любой папке проекта: `codex`
2. Попросит API ключ — возьми на platform.openai.com
3. Пиши задачу
4. Агент предложит план — подтверждаешь или правишь
5. Он выполняет по шагам

## Нюансы

- Требует OpenAI API — в РФ без VPN не заработает
- С GPT-4 токены улетают быстро, держи лимиты на аккаунте
- У Anthropic есть свой аналог (Claude Code) — если ты в Anthropic, он удобнее
