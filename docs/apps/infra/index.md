# 🖥️ Инфраструктура

Модели и среды где всё это крутится. Для тех кто хочет без VPN, дешевле, или вообще локально на своём компе.

## Что есть

<div class="app-list" markdown>

- :material-desktop-tower: **[Ollama](ollama.md)** — 169K⭐ запусти DeepSeek, Llama, Qwen у себя, бесплатно
- :material-api: **[DeepSeek](deepseek.md)** — работает из РФ без VPN, дешёвый API

</div>

## Когда нужно

- **Не хочешь платить** → Ollama + Qwen 2.5 (бесплатно, локально)
- **Нужен API, но без VPN** → DeepSeek
- **Приватность важна** → только Ollama, всё на своём компе

---

*Локальные модели слабее коммерческих, но для 70% задач хватает с головой.*
