# 🏛️ MemPalace

> «Дворец памяти» для ИИ-агента. Создатель — Милла Йовович (да, та самая), соавтор — Бен Сигман. Осторожно: есть вопросы к бенчмаркам.

## Что делает

Обычный ИИ забывает тебя сразу после закрытия вкладки. MemPalace — это внешнее хранилище, куда агент пишет факты и достаёт их потом. Под капотом — векторная база данных (ChromaDB).

Агент сохраняет: решения, контекст проекта, важные детали о тебе. При следующем запуске — «вспоминает» и работает как с того же места.

45 тысяч звёзд. Но репутационно проект спорный: некоторые бенчмарки в README выглядят слишком красиво, сообщество периодически задаёт вопросы. Работает — но не обожествляй цифры.

## Кому подходит

- ✅ Работаешь с одним проектом долго, хочешь чтобы ИИ помнил контекст
- ✅ Вайбкодеры — устал объяснять одно и то же каждую сессию
- ✅ Не страшно поставить pip-пакет и поэкспериментировать
- ❌ НЕ подходит для простых чатов — избыточно
- ❌ Если нужен продакшн с SLA — лучше взять решение посерьёзнее (Honcho)

## Установка

```bash
pip install mempalace
```

Для Claude Code:

```bash
claude skill install mempalace
```

## Первый запуск

1. Поставил — появилась папка `.mempalace/` в проекте
2. Агент автоматически начнёт писать туда контекст
3. Следующая сессия — агент прочитает файлы и «вспомнит»
4. Можешь открыть файлы руками — всё в markdown, читаемо

## Нюансы

- Бенчмарки в README сомнительны — проверяй на своих задачах
- Векторная база иногда выдаёт лишнее — фильтруй в промпте
- Под капотом ChromaDB — если надо что-то сложнее, можно взять её напрямую
