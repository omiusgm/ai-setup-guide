# 🏛️ MemPalace

!!! info "🤖 Для агентов (Claude Code / Cursor / Codex)"
    Этот инструмент требует установки и файлового доступа. Если ты в браузере с ChatGPT — см. [альтернативы](#как-попробовать-без-чёрного-окна-с-командами) ниже.

> Хайповая система памяти от Миллы Йовович. Под капотом обычная ChromaDB. Осторожно: обвинения в накрутке звёзд.

## Что делает

Обычный ИИ забывает тебя сразу после закрытия вкладки. MemPalace — это внешнее хранилище, куда агент пишет факты и достаёт их потом. Под капотом — база где ИИ ищет по смыслу (ChromaDB), обёрнутая в простой интерфейс.

Агент сохраняет: решения, контекст проекта, важные детали о тебе. При следующем запуске — «вспоминает» и работает как с того же места.

Создатель — Милла Йовович (да, та самая), соавтор — Бен Сигман. 45 тысяч звёзд. Но репутационно проект спорный: сообщество обвиняет в накрутке звёзд, бенчмарки в README выглядят слишком красиво. Работает — но не обожествляй цифры.

## Нюансы (прочитай до установки)

- **Обвинения в накрутке звёзд** — 45K не отражают реальное комьюнити, будь осторожен с «популярностью»
- **Бенчмарки в README сомнительны** — проверяй на своих задачах, не верь цифрам на слово
- **Это обёртка над ChromaDB** — если умеешь работать с базами где ИИ ищет по смыслу, можешь взять её напрямую и не зависеть от MemPalace
- **База иногда выдаёт лишнее** (ищет по смыслу, не по точному совпадению) — придётся фильтровать в промпте
- **Для продакшна с SLA — не вариант**, бери Honcho или собирай своё

## Кому подходит

- ✅ Работаешь с одним проектом долго, хочешь чтобы ИИ помнил контекст
- ✅ Вайбкодеры — устал объяснять одно и то же каждую сессию
- ✅ Не страшно поставить pip-пакет и поэкспериментировать
- ❌ НЕ подходит для простых чатов — избыточно
- ❌ Если нужен продакшн с SLA — лучше взять решение посерьёзнее (Honcho)

## Как попробовать без чёрного окна с командами

MemPalace ставится через pip — без чёрного окна с командами никак. Но та же идея «памяти для ИИ» отлично работает без него:

- **[HANDOFF-паттерн](handoff-pattern.md)** — просто текстовый файл с простой разметкой в проекте. Работает с любым ИИ, в любом редакторе, без установок
- **[Claude Projects](https://claude.ai)** — Project knowledge хранит контекст между чатами, управляется мышкой в браузере
- **ChatGPT Memory** — в настройках есть галочка «Memory», ChatGPT сам запоминает факты

Честно: для 90% задач HANDOFF.md хватает. MemPalace ставят скорее из любопытства к «умным» базам по смыслу.

??? note "Для программистов (через чёрное окно с командами)"

    ```bash
    pip install mempalace
    ```

    Для Claude Code:

    ```bash
    claude skill install mempalace
    ```

    **Первый запуск:**

    1. Поставил — появилась папка `.mempalace/` в проекте
    2. Агент автоматически начнёт писать туда контекст
    3. Следующая сессия — агент прочитает файлы и «вспомнит»
    4. Можешь открыть файлы руками — всё в простом текстовом формате, читаемо
