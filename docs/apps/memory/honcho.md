# 🧠 Honcho

!!! info "🤖 Для агентов (Claude Code / Cursor / Codex)"
    Этот инструмент требует установки и файлового доступа. Если ты в браузере с ChatGPT — см. [альтернативы](#как-попробовать-без-чёрного-окна-с-командами) ниже.

> Внешняя память для ИИ-агентов от Plastic Labs. Не просто хранит факты, а делает выводы о пользователе.

## Что делает

Большинство систем памяти тупо сохраняют фразы. Honcho идёт дальше — строит модель пользователя. Понимает контекст, отношения, предпочтения. Агент не просто помнит «что ты сказал», а понимает «какой ты человек».

Plastic Labs — не стартап-однодневка, они давно в теме персонализации ИИ. Репутация серьёзная.

Работает как отдельный сервер (можно установить у себя) или облачный сервис. Агент обращается к Honcho через подключение.

## Кому подходит

- ✅ Делаешь продукт с постоянными пользователями (чат-бот, ассистент)
- ✅ Важна персонализация — разные ответы разным людям
- ✅ Хочешь контроль — можно установить у себя (не в облаке)
- ❌ НЕ подходит для простых личных задач — избыточно
- ❌ Если не умеешь работать с подключениями и серверами — барьер входа высокий

## Как попробовать без чёрного окна с командами

Honcho — серверный инструмент для разработчиков. Если не кодишь, но нужна «память для ИИ» — забирай что попроще:

- **[HANDOFF-паттерн](handoff-pattern.md)** — обычный текстовый файл с простой разметкой, работает везде без установок
- **[Claude Projects](https://claude.ai)** в браузере — Project knowledge хранит контекст между чатами
- **[MemPalace](mempalace.md)** — попроще технически, но тоже требует Python
- **ChatGPT Memory** — в настройках ChatGPT есть «Memory», сам запоминает факты о тебе

Если реально нужен именно Honcho — готовься разбираться с серверами, подключениями и OAuth (авторизация одной кнопкой). Для хобби он перебор.

??? note "Для программистов (через чёрное окно с командами)"

    Для Claude Code через скилл:

    ```bash
    npx skills add plastic-labs/honcho
    ```

    Или установить у себя — свой сервер:

    ```bash
    git clone https://github.com/plastic-labs/honcho
    cd honcho
    docker-compose up
    ```

    **Первый запуск:**

    1. Поднял сервер (локально или в облаке)
    2. В агенте — подключил
    3. Указал ID пользователя — агент начнёт писать туда заметки
    4. Следующие запросы — агент читает и использует
