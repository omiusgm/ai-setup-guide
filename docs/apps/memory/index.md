# 🧠 Память для ИИ

!!! info "🤖💬 Работает и в чате, и в агенте"
    Бесплатные решения (CLAUDE.md, HANDOFF) — для агента. Для чата — длинный системный промпт с контекстом.

Claude забывает что ты делал 5 минут назад. Каждый новый чат — с нуля. Рассказал ему про свой проект, он кивнул, написал код. Через час вернулся, а он опять: «Привет! Чем могу помочь?».

Бесит, да. Но это не баг — это так устроены языковые модели. И это лечится.

## Почему так происходит

У ИИ есть **память одного разговора** (контекстное окно) — это его оперативка. Туда помещается примерно 200 тысяч слов (у Claude). Всё что там — модель видит. Всё что вылетело — забыто навсегда.

Каждая новая сессия стартует с пустым окном. Модель не хранит ничего между чатами. Она вообще не знает что у неё был другой чат.

Внутри одной сессии есть ещё штука — **компакция**. Когда диалог растёт, старое автоматом сжимается в саммари. То есть детали 50-го сообщения назад уже не те, что были изначально. ИИ начинает путаться.

## Как это выглядит на практике

=== "Было (больно)"
    Ты: «Продолжим наш проект про дашборд»  
    ИИ: «О каком проекте речь? Расскажи подробнее»  
    Ты: *объясняешь третий раз за день*

=== "Стало (с CLAUDE.md в проекте)"
    Ты: «Продолжим»  
    ИИ: *читает CLAUDE.md автоматом*  
    ИИ: «Ок, мы остановились на фильтре по датам. Продолжаем?»

## Бесплатные решения без установок

Фишки которые работают прямо сейчас:

**CLAUDE.md в корне проекта**

Claude Code читает этот файл автоматом каждый раз как заходишь в папку. Напиши туда кто ты, что за проект, как писать код. Больше не надо объяснять с нуля.

```bash
# В корне проекта
echo "Это проект X. Стек: Python + FastAPI. Стиль: PEP8." > CLAUDE.md
```

**Файлы вместо чата**

Не храни контекст в переписке — храни в файлах. Задача → `task.md`, прогресс → `progress.md`, решения → `decisions.md`. ИИ их читает когда надо, а ты не теряешь нить между сессиями.

**Mention через @**

В Claude Code `@README.md` заставит ИИ прочитать файл. Не надо копировать-вставлять содержимое — пишешь `@файл` и всё.

**Новый чат каждые 50 сообщений**

Длинные диалоги тупят модель. Контекст забивается, компакция съедает детали. Закрыл → открыл новый → дал саммари из файла. Чище работает.

**Команда /memory**

В Claude Code есть `/memory` — настраивает что помнить. Посмотри что умеет.

## Если бесплатного мало

- :material-memory: **[MemPalace](mempalace.md)** — если CLAUDE.md разросся и стало тяжело — раскладывает память по комнатам автоматом

- :material-file-document: **[Handoff-паттерн](handoff-pattern.md)** — если хочешь контролировать что именно ИИ помнит — руками пишешь HANDOFF.md
