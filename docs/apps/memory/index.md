# 🧠 Память для ИИ

Обычный чат забывает тебя сразу после закрытия вкладки. Каждый раз приходится объяснять заново: как зовут, чем занимаюсь, что уже обсуждали. Бесит.

Эти инструменты дают ИИ постоянную память. Он начинает помнить проекты, решения, контекст — как нормальный коллега.

## Что использовать

<div class="app-list" markdown>

- :material-memory: **[MemPalace](mempalace.md)** — «дворец памяти», векторная база, ставится через pip
- :material-brain: **[Honcho](honcho.md)** — внешняя память с рассуждением, от Plastic Labs
- :material-file-document: **[Handoff-паттерн](handoff-pattern.md)** — не репо, а способ: писать прогресс в HANDOFF.md

</div>

## Что выбрать

- **Простой вариант без установок** → HANDOFF.md (просто файл, работает везде)
- **Серьёзная память для агентов** → Honcho
- **Эксперимент** → MemPalace (под капотом векторная БД, но есть нюансы — см. страницу)

---

*Память — это не магия. Это файл или база, куда ИИ пишет и откуда читает. Всё просто.*
