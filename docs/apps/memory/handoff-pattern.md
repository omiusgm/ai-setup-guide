# 📋 HANDOFF-паттерн

!!! info "🤖💬 Для чатботов И агентов"
    Работает и в браузере (облачная версия / альтернатива), и через агента (установка). Ниже оба варианта.

> Самый простой способ дать ИИ память между сессиями. Не репо, не пакет — просто файл `HANDOFF.md` в проекте.

## Что делает

Никаких установок. Создаёшь в корне проекта файл `HANDOFF.md`. Агент пишет туда прогресс работы перед завершением сессии. Новая сессия — читает файл и продолжает с того же места.

Идея простая до гениальности: память — это не сложные базы где ИИ ищет по смыслу и не облачные сервисы. Память — это файл, куда ты пишешь и откуда читаешь.

Работает в любом редакторе, с любым агентом (Claude Code, Cline, Cursor, Goose). Ничего ставить не надо.

## Кому подходит

- ✅ Всем, кто работает с ИИ-агентами над долгими проектами
- ✅ Не хочешь ставить лишние пакеты
- ✅ Нужна простота и прозрачность — файл можно читать руками
- ❌ НЕ подходит для задач где нужны сотни воспоминаний — файл разрастётся
- ❌ Для продукта с тысячами пользователей — нужна настоящая БД

## Пример HANDOFF.md

```markdown
# HANDOFF — 16 апреля 2026

## Что сделано
- Настроил авторизацию через JWT
- Написал тесты на /api/users
- Развернул staging на Beget

## Что в процессе
- Добавляю роль админа (в файле auth/roles.py, 70% готово)
- Нужно: дописать проверку в middleware

## Открытые вопросы
- Согласовать с клиентом: нужен ли 2FA
- Проверить что SSL сертификат не истёк в мае

## Контекст для следующей сессии
Проект на FastAPI + Postgres. Структура: backend/ — API, frontend/ — React.
Главный файл — backend/main.py.
```

## Первый запуск

1. Создай `HANDOFF.md` в корне проекта
2. В CLAUDE.md (или аналоге) добавь: «Перед завершением сессии обновляй HANDOFF.md. В начале сессии — читай»
3. Первая сессия — агент начнёт писать туда
4. Следующая — читает и продолжает

## Нюансы

- Если агент забывает обновлять — добавь напоминание в системный промпт
- Файл должен быть коротким (под 200 строк) — иначе агент не читает полностью
- Для крупных проектов делай несколько: `HANDOFF-auth.md`, `HANDOFF-frontend.md`

## Почему это работает лучше сложных «умных» баз

- Всё в тексте → ты сам видишь что агент помнит
- Можешь править руками — удалить лишнее, добавить нужное
- Работает без интернета, без подключений к чужим сервисам, без квот
- Портируется между любыми ИИ
