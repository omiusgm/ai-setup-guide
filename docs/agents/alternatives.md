# Альтернативные ИИ-агенты

Claude Code -- не единственный агент. Вот главные конкуренты, каждый со своими плюсами.

---

## OpenHands (71K stars)

[github.com/All-Hands-AI/OpenHands](https://github.com/All-Hands-AI/OpenHands)

Автономный ИИ-инженер. Не просто помощник -- полноценный разработчик в песочнице. Может планировать, писать код, запускать, дебажить. Работает с любой моделью (Claude, GPT-4, локальные).

**Для кого:** разработчики, которые хотят автономного агента с выбором модели.

**Плюс:** open-source, не привязан к одной компании.

---

## Gemini CLI (101K stars)

[github.com/google-gemini/gemini-cli](https://github.com/google-gemini/gemini-cli)

Google Gemini в терминале. Главный козырь -- бесплатно. 1000 запросов в день, 1 миллион токенов контекста. Поддерживает MCP-серверы.

**Для кого:** те, кому нужен агент в терминале, но не хочется платить $20/мес.

**Плюс:** бесплатный, огромный контекст. **Минус:** качество кода ниже Claude (пока).

---

## Cline (58K stars)

[github.com/cline/cline](https://github.com/cline/cline)

Расширение для VS Code. Работает с любой моделью через API. Создаёт файлы, запускает команды, работает с браузером. Каждое действие показывает и спрашивает подтверждение.

**Для кого:** те, кто работает в VS Code и хочет агента прямо в редакторе.

**Плюс:** контроль -- ничего не делает без твоего OK. **Минус:** нужен API-ключ (подписка не подходит для Claude).

---

## Codex CLI (67K stars)

[github.com/openai/codex](https://github.com/openai/codex)

Агент от OpenAI в терминале. Аналог Claude Code, но на моделях GPT. Sandbox-режим для безопасности. Подписка ChatGPT Plus ($20) работает -- не нужен отдельный API.

**Для кого:** фанаты OpenAI или те, у кого уже есть ChatGPT Plus.

**Плюс:** подписка ChatGPT работает (не надо отдельно платить за API).

---

## Mastra (23K stars)

[github.com/mastra-ai/mastra](https://github.com/mastra-ai/mastra)

TypeScript-фреймворк для создания ИИ-агентов. Не готовый агент, а конструктор. Нужен для тех, кто хочет строить свои мультиагентные системы.

**Для кого:** разработчики, которые строят продукты с ИИ.

**Плюс:** максимальная гибкость. **Минус:** нужно кодить.
