# Agent Teams -- параллельные агенты с общей перепиской

Экспериментальная фича Claude Code: несколько агентов работают одновременно и общаются друг с другом через "почтовый ящик". Каждый в своей сессии, но видит сообщения остальных.

---

## Как работает

Обычно Claude Code -- один агент в одном терминале. Agent Teams запускает несколько сессий параллельно. Каждый агент:

- Работает в своём окне терминала
- Имеет свою роль и задачу
- Может отправить сообщение любому другому агенту
- Может прочитать сообщения от других

Это peer-to-peer: нет главного и подчинённых. Каждый агент равноправен.

---

## Как включить

Экспериментальная фича, включается через переменную окружения:

```bash
CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 claude
```

---

## Пример команды

Для веб-проекта:

| Агент | Роль | Что делает |
|-------|------|------------|
| Frontend | React-разработчик | Пишет компоненты, стили |
| Backend | API-разработчик | Пишет эндпоинты, БД |
| QA | Тестировщик | Пишет тесты, находит баги |

Frontend пишет компонент, отправляет сообщение Backend: "Мне нужен эндпоинт GET /api/users". Backend делает, отвечает: "Готово, формат ответа такой-то". QA видит оба сообщения и пишет тесты.

---

## Когда это нужно

- Проект большой и задачи можно делать параллельно
- Нужна скорость -- три агента быстрее одного
- Разные части проекта слабо зависят друг от друга
- Хочешь имитировать работу команды

---

## Когда НЕ нужно

- Маленький проект (один агент справится)
- Задачи последовательные (параллельность не поможет)
- Нет понимания как разбить на роли

---

## Ограничения

- **Экспериментально** -- может работать нестабильно
- **Токены** -- каждый агент тратит свои токены (x3 расход)
- **Координация** -- иногда агенты конфликтуют (правят один файл одновременно)
- **Подписка** -- нужна Claude Max для комфортной работы (лимиты)

---

## Альтернатива: субагенты

Если Agent Teams кажется сложным -- начни с субагентов. Это когда один главный агент порождает дочерние для конкретных задач. Проще в управлении, достаточно для большинства случаев.
