# AutoResearch -- паттерн Карпаты

Андрей Карпатый (бывший директор ИИ в Tesla, сооснователь OpenAI) опубликовал паттерн автономного исследования. Агент сам ставит гипотезы, проводит эксперименты, анализирует результаты и оптимизирует.

[Репозиторий](https://github.com/karpathy/autoresearch) (69K stars)

---

## Идея

Обычно ты говоришь агенту "сделай X". AutoResearch -- наоборот: ты говоришь "разберись в теме Y и найди лучший способ сделать Z". Агент сам:

1. Формулирует гипотезы
2. Пишет код для экспериментов
3. Запускает эксперименты
4. Анализирует результаты
5. Корректирует гипотезы
6. Повторяет

Это не просто "поиск информации" -- это научный метод, автоматизированный.

---

## Зачем обычному человеку

На первый взгляд -- штука для учёных. Но паттерн работает шире:

- **Оптимизация промптов** -- агент сам пробует разные формулировки и находит лучшую
- **A/B тестирование текстов** -- какой заголовок лучше конвертит
- **Подбор параметров** -- какие настройки модели дают лучший результат
- **Исследование рынка** -- агент сам собирает данные и ищет паттерны

---

## Как это выглядит

```
Задача: найти оптимальный промпт для генерации описаний товаров

Агент:
1. Создаёт 10 вариантов промпта
2. Генерирует 50 описаний каждым вариантом
3. Оценивает по критериям (длина, читаемость, конверсия)
4. Берёт 3 лучших, мутирует, создаёт новые варианты
5. Повторяет 5 раундов
6. Выдаёт победителя с метриками
```

---

## Ограничения

- Тратит много токенов (десятки итераций)
- Нужно чёткое определение "что считать успехом"
- Работает долго (минуты-часы, не секунды)
- Нужен Claude Max или API с бюджетом

---

## Главный урок

Даже если не будешь использовать AutoResearch напрямую -- паттерн "дай агенту цель, а не инструкцию" работает везде. Вместо "напиши текст вот так" -- "напиши 5 вариантов, оцени каждый по критериям, выбери лучший". Агент с итерациями выдаёт результат лучше, чем с одного захода.
