# Мультиагентность -- 3 уровня

Один агент -- хорошо. Несколько агентов, которые работают вместе -- ещё лучше. Но не всегда нужна армия -- иногда хватит одного бойца с правильными инструкциями.

---

## Уровень 1: Один агент с ролями

Самый простой и рабочий вариант. Один Claude Code, но с разными "шляпами":

- **GSD** -- режим "сделай проект". Планирует, разбивает на задачи, выполняет
- **/code-review** -- проверяет свой же код (да, работает лучше чем кажется)
- **Скиллы** -- подключаешь навыки через `npx skills add`

Это как один сотрудник, который и пишет, и проверяет, и деплоит. Для 80% проектов хватает.

---

## Уровень 2: Agent Teams (2-5 агентов)

Несколько агентов в параллельных сессиях с общим "почтовым ящиком". Каждый делает свою часть.

Пример:

- Агент-1: пишет фронтенд
- Агент-2: пишет бэкенд
- Агент-3: пишет тесты
- Все трое видят сообщения друг друга

Экспериментальная фича Claude Code. Включается через переменную окружения.

---

## Уровень 3: Внешние оркестраторы

Отдельный фреймворк управляет агентами:

- **Mastra** -- TypeScript фреймворк для мультиагентных систем
- **n8n** -- визуальный оркестратор (workflow из агентов)
- **OpenHands** -- автономный инженер с планированием

Это для тех, кому Agent Teams мало. Десятки агентов, сложная логика, кастомные роли.

---

## Что выбрать

| Задача | Уровень |
|--------|---------|
| Один проект, один человек | 1 -- один агент |
| Большой проект, нужна скорость | 2 -- Agent Teams |
| Корпоративная автоматизация | 3 -- оркестратор |
| "Я просто попробовать" | 1 -- начни с одного |

---

## Главное правило

Не усложняй. Один агент с хорошим CLAUDE.md и правильными MCP-серверами закроет 80% задач. Мультиагентность -- когда один агент объективно не справляется (параллельные задачи, разные кодобазы, разные роли).
