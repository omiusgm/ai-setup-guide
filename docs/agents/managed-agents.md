# Claude Managed Agents -- облачные агенты от Anthropic

Anthropic запустил платформу где агенты работают на серверах Anthropic. Не на твоём компьютере, не на твоём VPS -- на их инфраструктуре. Ты даёшь задачу, агент работает, присылает результат.

---

## Что это

Managed Agents -- полноценные среды выполнения в облаке:

- **Sandbox** -- изолированная машина с Linux
- **Bash** -- выполняет команды
- **Файлы** -- создаёт, редактирует, удаляет
- **Веб-поиск** -- гуглит без MCP-серверов
- **MCP из коробки** -- подключает серверы автоматически
- **Компьютер не нужен** -- работает даже когда ты спишь

---

## Цена

$0.08/час за среду + стоимость токенов (как обычно). Если агент работает 10 минут -- заплатишь ~$0.01 за среду + токены.

---

## Зачем если есть Claude Code

| Claude Code | Managed Agents |
|-------------|----------------|
| На твоём компьютере | В облаке |
| Комп должен быть включён | Работает без тебя |
| Ты видишь процесс | Получаешь результат |
| Бесплатно (в подписке) | $0.08/час + токены |
| Полный доступ к ОС | Sandbox (изоляция) |

---

## Когда использовать

- **Долгие задачи** -- "собери данные с 500 сайтов" (часы работы, комп можно закрыть)
- **Ночные задачи** -- "каждое утро готовь мне отчёт"
- **Безопасность** -- агент работает в песочнице, не имеет доступа к твоим файлам
- **Параллельность** -- запусти 10 агентов на 10 задач одновременно

---

## Как запустить

Через Claude Code:

```bash
claude agents create --name "мой-агент" --prompt "Собери цены конкурентов..."
```

Или через API Anthropic (для разработчиков).

---

## Ограничения

- Нет доступа к твоему компьютеру (это и плюс, и минус)
- Sandbox ограничен (нет GPU, ограничен RAM)
- Нужна подписка Claude (Pro минимум)
- В бета-тесте -- функционал может меняться
