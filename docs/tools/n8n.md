# n8n

> Визуальный конструктор автоматизаций -- соединяй сервисы без кода

## Зачем

У тебя Telegram-бот, Google Sheets, CRM и ещё пять сервисов. И ты вручную перекидываешь данные между ними. n8n -- это как Zapier, только бесплатный и на своём сервере. Ты рисуешь цепочку: "когда пришло письмо -- отправь в Telegram -- запиши в таблицу -- спроси у ИИ ответ". И оно работает само.

184 тысячи звёзд. Самый популярный open-source инструмент автоматизации.

## Как пользоваться

**Быстрый старт (облако):**

1. Зайди на [n8n.io](https://n8n.io) и создай аккаунт
2. Получишь визуальный редактор прямо в браузере
3. Перетаскивай блоки, соединяй стрелками -- готово

**Свой сервер (бесплатно навсегда):**

```bash
docker run -it --rm -p 5678:5678 n8nio/n8n
```

Откроется на `localhost:5678`.

Новая фишка -- **Agent-to-Agent**: можно строить цепочки из ИИ-агентов, где один агент передаёт задачу другому. По сути, мини-команда ИИ-ботов.
