# AmoCRM + ИИ-агент

> ИИ-агент для CRM: отчёты, мониторинг, уведомления -- всё голосом или в чате

## Зачем

AmoCRM -- популярная CRM в РФ. Но руководители отдела продаж тратят часы на отчёты и контроль менеджеров. ИИ-агент подключается к AmoCRM и делает грязную работу: собирает отчёты, следит за зависшими сделками, пингует если менеджер забил на клиента.

Реальный кейс: РОП подключил за один вечер, на следующий день получил первый автоматический отчёт.

## Как пользоваться

1. Получи API-токен AmoCRM (Настройки -- Интеграции -- API)
2. Опиши агенту задачу: "Каждое утро присылай мне в Telegram отчёт по новым сделкам за вчера"
3. Агент подключается к API, собирает данные, форматирует и отправляет

Что можно автоматизировать:

- Утренние отчёты по продажам
- Алерты: "Сделка на 500К зависла 3 дня без движения"
- Мониторинг: кто из менеджеров не звонил клиентам
- Автоматическое заполнение полей по входящим заявкам

## Для кого

- РОПы и руководители отделов продаж
- Предприниматели, которые сами ведут CRM
- Все, у кого AmoCRM и желание тратить на отчёты 0 минут вместо часа
