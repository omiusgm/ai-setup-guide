# Ollama

> Запускай ИИ-модели прямо на своём компьютере -- без облака, без VPN, без подписок

## Зачем

Все облачные ИИ -- это чужой сервер. Твои данные уходят куда-то, нужен интернет, часто нужен VPN. Ollama позволяет скачать модель и запустить её локально. Всё работает на твоём железе, без интернета, бесплатно навсегда.

169 тысяч звёзд на GitHub -- это один из самых популярных ИИ-проектов в мире.

## Как пользоваться

1. Скачай с [ollama.com](https://ollama.com) (Mac, Windows, Linux)
2. Установи как обычную программу
3. Открой терминал и запусти:

```bash
ollama run deepseek-r1
```

Всё. Модель скачается и заработает. Для первого раза скачивание займёт время -- модели весят от 2 до 70 ГБ в зависимости от размера.

Другие полезные модели:

- `ollama run llama3.1` -- Meta Llama, хороша для английского
- `ollama run mistral` -- быстрая и лёгкая
- `ollama run codellama` -- для кода

## Для кого

- Технари и вайбкодеры, которые хотят полный контроль
- Те, кому нужна приватность (данные не уходят в облако)
- Все в РФ -- локальный ИИ не зависит от санкций
