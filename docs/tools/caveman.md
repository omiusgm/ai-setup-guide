# Caveman Prompt

> Промпт, который экономит 70% токенов и убирает воду из ответов ИИ

## Зачем

Знаешь это чувство, когда спрашиваешь ИИ простую вещь, а он выдаёт три абзаца вступления, потом "Важно отметить", потом ещё абзац оговорок? Caveman Prompt заставляет ИИ говорить коротко и по делу. Как пещерный человек -- без лишних слов.

27 тысяч звёзд на GitHub не просто так. Люди устали от словесного поноса.

## Как пользоваться

1. Открой [GitHub-репозиторий](https://github.com/JuliusBrussee/caveman) и скопируй промпт
2. Вставь его в начало любого чата -- ChatGPT, Claude, DeepSeek, без разницы
3. Дальше общайся как обычно

Всё. Промпт работает как системная инструкция: ИИ перестаёт лить воду и начинает отвечать по существу.

## Для кого

- Любой, кто устал от длинных ответов ИИ
- Те, кто платит за токены и хочет экономить
- Новички, которым нужны короткие и понятные ответы
