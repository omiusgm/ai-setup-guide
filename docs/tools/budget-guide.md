# Бюджет на ИИ: от 0 до $200

> Сколько реально стоит ИИ, что бесплатно, и как не переплачивать

## Зачем

"ИИ -- это дорого" -- миф. Можно начать с нуля рублей и получать пользу. Но если готов платить -- за каждый уровень получаешь конкретные возможности. Тут без воды: сколько стоит, что даёт, стоит ли.

## Уровни

### $0 -- Бесплатно

- **DeepSeek** (chat.deepseek.com) -- бесплатный чат, работает из РФ
- **ChatGPT Free** -- базовая версия, есть ограничения
- **Ollama** -- локальные модели, бесплатно навсегда (но нужен комп помощнее)
- **Goose** -- бесплатный агент от Block

Что можно: писать тексты, отвечать на вопросы, простой анализ данных, помощь с кодом.

### $20/мес -- ChatGPT Plus

- GPT-4o без ограничений
- Генерация картинок (DALL-E)
- Поиск в интернете
- Загрузка файлов и анализ

Стоит ли: да, если пользуешься каждый день и нужны картинки или анализ файлов.

### $20/мес -- Claude Pro

- Claude Sonnet без ограничений
- Загрузка файлов до 100 страниц
- Проекты с контекстом

Стоит ли: да, если пишешь длинные тексты или работаешь с документами. Claude лучше пишет по-русски.

### $100/мес -- Claude Max (или Cursor $20)

- **Claude Max**: безлимитный Opus + Claude Code (ИИ-агент в терминале)
- **Cursor** ($20): ИИ-редактор кода, дешевле, но только для кода

Стоит ли: Claude Max -- для тех, кто строит с ИИ каждый день. Cursor -- если нужен только код.

### $200/мес -- Claude Max 5x

- В 5 раз больше использования Opus
- Remote Tasks (агент работает в облаке)
- Параллельные агенты

Стоит ли: только если ИИ -- основной рабочий инструмент и ты загружаешь его на полную.

## Как экономить

1. **Начни с бесплатного** -- DeepSeek + Ollama покрывают 80% задач
2. **Не плати за два чата** -- выбери ChatGPT ИЛИ Claude, не оба
3. **Caveman Prompt** -- экономит до 70% токенов (меньше воды = меньше расход)
4. **Локальные модели** -- Ollama бесплатна и не тратит токены
5. **Годовая подписка** -- обычно скидка 15-20%

## Для кого

- Новички: начните с $0, поймёте нужно ли больше
- Бизнес: $20-100 закрывает большинство задач
- Вайбкодеры: $100-200 если ИИ -- основной инструмент
