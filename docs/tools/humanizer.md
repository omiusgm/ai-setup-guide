# Humanizer

> Убирает следы ИИ из текста -- делает написанное похожим на человеческое

## Зачем

ИИ пишет узнаваемо. "В современном мире", "Важно отметить", "Данный подход позволяет" -- эти маркеры видны за километр. Преподаватели ловят, редакторы ловят, да и просто читать противно. Humanizer проходится по тексту и убирает типичные ИИ-штампы, заменяя их на нормальный человеческий язык.

14 тысяч звёзд. Люди хотят, чтобы ИИ писал как человек, а не как робот на совещании.

## Как пользоваться

**Как скилл Claude Code:**

```bash
claude skill install humanizer
```

После установки можно говорить агенту: "Прогони этот текст через humanizer" -- и он уберёт ИИ-маркеры.

**Как промпт (без установки):**

Можно просто скопировать подход и попросить ИИ: "Перепиши этот текст. Убери все типичные ИИ-маркеры: канцелярит, пассивный залог, слова-паразиты типа 'важно отметить'. Пиши как живой человек в переписке."

## Для кого

- Копирайтеры, которые используют ИИ для черновиков
- Студенты (без комментариев)
- Все, кто хочет чтобы текст от ИИ не выглядел как текст от ИИ
