# Everything Claude Code (ECC)

> Менеджер плагинов для Claude Code: 47 агентов, 181 скилл, 79 команд -- всё в одном месте

## Зачем

Claude Code из коробки умеет много, но ECC превращает его в швейцарский нож. Это как магазин приложений, только для ИИ-агента. Нужен агент для рефакторинга? Есть. Скилл для генерации тестов? Есть. Команда для деплоя? Тоже есть.

157 тысяч звёзд -- самый популярный набор расширений для Claude Code.

## Как пользоваться

1. Установи менеджер:

```bash
claude install ecc
```

2. Посмотри что доступно:

```bash
claude ecc list
```

3. Установи нужное:

```bash
claude ecc install code-review-agent
claude ecc install test-generator
```

4. Используй в работе -- агенты и скиллы интегрируются в Claude Code

Несколько полезных штук из коллекции:

- **code-review** -- ревью кода как от сеньора
- **test-gen** -- генерация тестов
- **refactor** -- рефакторинг с объяснениями
- **git-wizard** -- продвинутая работа с git

## Для кого
