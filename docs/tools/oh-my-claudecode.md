# Oh My Claude Code (OMC)

> 32 специализированных агента поверх Claude Code -- с умным роутингом между моделями

## Зачем

Claude Code использует одну модель для всего. OMC добавляет 32 агента, каждый заточен под свою задачу: один ревьюит код, другой пишет тесты, третий рефакторит. Главная фишка -- умный роутинг: простые задачи отправляются на дешёвый Haiku, средние на Sonnet, сложные на Opus. Экономия токенов до 60%.

28 тысяч звёзд. Проект для тех, кто уже сидит в Claude Code и хочет выжать из него максимум.

## Как пользоваться

1. Установи:

```bash
npm install -g oh-my-claudecode
```

2. Инициализируй в проекте:

```bash
omc init
```

3. Используй агентов:

```bash
omc review       # код-ревью
omc test         # генерация тестов
omc refactor     # рефакторинг
omc security     # аудит безопасности
```

Система сама решает какую модель использовать:

- **Haiku** -- форматирование, простые правки, линтинг
- **Sonnet** -- ревью, тесты, стандартные задачи
- **Opus** -- архитектурные решения, сложный рефакторинг
