# Hermes Agent

> ИИ-агент, который учится на опыте и создаёт себе навыки сам

## Зачем

Обычный ИИ каждый раз решает задачу с нуля. Hermes запоминает как он решил задачу и в следующий раз делает быстрее. Решил один раз как деплоить проект -- записал себе скилл. В следующий раз не будет разбираться заново, а возьмёт готовый рецепт.

84 тысячи звёзд. Идея "агент, который растёт" зацепила многих.

## Как пользоваться

1. Установи:

```bash
pip install hermes-agent
```

2. Запусти с любой моделью (OpenAI, Anthropic, Ollama):

```bash
hermes --model ollama/deepseek-r1
```

3. Дай задачу. Агент решит её и спросит: "Сохранить как скилл?"
4. В следующий раз при похожей задаче он использует сохранённый скилл

Примеры автоскиллов:

- "Деплой на VPS через SSH" -- один раз настроил, потом повторяет
- "Парсинг CSV и построение графика" -- запомнил формат, применяет к новым файлам
- "Код-ревью по чеклисту" -- создал чеклист, проверяет автоматически
