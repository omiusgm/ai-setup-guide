# Goose (от Block)

> Бесплатный ИИ-агент с десктопным приложением -- работает с Ollama, без VPN

## Зачем

Хочешь ИИ-агента, но Claude Code стоит $100+, а Cursor $20? Goose -- бесплатный. Его делает Block (бывший Square, компания Джека Дорси). Главная фишка: работает с локальными моделями через Ollama. То есть можно запустить ИИ-агента полностью на своём компьютере, без облака, без VPN, без подписок.

42 тысячи звёзд. Десктопное приложение + терминал.

## Как пользоваться

**Десктоп (проще):**

1. Скачай с [block.github.io/goose](https://block.github.io/goose)
2. Установи как обычную программу
3. Подключи модель: облачную (OpenAI, Anthropic) или локальную (Ollama)

**Терминал:**

```bash
# Установка
brew install goose

# Запуск с локальной моделью
goose configure --provider ollama
goose session
```

**Связка с Ollama (бесплатно и из РФ):**

1. Установи Ollama и скачай модель: `ollama run deepseek-r1`
2. В настройках Goose выбери Ollama как провайдер
3. Готово -- бесплатный ИИ-агент на своём железе
