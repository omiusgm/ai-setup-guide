# DeepSeek R1/V3

> Бесплатный ИИ-чат, который работает из России без VPN

## Зачем

ChatGPT стоит $20/мес и требует VPN из РФ. DeepSeek -- бесплатный, работает напрямую, и по качеству ответов уже наступает на пятки платным моделям. R1 -- это их "думающая" модель (аналог o1 от OpenAI), V3 -- быстрая рабочая лошадка.

Китайцы не ввели санкции против России, поэтому сервис работает без танцев с бубнами.

## Как пользоваться

1. Зайди на [chat.deepseek.com](https://chat.deepseek.com)
2. Зарегистрируйся (можно через Google-аккаунт)
3. Выбери модель: DeepThink (R1) для сложных задач, обычный чат для простых
4. Пиши как в ChatGPT -- всё то же самое

На подходе V4 -- обещают на чипах Huawei, конец апреля 2026.

## Для кого

- Новички, которые хотят попробовать ИИ бесплатно
- Все, кто в РФ и не хочет заморачиваться с VPN
- Те, кому ChatGPT дорого, а пользоваться ИИ хочется
