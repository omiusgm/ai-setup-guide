# 10 правил вайбкодинга

> Конкретные ошибки и их исправления -- чтобы ИИ делал что надо, а не что попало

## Зачем

Вайбкодинг -- это когда ты описываешь что хочешь, а ИИ пишет код. Звучит просто, но 90% новичков наступают на одни и те же грабли: длинные диалоги, размытые промпты, отсутствие контекста. Эти 10 правил собраны из реального опыта -- каждое закрывает конкретную боль.

Самый популярный раздел гайда. Потому что без этих правил вайбкодинг превращается в лотерею.

## Правила

### 1. Длинный диалог = тупой ИИ

После 20-30 сообщений модель начинает "забывать" начало разговора. Решение: начинай новый чат, дав контекст в первом сообщении.

### 2. Один чат = одна задача

Не мешай "сделай кнопку" с "поправь баг в авторизации". Каждая задача -- отдельный чат.

### 3. Сначала план, потом код

Не проси сразу "напиши приложение". Сначала: "Составь план из 5 шагов, как сделать X". Потом иди по шагам.

### 4. Давай контекст файлами

Не описывай проект словами. Скинь файлы: package.json, структуру папок, примеры кода. ИИ работает лучше когда видит реальный код.

### 5. Промпт-файл -- твоя страховка

Создай файл CLAUDE.md (или .cursorrules) с описанием проекта. ИИ читает его при каждом запуске и не забывает контекст.

### 6. Не соглашайся на первый ответ

Если ответ не нравится -- скажи. "Нет, проще", "Не так, без фреймворков", "Перепиши короче". ИИ подстраивается.

### 7. Проверяй что написал ИИ

ИИ может написать рабочий код с дырой в безопасности. Или добавить зависимость, которая не нужна. Всегда читай что он сделал.

### 8. Git -- обязателен

Делай коммиты после каждого рабочего шага. Если ИИ сломает что-то -- откатишься. Без git вайбкодинг -- это русская рулетка.

### 9. Тесты -- не роскошь

Попроси ИИ написать тесты ДО того, как он начнёт кодить. Это как ТЗ, только для машины.

### 10. Знай когда остановиться

Если ИИ третий раз переписывает одно и то же -- стоп. Опиши проблему заново в новом чате, или разбей задачу на части.

## Для кого

- Новички в вайбкодинге

- Все, кто хочет получать от ИИ предсказуемый результат
