# Browser Use

> ИИ-агент, который сам кликает по сайтам, заполняет формы и собирает данные

## Зачем

Представь: тебе надо каждый день заходить на 10 сайтов, проверять цены, заполнять таблицу. Или парсить карточки товаров конкурентов. Или заполнять однотипные формы. Browser Use -- это ИИ, который умеет управлять браузером как человек. Он видит страницу, понимает что на ней, и кликает куда нужно.

87 тысяч звёзд -- проект взлетел, потому что задача "автоматизировать браузер" нужна всем.

## Как пользоваться

1. Установи Python 3.11+ (если нет)
2. В терминале:

```bash
pip install browser-use
playwright install
```

3. Напиши скрипт на Python, который описывает задачу:

```python
from browser_use import Agent
agent = Agent(task="Зайди на ozon.ru и найди цены на iPhone 16")
result = await agent.run()
```

4. Агент сам откроет браузер, перейдёт на сайт и выполнит задачу

Да, нужен минимальный Python. Но задачу описываешь человеческим языком.
