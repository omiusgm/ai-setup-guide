# /loop + Remote Tasks

> ИИ работает пока ты спишь -- локально или в облаке

## Зачем

Обычно ИИ-агент работает пока ты сидишь за компом. Закрыл крышку -- всё встало. /loop и Remote Tasks решают эту проблему: агент продолжает работу в фоне. /loop -- локально (компьютер должен быть включён), Remote Tasks -- в облаке (работает даже с выключенным ноутом).

Это как оставить помощника в офисе на ночь. Утром приходишь -- всё готово.

## Как пользоваться

**/loop (локально, в Claude Code):**

```bash
# Проверяй деплой каждые 5 минут
/loop 5m "проверь статус деплоя и напиши результат"

# Мониторь логи
/loop 10m "проверь логи на ошибки, если найдёшь -- запиши в errors.md"
```

Агент будет выполнять команду с заданным интервалом. Компьютер должен быть включён.

**Remote Tasks (в облаке):**

1. Создай задачу через Claude Code:

```bash
/schedule "Каждое утро в 9:00 проверяй новости по ИИ и пиши дайджест"
```

2. Задача выполняется на серверах Anthropic
3. Результат приходит в чат или сохраняется в файл

## Для кого

- Те, кто хочет автоматизировать рутинные проверки
- Разработчики с CI/CD задачами
- Все, кому нужен ИИ-помощник, работающий 24/7
