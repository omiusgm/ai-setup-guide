# MemPalace

> Долгосрочная память для ИИ -- "дворец памяти", где агент хранит знания между сессиями

## Зачем

ИИ забывает всё после закрытия чата. Каждый раз объясняешь заново: как устроен проект, какие решения принял, что уже пробовал. MemPalace решает эту проблему -- создаёт структурированное хранилище памяти, где ИИ-агент записывает и достаёт знания. Как записная книжка, но для машины.

45 тысяч звёзд. Создала, кстати, Мила Йовович (да, та самая актриса). Правда, бенчмарки вызвали споры в сообществе -- некоторые цифры выглядят слишком красиво.

## Как пользоваться

1. Установи через Claude Code:

```bash
claude skill install mempalace
```

2. Агент начнёт автоматически сохранять контекст между сессиями
3. При следующем запуске он "вспомнит" предыдущие разговоры

По сути, это скилл для Claude Code, который добавляет файловую систему памяти. Агент записывает туда факты, решения, паттерны -- и потом достаёт когда нужно.

## Для кого

- Те, кто работает с ИИ-агентами над долгими проектами
- Вайбкодеры, которые устали объяснять контекст каждый раз
- Все, кто хочет чтобы ИИ "помнил" между сессиями
