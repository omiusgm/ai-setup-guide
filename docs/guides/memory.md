# Контекст и память ИИ

Как сделать так, чтобы ИИ не забывал контекст между сессиями и не терял нить разговора.

---

## Проблема "Мементо"

ИИ как герой фильма "Мементо" -- каждый разговор начинает с чистого листа. Через 20-50 сообщений теряет начало беседы. Не помнит прошлые сессии.

---

## Как решать

### CLAUDE.md -- "стикеры на теле" из фильма

Файл который агент читает при каждом запуске. Храни архитектуру, решения, приоритеты. Это конституция проекта -- ИИ-фрилансер читает её при каждом "выходе на смену".

### /compact -- сжатие контекста

Команда для сжатия длинного диалога. Используй когда разговор затянулся и ИИ начинает путаться.

### Auto Memory / Auto Dream

Claude сам запоминает паттерны между сессиями. Работает автоматически. Проверить: `/memory`.

### Honcho -- кросс-сессионная память через MCP

```
npx skills add plastic-labs/honcho
```

[honcho.dev](http://honcho.dev) -- внешняя память — ИИ запоминает между чатами и думает о запомненном.

### Кастомные GPTs / Projects

Привязанная инструкция + база знаний. Подходит когда нужен стабильно один и тот же результат.

---

## Обратный промптинг

Если получил идеальный результат и хочешь воспроизвести его стабильно:

> Скажи: "Напиши промпт, который даст точно такой же результат в новом чате"

ИИ создаст промпт-инструкцию который ты можешь переиспользовать.

---

## Правила ведения проекта в файлах (не в чате!)

Не храни контекст проекта в чате -- он потеряется. Храни в файлах:

| Файл | Зачем |
|------|-------|
| `.claude/CLAUDE.md` | Конституция проекта (архитектура, стек, решения) |
| `docs/roadmap.md` | Куда идём |
| `docs/decisions.md` | Почему приняли решение X |
| `docs/done.md` | Что уже сделано |
| `CHANGELOG.md` | История изменений |

Периодически напоминай агенту: "Прочитай и обнови project docs".
