    📄 Красивые документы из ИИ¶

    🤖 Для агентов (Claude Code / Cursor)

    В браузерном ChatGPT тоже можно просить «сделай КП» — но структуру и визуал руками. Через агента — текст + .docx + загрузка в Google Docs автоматом.

    ИИ умеет генерировать не только текст, но и готовые деловые документы с таблицами, цветными callout-боксами, диаграммами и фирменным стилем. .docx, PDF, Google Docs — без Word и Canva.

    Обзор: Posit PBC — «Get started with Quarto — Mine Çetinkaya-Rundel»

    Зачем это нужно¶

    Предпринимателю без команды регулярно нужны красивые документы: - Коммерческое предложение клиенту - Техническое задание подрядчику - Договор согласования (правила, регламенты) - Отчёт по проекту для собственника - Одностраничник для встречи

    В Word собирать это руками — 2-4 часа на документ. Плюс дизайн съедает время. В результате — типовые простыни в Arial 11.

    С ИИ-пайплайном — 15-30 минут, и документ выглядит как профессиональный: callout-боксы выделяют суть, таблицы сравнивают варианты, диаграммы объясняют процесс.

    Бесплатные фишки до установки¶

    ChatGPT/Claude в браузере + ручная вёрстка в Canva¶

    Написал текст в чате → скопировал в Canva-шаблон → экспорт в PDF. Не быстро, но бесплатно. Подходит для 1-2 документов в месяц.

    Promptdown — Markdown с блоками¶

    Пишешь в Markdown с разделителями: 

    ## Заголовок
> **Важно:** текст в блоке-цитате

    Конвертируешь через markdown.io → Word → готово. Работает, но callout-боксы с цветными полосами так не получить.

    Готовые шаблоны КП¶

    Поищи «коммерческое предложение шаблон Word» в Яндексе — сотни бесплатных. Скачал → заполнил → экспортировал. Самый медленный путь, но нулевой порог входа.

    Если бесплатного мало — инструменты¶

    ⭐ Pretty-Docs + Pretty-PDFs — наши скиллы¶

    Скиллы автора канала для Claude Code. Генерят .docx и PDF с фирменным стилем: callout-боксы с цветными полосами слева, красные ❓-боксы для решений пользователя, таблицы, диаграммы, автозагрузка в Google Docs.

    Что уникально:

    • Callout с цветной полосой слева — ни в одном из 6 других инструментов этого нет из коробки. Визуально выделяет ключевую мысль.
    • ❓-бокс для решений — красный блок с «❓ Решение: какой вариант выбрать». Идеально для документов согласования когда нужно действие от читателя.
    • DSL-хелперы — вместо низкоуровневого python-docx/reportlab пишешь h1 / callout / callout_typed / callout_decision / std_table. За 50 строк собираешь КП на 10 страниц.
    • 5 типов callout по модели Quarto: note (синий ℹ️) / tip (зелёный 💡) / warning (жёлтый ⚠️) / caution (оранжевый 🚧) / important (красный ❗).
    • Кириллица из коробки в обеих версиях (docx через Arial, PDF через TTF).
    • Автозагрузка в Google Docs через google_docs_codex.py import-docx — получаешь ссылку автоматом.

    Как работает:

    Пишешь Claude Code в проекте что-то вроде «оформи как КП», «сделай красивый документ», «подготовь презентационный PDF» — Claude вызывает скилл, собирает .docx (или .pdf), загружает на Google Drive, возвращает ссылку.

    Кому подходит:

    • ✅ Регулярно пишешь КП клиентам (фрилансеры, агентства, B2B-услуги)
    • ✅ Делаешь документы согласования (регламенты, политики, правила)
    • ✅ Нужна автоматизация из Claude Code без Word
    • ✅ Важна кириллица и чистый Arial без глюков
    • ❌ НЕ подходит если ты не в Claude Code — скиллы локальные, не SaaS

    Нюанс ДО установки:

    • Скиллы НЕ публикуются в npm/brew — это кастомное решение для Claude Code. Исходники доступны в ~/.claude/skills/pretty-docs и ~/.claude/skills/pretty-pdfs у автора канала. Если хочешь такой же — пиши в @agentezh, поделюсь шаблоном.

    python-docx + docxtpl — шаблонные КП с переменными¶

    • python-docx — 5500⭐ базовая Python-библиотека для генерации .docx
    • docxtpl — 2600⭐ Jinja2-шаблоны внутри Word-файла

    Как работает:

    1. Дизайнишь шаблон КП руками в Word (один раз)
    2. В тексте вставляешь {{ client_name }}, {{ price }}, {{ deadline }}
    3. Говоришь Claude: «сделай 5 КП для этих клиентов» → питон-скрипт подставляет данные → 5 готовых .docx

    Кому подходит: делаешь 5+ однотипных КП в месяц (агенты недвижимости, SMM-фрилансеры, подрядчики). Окупается на третьем документе.

    WeasyPrint — HTML/CSS → PDF¶

    WeasyPrint — 8866⭐ мощный конвертер HTML+CSS в PDF

    Почему круто: дизайнишь документ как веб-страницу — CSS-сеткой, шрифтами с Google Fonts, цветами по Figma. На выходе — профессиональный PDF с разрывами страниц, колонтитулами, нумерацией.

    Кому подходит: делаешь одностраничники (pitch deck, executive summary), знаком с CSS хотя бы на уровне «умеешь читать» или готов попросить Claude написать стили.

    Нюанс ДО установки: нужны системные зависимости (Pango, Cairo, GLib). На Mac ставятся через brew install weasyprint. На Windows — через WSL или Docker.

    Office-Word-MCP-Server — говоришь, Claude редактирует Word¶

    Office-Word-MCP-Server — 1863⭐ MCP-сервер, Claude получает доступ к Word-документам

    Как работает: подключаешь как MCP в Claude Code / Cursor. Говоришь: «открой КП для Иванова, замени в разделе 3 таблицу на новую, сохрани». Claude делает.

    Кому подходит: много ручной правки существующих документов (юристы, бухгалтеры, сотрудники отдела закупок). Нюанс: кириллица пока не подтверждена сообществом, проверь руками.

    Quarto — Markdown → PDF/Word/HTML с callout-ами¶

    Quarto — 5517⭐ открытый инструмент для научных документов

    Почему круто: пишешь Markdown с простым синтаксисом {.callout-warning} → получаешь красиво оформленный документ в 5 форматах. 5 типов callout встроено: note / tip / warning / caution / important.

    Кому подходит: пишешь много технических отчётов, руководств, курсов. Тяжёлый для разового КП (требует LaTeX), оправдан для серии.

    fpdf2 — простой PDF без системных зависимостей¶

    :material-file-pdf: fpdf2 — 1509⭐ лёгкий Python-генератор PDF

    Почему круто: ставится через pip install fpdf2, без brew/apt, работает из коробки с кириллицей (через TTF-шрифты). Проще WeasyPrint и reportlab.

    Кому подходит: нужен PDF-счёт, накладная, короткий отчёт. Для сложных лейаутов — берёшь WeasyPrint.

    Для продвинутых — связка .docx → Google Docs¶

    Скрипт для автозагрузки на Google Drive:

    Для продвинутых (терминал)

    ⚠️ Для тех кто работает в Claude Code и хочет чтобы ИИ генерил документ и сразу присылал Google Docs-ссылку. Требует OAuth-настройки Google API.

    # 1. Настройка Google credentials (разово)
#    https://console.cloud.google.com → Create Project → Enable Drive API → OAuth credentials

# 2. Скрипт загрузки .docx как Google Doc:
python3 ~/scripts/google_docs_codex.py import-docx \
  --file /tmp/my_kp.docx \
  --title "КП для Иванова"

    Возвращает URL Google Doc. Работает в связке с python-docx / docxtpl.

    Сравнение по задаче¶

    Если нужно... Инструмент Сложность
    ⭐ КП с callout-боксами + Google Docs автозагрузка Pretty-Docs (наш) Низкая (скилл в Claude Code)
    ⭐ Одностраничник PDF с callout + кириллица Pretty-PDFs (наш) Низкая (скилл в Claude Code)
    Разовое КП клиенту ChatGPT + Canva-шаблон Нулевая
    5+ однотипных КП/мес docxtpl Средняя (Word шаблон + Python)
    Красивый одностраничник PDF через HTML/CSS WeasyPrint Средняя (знать CSS)
    PDF-счета и накладные fpdf2 Низкая
    Технические отчёты и гайды Quarto Средняя (LaTeX)
    Править существующие Word через ИИ Office-Word-MCP-Server Средняя (MCP)

    Кому точно подходит¶

    • ✅ Делаешь КП клиентам регулярно — агентство, фриланс, B2B-услуги
    • ✅ Пишешь ТЗ подрядчикам и сотрудникам
    • ✅ Работаешь с регламентами, политиками, инструкциями
    • ✅ Отчёты собственнику / инвесторам каждую неделю
    • ❌ НЕ подходит если документ нужен 1 раз в год — проще Word
    • ❌ НЕ подходит если нужен сложный дизайн (журнал, буклет) — там InDesign

    Альтернативы¶

    • Documint, PandaDoc, Better Proposals, Qwilr — SaaS платно (от $50/мес), красиво, но закрытая экосистема, не автоматизируется из скриптов
    • Google Docs напрямую — бесплатно, но без callout-боксов и цветных полос, всё вручную
    • Notion export → PDF — работает, но стиль Notion-минималистичный, не «КП»

    Совместимость

    Все Python-инструменты ставятся через pip. WeasyPrint и Office-Word-MCP-Server — open-source, можно использовать бесплатно. Claude Code → Google Docs связка требует Google Cloud проект (бесплатный до 1 млн запросов/мес).
