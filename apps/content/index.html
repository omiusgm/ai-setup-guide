    🎨 Контент¶

    🤖 Для продвинутых (агент или код)

    В браузере — альтернативы: Canva + ChatGPT для текста, Midjourney для картинок, Runway для видео.

    ИИ может сгенерировать картинку за 10 секунд. Но написать пост для Телеги который не воняет ChatGPT — это уже другая история. И ролик на 3 минуты с субтитрами и музыкой — тоже не «одна кнопка».

    Проблема: генерация ≠ написание. Генерация ≠ монтаж. Для серьёзного контента нужны не просто модели, а цепочки из них.

    Почему одной модели мало¶

    Генерация против написания. ChatGPT генерирует текст — набор слов подходящих друг к другу. Но пост для аудитории — это структура + голос + факты + CTA. Одним промптом такое не сделать. Нужны итерации, ревью, правки.

    Видео — это пайплайн. Один ролик = сценарий + озвучка + картинки + монтаж + субтитры + музыка. Это 6 разных инструментов. Агент может это связать — одна модель не может.

    Стиль и голос. Модель по умолчанию пишет корпоративно-вежливо. Чтобы звучало как ты, а не как пресс-релиз — нужны правила, примеры, редактура. Снова — цепочка.

    Поэтому простой ChatGPT хорош для черновика. Для серьёзной работы — нужны скиллы и агенты.

    Бесплатные фишки¶

    Midjourney в Discord

    Нужна одна картинка в месяц? Не ставь Remotion, не городи пайплайн. Зашёл в Discord → /imagine → готово. $10/месяц если разово, бесплатные пробы если в первый раз.

    Canva + ChatGPT

    Тексты в ChatGPT, обложки в Canva, собрал вручную. Бесплатно, быстро, для постов и сторис хватает. Не надо Remotion для одной картинки.

    Голосовой промпт

    Продиктуй ChatGPT мысли голосом через микрофон → он транскрибирует → ты получаешь черновик поста. Живее чем печатать, голос остаётся.

    Шаблоны промптов

    Один хороший шаблон «напиши пост в стиле X про Y с CTA Z» работает годами. Сохрани в файл, используй каждый раз. Не надо скилл.

    Humanizer-правила вручную

    Перед публикацией: убери «важно отметить», убери «представляет собой», сократи вступление, добавь разговорности. 5 минут — и текст нормальный. Не надо инструментов.

    Если фишек мало¶

    Для видео: - Remotion — 44K⭐ видео через React-компоненты, автогенерация роликов

    Для звонков и встреч: - Транскрибация с диаризацией — WhisperX 21K⭐, текст звонка с метками «менеджер/клиент». Кейс AmoCRM

    Для документов: - Pretty-Docs + WeasyPrint + Quarto — красивые Google Docs и PDF из Claude Code

    Скоро: Midjourney, Runway, Suno — обзоры в процессе.

    Для деловых документов (КП, отчёты, PDF): - Красивые документы из ИИ — python-docx, docxtpl, WeasyPrint, Quarto, MCP для Word. Обзор 6 инструментов

    Для текстов: - Humanizer — 14K⭐ убирает следы ИИ из текста - Шаблоны промптов → no-code-start
