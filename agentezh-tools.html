/ghost
миф		 Делает текст более человечным, обходит AI-детекторы CLI отсекает за 12мс с "Unknown skill: ghost". 0 токенов до модели. Не существует ни в каком виде в leaked source code (512K LOC проверено).

Уже сильнее:

  • copywriter Ёж-Перо пишет на голосе Ежа (мат, кухня, «ИИшечка»)
  • bulldog ловит AI-маркеры (канцелярит, «применима везде», «фундамент — статистика», «итак»)
  • failures_log учит copywriter не повторять anti-pattern фразы
Дополнительный humanizer избыточен.
/godmode (Claude built-in)
миф		 «Бог-режим», агент сам всё решает "Unknown skill: godmode". Тоже миф. Но существует third-party skill NoobyGains/godmode — engineering framework для coding (36 skills, Define→Plan→Execute→Review→Ship). Для contentpipeline @agentezh — overlap с тем что есть (CONSILIUM gate = quality gate, decide_action = task-planning).
Для собственных coding-проектов (preview-site v2, video-pipeline) — может быть полезен как scaffolding. В сундук → когда захочешь coding-проект.
OODA (как «команда»)
misnomer		 «Включает» OODA-режим Это не команда, а фреймворк John Boyd (Observe→Orient→Decide→Act). Без слэша уходит к модели, Claude узнаёт и структурирует ответ. То же самое со «SWOT», «5 Whys», «RACI». Не hidden feature — обычная грамотность Claude.

Реально полезно как pattern в rubric:

  • bulldog может судить через OODA: Observe (что сказано) → Orient (куда уводит) → Decide (publish или нет) → Act (конкретные правки)
  • strategist для конкурентных постов: OODA по тренду
Можно добавить в их prompt'ы как optional rubric.
